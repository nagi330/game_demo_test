# 吴国人物卡牌设计

版本：v2
日期：2026-10-13
用途：合并吴国人物卡牌的前后两批最终设计，供实现、测试和后续平衡调整参考。

> 本文档是设计归档，不作为运行时数据源。实际卡牌数据以 `data/cards.yaml` 为准，游戏机制以 `docs/gdd/` 为准。

## 人物设计

数值统一使用“费用 / 攻击 / 生命”表示。

| 武将 | 数值 | 技能效果 | 设计背景 |
|---|---:|---|---|
| 太史慈 | 7/3/6 | **归吴**：战吼，召唤一个骑兵。<br>**神射**：战技，选择一名敌方单位，造成2点伤害，并使其攻击力-2，持续至我方回合结束。 | 太史慈原为刘繇部将，后被孙策招降并重用，“归吴”表现其带兵归附。演义中他多次展现精准箭术，曾射中敌方士兵的手，使其武器脱落、无法继续作战，对应“神射”的伤害与减攻。 |
| 诸葛恪 | 4/1/4 | **急智**：战吼，抽2张牌。<br>**骄狂**：己方回合结束时获得1层“骄狂”；随机弃置等同于“骄狂”层数的手牌，每少弃置1张，移除己方牌库顶1张牌；成功弃牌后，造成3次伤害，每次对一名随机敌方单位造成1点伤害。 | 诸葛恪少年时机敏善辩，故有“急智”。东兴大捷后声望达到顶峰，后因合肥新城久攻不下仍不愿撤退，体现由才智转向骄狂和误判。 |
| 鲁肃 | 4/1/4 | **榻上策**：战吼，发现吴国或蜀国战法牌，选择一张加入手牌。<br>**仗义疏财**：初始三层“资粮”，战技，消耗一层资粮，使一名其他己方单位获得+1/+1。 | “榻上策”对应鲁肃为孙权分析天下形势、提出联合刘备抗曹的战略；“仗义疏财”对应他散财助人、资助周瑜和军队。 |
| 陆逊 | 6/4/4 | **火烧连营**：战技，每回合一次，抉择：①使所有敌方单位获得“引火”；②对所有具有“引火”或“灼烧”的敌方单位各造成1点火攻伤害。 | 夷陵之战中，陆逊长期坚守，等待蜀军疲惫后发动火攻，最终烧毁刘备连营。两种抉择分别表现布置火势与连锁焚烧。 |
| 周瑜 | 7/1/5 | **反间计**：战吼，选择一名敌方武将，与其进行拼点；若获胜，消灭该武将，并对敌方主公造成等同于该武将被消灭前攻击力的伤害；若失败，使该武将获得“震慑”，持续至下个敌方回合结束；平局无效果。<br>**赤壁督军**：光环，己方造成的直接火攻伤害增加1点。 | “反间计”对应蒋干盗书，周瑜伪造蔡瑁、张允通敌的书信，使曹操误杀水军将领；“赤壁督军”对应周瑜统筹黄盖诈降、水军调度和火攻作战。 |
| 潘璋 | 5/4/3 | **擒将夺刃**：战吼，对一名受伤的敌方武将造成3点伤害；若该伤害使其阵亡，潘璋获得+2攻击。<br>**归刃**：亡语，击杀潘璋的敌人获得+2攻击力。 | 潘璋参与麦城截击，其部将马忠擒获关羽；潘璋后来使用关羽的青龙偃月刀，最终被关兴杀死并夺回兵刃，分别对应收割敌将与兵刃归还。 |
| 徐盛 | 5/1/6 | **疑城**：架盾；每个敌方回合首次被攻击时，获得等同于手牌中武将牌与兵种牌数量的攻击力，持续至该回合结束。 | 徐盛擅长防守、布阵和疑兵。演义中，他通过设置旗帜、营寨制造吴军数量众多的假象，体现架盾坚守与预先布置后的防守反击。 |
| 董袭 | 4/3/5 | **架盾。当锋护驾**：当己方主公受到敌方具有“先攻”的单位造成的伤害时，若董袭在手牌中，可在敌方回合自动触发，不消耗统率将董袭召唤上场，并由董袭承受此次伤害。每局限一次。 | 董袭是孙权身边的勇猛护卫，在敌军突袭和撤退时负责保护主公。“先攻”表现突然冲击，免费登场并承伤表现临危护驾、以身挡敌。 |
| 陈武 | 4/2/3 | **先攻。芦荡死战**：当其他己方角色阵亡时，陈武获得+1攻击；当陈武阵亡时，对敌方全体造成1点物理伤害。 | 陈武是孙权麾下的勇将，合肥之战中陷入芦苇荡并战死。先攻表现勇猛冲阵，友军阵亡后的强化表现局势越危急越奋死作战。 |
| 张昭 | 3/1/3 | **激励。辅政**：每次使用主公技后，抽1张牌。 | 张昭与张纮并称“二张”，孙策临终时托孤于张昭，孙权执政后长期负责政务和朝廷秩序。“辅政”表现其稳定内政、协助主公决策的作用。 |
| 李异 | 2/2/2 | **统帅水军**：战吼，从牌库发现一张具有水攻伤害效果的牌。<br>**协同追击**：其他己方来源造成水攻伤害后，对其中一名受伤目标额外造成1点水攻伤害；该额外伤害不会触发李异的协同追击。 | 《三国志》中与谢旌共同统领水军；《演义》第82回率水军作战，后被关兴击杀，体现水军统率与协同追击。 |
| 宋谦 | 2/2/3 | **奋戟**：敌方回合开始时，攻击力+1。<br>**轻进**：己方回合开始时，失去1点生命，最低降至1。 | 《演义》第53回与贾华护卫孙权，追击乐进，最终被李典射杀，体现护主、追敌与冒进。 |
| 朱然 | 3/2/3 | **截江**：战吼，对指定敌方目标造成1点伤害；目标为主公时禁用主公技，否则禁用战技，持续至敌方下个回合结束。 | 《演义》第84回在江上截击刘备退路；历史上长期坚守江陵，体现截击、封锁与水战控制。 |
| 祖茂 | 3/2/4 | **换帻**：战吼，秘密选择另一名己方单位，由祖茂承受其伤害，直至祖茂离场；首次转移伤害时揭示目标。 | 《演义》第5回替孙坚戴红帻，引诱华雄追击，体现替主担险、隐蔽诱敌与忠勇。 |
| 马忠 | 3/2/3 | **设伏**：战吼，选择受伤敌方武将，使其攻击力变为0并获得震慑，直至其恢复满生命值。 | 《演义》第77回设伏擒获关羽；第83回伏击并射伤黄忠，体现伏击、擒将与持续压制。 |
| 丁奉 | 4/2/2 | 先攻。<br>**雪中奋短兵**：光环，使后续召唤的武将、谋臣或兵种获得先攻，但攻击力和生命上限各-2，最低1。 | 《演义》第108回雪中率三千水兵脱甲持短刀，突袭魏营，体现轻装突袭与以身犯险。 |
| 韩当 | 4/3/3 | **救援**：为一名友方单位恢复3点生命。<br>**火攻接应**：所有敌方单位获得1层灼烧。 | 《演义》第50回救起中箭落水的黄盖并为其包扎，随后率水军接应赤壁火攻，体现救援与火攻协同。 |
| 黄盖 | 4/3/4 | **苦肉计**：战技，选择敌方武将，自身受1点伤害；50%使其下个回合无法普通攻击；成功则在下个敌方回合结束时对所有敌方单位造成1点火攻伤害。 | 《演义》第46、49回主动受刑诈降，随后驾火船冲击曹军，体现苦肉、诈降与延迟火攻。 |
| 陆抗 | 4/2/4 | **息兵**：己方回合结束时，为本回合未攻击且未使用战技的其他己方单位恢复1点生命。 | 《演义》第120回与羊祜礼尚往来，主张各守疆界、不争小利，体现持重、休整与以德守边。 |
| 孙坚 | 6/5/5 | **聚义兴师**：从牌库发现一张武将。<br>**遗志相承**：亡语，使手牌中所有武将统帅-1。 | 孙坚是孙氏基业奠基者，聚集程普、黄盖、韩当等旧部；阵亡后由孙策承继事业，体现聚将与遗志传承。 |
| 朱桓 | 4/3/5 | **以逸待劳**：战吼，标记所有敌方单位为疲困；与被标记单位战斗时，本次攻击+2。 | 《演义》第85回据濡须坚守，认为曹仁远道疲惫，偃旗息鼓后突然斩杀常雕，体现守势蓄力与突然反击。 |
| 甘宁 | 5/3/3 | **锦帆统领**：将己方无属性或物理伤害改为水攻。<br>**锦帆聚众**：召唤锦帆军。<br>**百骑劫营**：使所有敌方单位攻击力-1，持续至下个敌方回合结束。 | 甘宁早年为锦帆贼；《演义》第68回率百骑夜袭曹营，扰乱中军后全身而退，体现锦帆水军与突袭扰乱。 |
| 凌统 | 7/3/4 | 先攻。<br>**逍遥津死战**：战吼，召唤一个东吴精骑，该骑兵在本回合结束时阵亡。 | 《演义》第67回逍遥津之战，率三百余骑死战断后，掩护孙权撤退，部下尽数战死，体现先攻、骑兵突击与牺牲断后。 |
| 孙策 | 5/5/5 | **江东霸王**：战吼，对敌方人物造成等同于己方场上武将数量的伤害。 | 《演义》第15回承接孙坚旧部、借兵渡江、平定江东，并以武勇获得“小霸王”称号，体现聚将扩张与个人威势。 |
| 程普 | 5/4/5 | **三朝虎臣**：每回合一次，其他己方武将普通攻击后若存活，使其获得+1/+1。 | 程普历经孙坚、孙策、孙权三代，长期征战并辅佐孙氏，体现老将带队、扶持后辈与持续作战。 |

## 实现对应

- 卡牌数据：`data/cards.yaml`。
- 状态和关键词注册：`data/statuses.yaml`、`data/keywords.yaml`。
- 规则实现：`core/src/`。
- 专项测试：`core/test/wu-new-cards.test.ts`。

本版本合并了 v1 的吴国人物设计，并补充太史慈、诸葛恪、鲁肃、陆逊、周瑜、潘璋、徐盛、董袭、陈武和张昭的设计记录。实际实现以卡牌数据和规则测试结果为准。
