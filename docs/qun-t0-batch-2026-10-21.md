### 2.1 李儒（考证已回，2026-10-21）

> 考证修正：T0 预判的「毒计/焚城/迁都」**三条都站不住**——《三国志》65 卷（正文+裴注）「李儒」**0 命中**；焚城/迁都的 A/B 主语是**董卓**（「焚燒洛陽宮室」《三国志》卷六《董卓传》；「卓留屯洛陽，遂焚宮室」卷一《武帝纪》；「悉燒宮廟官府居家」《后汉书》七十二；「董卓收諸富室」《通鉴》五十九）；「毒计」是**贾诩**的标签；「董卓女婿」「被王允斩」「死于董卓之死」都是演义/误传。唯一 A 级「李儒」原文是《后汉书》卷十下「**使郎中令李儒進酖**」（鸩杀弘农王）；《后汉纪》二十七记他 195 年还由李傕举为侍中。

**推荐 鸩酒 4 费 1/4 谋臣（`elite`，`tags: [dong_zhuo]`，`keywords: [ju_du]`）**
> 战吼：若一名敌方人物攻击力 < 4，对其造成 1 点毒攻。若伤害生效，剧毒直接消灭。

- **史料**：A-01《后汉书》卷十下「使郎中令李儒進酖」——毒酒鸩杀弘农王；「鸩酒」即此。
- **剧毒 ≠ 中毒**：`ju_du` 是该单位造成伤害并**实际命中**后直接消灭受伤单位；`zhong_du` 是永久削生命上限。剧毒只对场上单位、对主公无效；此前卡池 0 使用者（无当飞军已移除，ADR-117 裁定「剧毒另立卡牌」），李儒是第一张。
- **只判断攻击 <4，不削攻**：`condition: { chosen_attack_max: 3 }` 读目标**当前**攻击力（0/1/2/3 可毒杀；4 攻及以上完全不碰）；`ju_du` 只在伤害生效时触发。
- **引擎**：`ju_du` 已有 + 新增 `chosen_attack_max`（`core/src/types.ts` / `effects.ts`；1 个条件，无新动作）。
- **平衡**：4 费 1/4 = 5（基准 9，**−4**）；攻击 <4 才下毒 ≈ **3~4**；贴线。若偏强：3 → 2（只毒杀 ≤2 攻）；若偏弱：3 → 4（≤4 攻）。
- **对冲**：披坚/免疫/减伤到 0 → 1 点毒攻不生效 → `ju_du` 不触发（披坚人物不会被毒杀）；4 攻及以上天然免疫；主公不能选；李儒 1/4 可被解。
- **`flavor`**：`使郎中令李儒進酖`（《后汉书》卷十下，A）。
- **`note` 不得写**：李儒焚洛阳/劝迁都；李儒是董卓女婿；李儒被王允斩/死于董卓之死；《三国志》载李儒；李儒读废立策（读册的是尚书）。
- **测试（已实现）**：`core/test/qun-liru.test.ts` 10 条——数据形态 / 3 攻杀 / 2 攻杀 / 1 攻杀 / 0 攻杀 / 4 攻边界不杀 / 5 攻不杀 / 7 攻不杀 / 披坚不触发 / 主公不能选。
- **验证（已跑）**：`npm test` 897 全绿；typecheck 通过；validate 0 错误 / 12 警告；verify:dsl 208 张通过；smoke 回放一致。

**备选 J1「缓师·持重」4 费 1/4 谋臣**

## 3. 设计标准（每张卡交付时）

1. **1 推荐 + 2~3 备选**，覆盖至少 3 个不同方向；不靠同一方向微调数字。
2. 每个方案标：**史料等级 / 引擎成本（零改动 or 需补什么）/ 强度估算 / 对手能否对冲**。
3. **不把机制绑死在另一张特定卡上**（禁止“颜良死了文丑才强”这类两卡凑齐）。
4. **不为了贴史料把设计者定稿的数值改弱改窄**；史料是素材，不是枷锁。
5. 过 `12-randomness.md`：不做“单次随机决定胜负”；随机只做可读目标。
6. `note` 写出处与等级 + 「不得写」；`flavor` 用 A/B 级原文；C 级（演义）只作气质，不进史实区。
7. 检查引擎：动作/触发器/条件/过滤器是否存在；⚠️ `mode:'choose'` 兜底、`condition` 求值时机。
8. 每张卡带测试；全量 `npm test` / typecheck / validate / verify:dsl / smoke；重建 bundle 与 GDD HTML。
