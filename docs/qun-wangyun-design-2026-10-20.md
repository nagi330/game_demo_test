## 0. 先算账：5 费 1/4 谋臣

| 项 | 数值 |
|---|---|
| 属性点 | 1 + 4 = **5** |
| 5 费基准 | 2×5+1 = **11** |
| 身体偏差 | **−6**（身板很脆，技能预算 ≈6 点） |
| 同费谋臣对照 | 陈宫 4 费 1/5（6，−3）、貂蝉 5 费 1/3（4，−7）、程昱 5 费 1/5（6，−5）、荀彧 5 费 1/5（6，−5） |
| 定位 | 5 费「纯技能」谋臣；1/4 是**代价**，技能必须撑起 6 点左右的节奏 |

**结论**：5 费 1/4 的预算足够做一个“有决策重量”的谋臣，但不能给**无条件**的硬解。
下面五个方案从“纯链”“硬解”“辅助”“税”四个方向排开；推荐方案是**两难抉择**，避免单一路线被针对后变成白板。

## 1. 王允的五个抓点（史料 → 机制方向）

| # | 抓点 | 史料 | 机制方向 |
|---|---|---|---|
| ① | **合谋诛董卓**：王允与士孙瑞密谋、告吕布为内应，吕布手刃董卓 | **A（已核）**：`qun-lvbu.md` A-05（卷七） | 硬解/刺杀高价值目标；与吕布形成“克星”关系 |
| ② | **连环计/离间**：让董卓、吕布互相猜忌 | **C**（演义第 8~9 回；正史无“连环计”之名） | 令敌人互相攻击、链式离间 |
| ③ | **秉政**：董卓死后，王允“共秉朝政”、录尚书事 | **A（已核）**：A-05 末句「共秉朝政」 | 辅助/主公收益 |
| ④ | **刚棱疾恶、不循权宜**：史书评他刚直、不容恶、不善权变 | **A（待考证稿）** | 对“大牌/权臣”的税/压制；或作为代价面 |
| ⑤ | **拒赦李傕/郭汜 → 反攻长安 → 王允被杀**：刚直带来的反噬 | **A/B（待考证稿）** | 自伤/风险；硬解要付代价 |

> ⚠️ **不能用的抓点**：貂蝉、凤仪亭、王允“义父”、王允“跳楼”都是 **C**；
> 王允不是武将、不是董卓部下；他死在李傕/郭汜手里，不是董卓手里。

## 2. 最推荐：连环计（抉择：离间 / 诛恶）

- **卡**：王允 · 群 · **谋臣** · **5 费 1/4** · `rarity: elite` · 无关键词
- **技能**：`连环计`（战吼，抉择）
- **卡面文案**：
  > 战吼（抉择）：① **离间**：选择一名敌方人物，令其攻击另一名随机敌方人物；然后令另一名随机敌方人物攻击另一名随机敌方人物。② **诛恶**：消灭一名费用 ≥5 的敌方人物；若如此做，王允受到 3 点伤害。
- **DSL 形状**：
  ```yaml
  skills:
  - id: lian_huan_ji
    name: 连环计
    kind: trigger
    trigger: on_play
    text: 战吼（抉择）：① 离间：选择一名敌方人物，令其攻击另一名随机敌方人物；然后令另一名随机敌方人物攻击另一名随机敌方人物。② 诛恶：消灭一名费用 ≥5 的敌方人物；若如此做，王允受到 3 点伤害。
    modes:
    - name: 离间
      effects:
      - action: force_attack
        attack_side: own
        target: { side: enemy, filter: { type: character }, count: 1, mode: choose }
      - action: force_attack
        attack_side: own
        target: { side: enemy, filter: { type: character }, count: 1, mode: random }
    - name: 诛恶
      effects:
      - action: destroy
        target: { side: enemy, filter: { type: character, cost_min: 5 }, count: 1, mode: choose }
      - action: damage
        value: 3
        target: { source: true }
        condition: { chosen_dead: true }
  ```
- **史料**：
  - **A（已核，卷七 A-05）**：「先是，司徒王允以布州里壯健，厚接納之。後布詣允，陳卓幾見殺狀。時允與僕射士孫瑞密謀誅卓，是以告布使為內應。……布遂許之，手刃刺卓。……允以布為（奮威）〔奮武〕將軍，假節，儀比三司，進封溫侯，**共秉朝政**。」
    —— **合谋诛董卓**是 A；`共秉朝政` 是 A；这是本卡“诛恶/秉政”两条线的硬底子。
  - **C（演义，只作名字/气质）**：貂蝉、连环计、凤仪亭（毛本第 8~9 回）；正史无“连环计”之名，貂蝉不见于王允/吕布相关纪传。
  - **A（司徒已核 / 字·籍贯待稿）**：司徒（A-05 已核）；字子师、太原祁人（待稿）；“刚棱疾恶”“不循权宜”（待稿）；拒赦李傕/郭汜 → 反攻长安 → 王允被杀（待稿）。
- **引擎**：**零改动**。
  - `modes` 抉择（曹彰/陷阵营先例）；
  - `force_attack` 已实现（贾诩「离间计」、趁火打劫在用），`attack_side: own` = 打自己人；
  - `destroy` 已实现（马岱「追斩」、周仓「死节」在用），`cost_min` 过滤已实现；
  - 自伤条件用 **`chosen_dead`**（ADR-179，刚为吕布加的条件）：`destroy` 之后读“所选目标是否已阵亡”，
    若目标被披坚救下/没有目标 → 不反噬；这个条件正好复用。
- **强度**：5 费 1/4 = 5（基准 11，**−6**）。
  - 离间：两次强制普攻（每次 2~4 点，含反击）≈ 4~8；合计 9~13。
  - 诛恶：消灭一个费用 ≥5 的目标（≈5~7）＋自伤 3（≈−1.5）；合计 8.5~10.5。
  - 抉择的灵活性 ≈ +1；综合 **10~13**，略强于 5 费基准——`elite` 可接受。
  - 若实测过强，杠杆按顺序：① 自伤 3 → 4；② 离间只保留一次强制攻击；③ 6 费。
  - 若实测偏弱：身板 1/4 → 1/5，或诛恶自伤 3 → 2。
- **对冲**：
  - **离间**：敌方只留一个人物 → 没有“另一名随机敌方人物”，第一次强制攻击直接空放；高血量/披坚/藤甲也能降低收益。
  - **诛恶**：敌方没有费用 ≥5 的人物 → 目标池为空，只剩 1/4 白板；**披坚**可以吃掉 `destroy` 的 9999 伤害（`destroy` 实际是 9999 点伤害，不是“规则消灭”）；`untargetable`（奇袭/翻面/空城）不能被选。
  - **自伤**：王允 1/4，诛恶后只剩 1 血；对手下回合可以直接补掉。
- **为什么最推荐**：
  - 它同时给出**两个“王允式”的解法**：离间（让敌人内讧）和诛恶（除掉权臣），玩家根据对手场面选；
  - 它不是单一路线：对手不铺场 → 选诛恶；对手铺大牌 → 选离间；两边都有反制，不是无脑强；
  - 它把“诛董卓”的 A 级事件做成“费用 ≥5”的硬解，正好克制刚加的 9 费吕布；
  - 零引擎改动（复用 `chosen_dead`），落地风险低；
  - 自伤 3 是王允“刚棱疾恶/不循权宜”的代价面，不是白给的硬解。

## 3. 备选 A：连环计·双离间（纯链，不带硬解）

- **卡**：同上（5 费 1/4）
- **技能**：`连环计`（战吼）
- **卡面**：
  > 战吼：选择一名敌方人物，令其攻击另一名随机敌方人物；然后令另一名随机敌方人物攻击另一名随机敌方人物。
- **DSL**：只保留推荐方案的「离间」分支（两个 `force_attack`，第一个 `mode: choose`、第二个 `mode: random`）。
- **史料**：A-05 合谋（A）＋ 连环计（C）；“令敌人互相攻击”是“离间董卓吕布”的设计演绎。
- **引擎**：零改动。
- **强度**：5 + 两次强制普攻（4~8）≈ **9~13**；对铺场强，对单大哥弱。
- **对冲**：只留一个人物 → 双空放；高血/披坚/藤甲降低收益；随机目标让对手可以用站位/血量控制。
- **为什么是备选**：比推荐方案更“纯”，但没有硬解；遇到单大哥（如吕布）时只能打杂兵，容易变成 1/4 白板。

## 4. 备选 B：诛董卓（单体除国贼，付自伤）

- **卡**：同上（5 费 1/4）
- **技能**：`诛董卓`（战吼）
- **卡面**：
  > 战吼：消灭一名费用 ≥5 的敌方人物；若如此做，王允受到 3 点伤害。
- **DSL**：只保留推荐方案的「诛恶」分支。
- **史料**：A-05 合谋诛董卓（A）；“费用 ≥5”是游戏抽象，不是史料原文；`诛董卓` 是后世对这件事的简称。
- **引擎**：零改动（`destroy` + `cost_min` + `chosen_dead`）。
- **强度**：5 + 消灭高费（5~7）＋自伤 3（−1.5）≈ **8.5~10.5**；对 9 费吕布/8 费关羽是硬解，对低费卡组是 1/4 白板。
- **对冲**：没有费用 ≥5 的人物；披坚吃掉 `destroy`；`untargetable`；自伤后只剩 1 血。
- **为什么是备选**：最直接、最像“诛董卓”，但它是**单点银弹**：对手低费铺场时完全空放，不如推荐方案的抉择稳。

## 5. 备选 C：秉政（扶汉辅助）

- **卡**：王允 · 群 · 谋臣 · **5 费 1/5** · `rarity: common`
- **技能**：`秉政`（战吼）
- **卡面**：
  > 战吼：己方主公回复 4 点生命；抽 1 张牌。
- **DSL**：
  ```yaml
  effects:
  - action: heal
    value: 4
    target: { side: ally, lord: true }
  - action: draw
    value: 1
  ```
- **史料**：A-05「共秉朝政」（A）；回复/抽牌是设计抽象。
- **引擎**：零改动。
- **强度**：6 + 回复 4（≈1.6）＋抽 1（3）≈ **10.6**；贴 5 费基准。
- **对冲**：没有直接反制，但它是纯辅助，对手可以抢节奏；1/5 身板很弱。
- **为什么是备选**：最稳、最“汉臣”，但最不像“王允的计”；如果设计者想要一张**辅助型谋臣**，这条最干净。

## 6. 备选 D：刚棱疾恶（高费手牌税）

- **卡**：王允 · 群 · 谋臣 · **4 费 1/5** · `rarity: common`
- **技能**：`刚棱疾恶`（光环）
- **卡面**：
  > 光环：敌方手牌中费用 ≥5 的人物卡统率消耗 +2（王允离场即失效）。
- **DSL**：
  ```yaml
  - id: gang_leng_ji_e
    name: 刚棱疾恶
    kind: aura
    text: 光环：敌方手牌中费用 ≥5 的人物卡统率消耗 +2（王允离场即失效）。
    effects:
    - action: cost_modifier
      value: 2
      target:
        side: enemy
        zone: hand
        filter:
          type: character
          cost_min: 5
        count: all
  ```
- **史料**：A（待考证稿）「刚棱疾恶」；税是设计抽象。
- **引擎**：零改动（`aura` + `cost_modifier` + `cost_min`；黄权「闭境待清」同一条路径）。
- **强度**：6 + 税（2~3）≈ **8~9**；4 费基准 9，贴线。
- **对冲**：低费卡组几乎不吃；王允被解即失效；只税“手牌”，已上场的大哥不受影响。
- **为什么是备选**：它是“刚棱疾恶”的直译，但**与黄权「闭境待清」同轴**（都是敌方手牌人物加费）——
  黄权是“所有人物 +1”，王允是“费用 ≥5 的人物 +2”。如果要避免同轴，优先选推荐方案/诛董卓。
- **与黄权的区分**：黄权惩罚“所有人物”，王允只惩罚“大牌”；黄权 2 费 1/3，王允 4 费 1/5。
  即便如此，两张卡放在一起仍有“同一种税”的既视感，`note` 要写清。

## 7. 横向对比

| 方案 | 方向 | 引擎 | 强度（≈） | 对谁强 | 对谁弱 | 风险 |
|---|---|---|---|---|---|---|
| ⭐ **连环计（离间/诛恶）** | 抉择/硬解/离间 | 零改动 | 10~13 | 大牌单核、铺场 | 单人物、低费、披坚 | 略超模；自伤后很脆 |
| **连环计·双离间** | 纯离间 | 零改动 | 9~13 | 铺场、多单位 | 单大哥、高血 | 没有硬解，容易白板 |
| **诛董卓** | 硬解 | 零改动 | 8.5~10.5 | 9 费吕布/8 费关羽 | 低费、披坚 | 单点银弹，空放 |
| **秉政** | 辅助 | 零改动 | 10.6 | 慢速、主公血量 | 快攻 | 太通用，不像王允 |
| **刚棱疾恶** | 税/控制 | 零改动 | 8~9 | 高费卡组 | 低费快攻 | 与黄权同轴 |

**推荐顺序**：连环计（抉择） > 诛董卓 > 连环计·双离间 > 秉政 > 刚棱疾恶。

```

- ❌ 王允被董卓所杀（董卓先死；王允后被李傕/郭汜所杀，A/B 待考证稿）；
```

## 11. 修订（2026-10-20 设计者反馈：5 费版太强）

设计者意见：
- 5 费 1/4 的「连环计」太强，虽然很符合人物。
- 想做 **6~8 费橙卡**；「离间」作为直接战吼；**直接消灭要限制在“选择离间的两个人”里**。
- 失败 = 王允阵亡？但王允战吼后本来就没用，**单纯阵亡不是代价**。

### 11.1 先回答两个问题

**① 消灭必须限制在“被离间的两个人”里 —— 对。**
否则它就是“任意费用≥5 硬解 + 两次强制攻击”，5 费太灵活。修订版把消灭限定为：
**两名被选中的敌人互相攻击；若其中一名阵亡，消灭另一名（幸存者）**。这不是“任意高费硬解”，
而是“你选的这对里，死一个就带走另一个”。

**② 王允阵亡不是代价 —— 对。**
1/4 或 1/7 的谋臣，战吼后本来就没有持续价值；单纯死亡只是送对手一个 1/x 的墙。
要让失败有意义，三选一：
- **A. 给他一个战后仍有价值的光环**（「刚棱疾恶」：敌方手牌高费人物 +1/+2）——阵亡 = 光环丢失；
- **B. 不让他死，失败 = 计不成**（不斩杀）——卡本身还是一张 1/7 墙；
- **C. 加大失败代价**（阵亡 + 敌方抽 2 / 获得护甲）——更像赌徒，不是谋臣。

我推荐 **B（R2）** 作为最稳的版本；要“死亡风险”选 **A（R1）**；要“8 费赌徒”选 **C（R3）**；
要零引擎选 **R4**。

### 11.2 R1：7 费 1/7 · 连环计（双选决斗 + 斩杀幸存者 + 计败阵亡 + 刚棱疾恶光环）

**卡**：王允 · 群 · 谋臣 · **7 费 1/7** · `rarity: elite` · 无关键词

**卡面**：
> 战吼：选择两名敌方人物，令它们互相攻击一次（双方各进行一次真实普攻）。若其中一名阵亡，消灭另一名；若两名都存活，王允阵亡。
> 光环：敌方手牌中费用 ≥5 的人物卡统率消耗 +1（王允离场即失效）。

**DSL（需要 `force_attack.victim_pick` + `chosen2_dead`）**：
```yaml
skills:
- id: lian_huan_ji
  name: 连环计
  kind: trigger
  trigger: on_play
  text: 战吼：选择两名敌方人物，令它们互相攻击一次。若其中一名阵亡，消灭另一名；若两名都存活，王允阵亡。
  effects:
  - action: force_attack
    attack_side: own
    victim_pick: 2
    target: { side: enemy, filter: { type: character }, count: 1, mode: choose, pick: 1 }
  - action: force_attack
    attack_side: own
    victim_pick: 1
    target: { side: enemy, filter: { type: character }, count: 1, mode: choose, pick: 2 }
  - action: destroy
    target: { side: enemy, filter: { type: character }, count: 1, mode: choose, pick: 2 }
    condition: { all_of: [{ chosen_dead: true }, { chosen2_dead: false }] }
  - action: destroy
    target: { side: enemy, filter: { type: character }, count: 1, mode: choose, pick: 1 }
    condition: { all_of: [{ chosen2_dead: true }, { chosen_dead: false }] }
  - action: damage
    value: 9999
    target: { source: true }
    condition: { all_of: [{ chosen_dead: false }, { chosen2_dead: false }] }
- id: gang_leng_ji_e
  name: 刚棱疾恶
  kind: aura
  text: 光环：敌方手牌中费用 ≥5 的人物卡统率消耗 +1（王允离场即失效）。
  effects:
  - action: cost_modifier
    value: 1
    target:
      side: enemy
      zone: hand
      filter: { type: character, cost_min: 5 }
      count: all
```
- **强度**：7 费 1/7 = 8（基准 15，**−7**）＋ 2 换 1（≈6~8）＋光环（≈2）≈ **16~18**（+1~3，elite）。
- **失败**：两名都存活 → 王允阵亡 → 光环丢失；这是“阵亡有代价”的关键。
- **对冲**：对手只留高血/高攻单位（两边都杀不死）→ 计败；披坚/藤甲降低决斗伤害；王允死后光环立即失效。

### 11.3 R2：7 费 1/7 · 连环计（双选决斗 + 斩杀幸存者；计败不斩，王允存活 + 刚棱疾恶光环）【推荐】

**卡面**：
> 战吼：选择两名敌方人物，令它们互相攻击一次（双方各进行一次真实普攻）。若其中一名阵亡，消灭另一名。
> 光环：敌方手牌中费用 ≥5 的人物卡统率消耗 +1（王允离场即失效）。

**与 R1 的差别**：删掉“若两名都存活，王允阵亡”。计不成 = **不斩杀**，王允活着继续挂光环。
- **强度**：7 费 1/7 = 8 ＋ 2 换 1（≈6~8）＋光环（≈2）≈ **16~18**；失败只是“没赚到 2 换 1”，不是送死。
- **为什么推荐**：它正面回答“王允阵亡不是代价”——**不让他死**，把失败做成“计不成”；同时保留“死一个带走另一个”的连环感；
  7 费 1/7 的墙 + 光环让他战后仍有一点价值，不是纯白板。
- **对冲**：同 R1；但对手不能靠“逼死王允”来赚节奏，只能让决斗不产生击杀。

### 11.4 R3：8 费 1/8 · 连环计（双选决斗 + 斩杀幸存者；计败阵亡 + 敌方抽 2）

**卡面**：
> 战吼：选择两名敌方人物，令它们互相攻击一次。若其中一名阵亡，消灭另一名；若两名都存活，王允阵亡，敌方抽 2 张牌。

- **无光环**；8 费 1/8（9 点，基准 17，−8）＋ 2 换 1（≈6~8）≈ **15~17**。
- **失败**：王允阵亡 + 敌方抽 2，是**真代价**（不是“死一个没用的谋臣”）。
- **对冲**：同 R1；但 8 费很慢，对手有更多时间准备高血单位/披坚。
- **适合**：设计者想要“高风险 8 费橙卡/赌徒感”的版本；不适合作为第一版。

### 11.5 R4：6 费 1/6 · 连环计（零引擎弱化版，无硬解）

**卡面**：
> 战吼：选择一名敌方人物，令其攻击另一名随机敌方人物；然后抽 1 张牌。

- **6 费 1/6**（7 点，基准 13，−6）＋一次强制攻击（2~4）＋抽 1（3）≈ **12~14**。
- **零引擎**：只用一个 `force_attack` + `draw`；没有硬解、没有斩杀、没有死亡失败。
- **适合**：如果不想为“双选/斩杀”加引擎，这是最稳的弱化版；但“连环”感最弱。

### 11.6 引擎成本（R1~R3）

需要 2 个小扩展（不是零改动）：
1. **`force_attack.victim_pick: 1 | 2`**：让“第一个选定目标”攻击“第二个选定目标”（反之亦然）。
   当前 `force_attack` 的受害者是**随机/最高血**，不能精确指定第二个目标。
2. **`chosen2_dead`**：`chosen_dead` 的姊妹条件，判断“第二个选定目标是否已阵亡”。
   R1/R3 的“计败自毁”和 R1/R2 的“斩杀幸存者”都靠它。
3. （可选）若不想加 `victim_pick`，可以新造 `duel_between` 动作（两个目标互相真实普攻），
   但这是一整个新动作，成本更高；`victim_pick` 更小、更通用。

按铁律：先改 `docs/gdd/13-balance-data-model.md`（动作/条件表），再改 `core`，再补 ADR 与测试。
**如果坚持零改动 → R4**（随机离间，无硬解）。

### 11.7 对比

| 版本 | 费/身板 | 核心 | 引擎 | 强度（≈） | 失败代价 | 适合 |
|---|---|---|---|---|---|---|
| **R1** | 7 费 1/7 | 双选决斗 + 斩杀幸存者 + 阵亡 + 光环 | +2 扩展 | 16~18 | 阵亡 + 光环丢失 | 要“死亡风险”的橙卡 |
| **R2 ⭐** | 7 费 1/7 | 双选决斗 + 斩杀幸存者 + 光环 | +2 扩展 | 16~18 | 计不成（不斩杀） | **最稳、最推荐** |
| **R3** | 8 费 1/8 | 双选决斗 + 斩杀幸存者 + 阵亡 + 敌方抽 2 | +2 扩展 | 15~17 | 阵亡 + 敌方抽 2 | 高风险 8 费赌徒 |

- R2 正面回答“王允阵亡不是代价”：不让他死，失败=计不成；
- R1 保留死亡风险，但用光环让死亡有代价；
- R3 是 8 费高风险版；
- R4 是不改引擎的弱化版。

## 12. 考证稿回来后：弃用「连环计/离间」，改「隐忍 + 诛国贼」（2026-10-20 定稿方向）

`docs/research/qun-wangyun.md`（877 行，A44/B13/C11/D22，§9 陷阱 22 条）回来了。结论很明确：

- **「连环计/离间」不能做**：① 正史无「连环计」之名（**C**）；② 「让敌人打敌人」是**贾诩**（离间计 50% 强制攻击）和**周瑜**（拼点离间）的轴；③ **贾诩恰恰是劝李傕/郭汜反攻长安、间接害死王允的人**——把仇人的招牌给受害者，既撞轴又反讽。
- 你想要的「**设局 → 敌人有一回合反制 → 失败王允死**」这个**玩法特点**可以保留，但桥段换成 A 级的「**隐忍 + 诛董卓**」：
  - **隐忍**：A-11「允矯情屈意，每相承附，卓亦推心，不生乖疑」——先示弱，再动手；
  - **诛董卓**：A-12/A-29/A-35 合谋诛卓（王允是策划者，不是动手的人）；
  - **失败**：A-21「臨難苟免，吾不忍也」——王允选择死，不死于董卓，而死于李傕/郭汜。

### 12.1 最推荐：7 费 1/7 · 王允「隐忍 / 诛国贼」

**卡**：王允 · 群 · **谋臣** · **7 费 1/7** · `rarity: elite`（橙） · 无关键词

**卡面**：
> 战吼：本回合王允不能攻击；选择一名费用 ≥5 的敌方人物，将其标记为「国贼」。
> 下个己方回合开始时，若王允存活，消灭它；若王允阵亡，此计作废。

**为什么它比 5 费连环计弱、但更有“王允感”**：
- 5 费版是**即时**硬解 + 两次强制攻击，太灵活；这版是**延迟**硬解：敌人有**一整个回合**去杀王允（1/7 墙）或给目标上披坚/净化/夺控。
- **失败 = 王允阵亡**这次是**真代价**：王允不是“战吼完就没用”，他的**存活**就是下回合斩杀的触发条件；1/7 的身板必须活过一个敌方回合。
- 目标限定**费用 ≥5**，不是任意敌人；对低费铺场是白板（7 费 1/7），对 9 费吕布/8 费关羽是“定时炸弹”。

**DSL（零代码；只加 1 个状态 + 1 张卡）**：
```yaml
# data/statuses.yaml
- id: guo_zei
  name: 国贼
  kind: debuff
  numeric: false
  scope: character
  timing: 3
  duration: permanent
  memo: "下个己方回合开始时，若王允存活，消灭此人物"

# data/cards.yaml
- id: qun_wangyun
  name: 王允
  faction: qun
  type: strategist
  cost: 7
  attack: 1
  health: 7
  rarity: elite
  memo: 7 费 1/7：标记一个高费敌人，下回合若王允还活着就消灭它
  gender: male
  keywords: []
  skills:
  - id: yin_ren
    name: 隐忍
    kind: trigger
    trigger: on_play
    text: 战吼：本回合王允不能攻击；选择一名费用 ≥5 的敌方人物，将其标记为「国贼」。
    effects:
    - action: apply_status
      status: jin_gong
      duration: 1
      target: { source: true }
    - action: apply_status
      status: guo_zei
      target: { side: enemy, filter: { type: character, cost_min: 5 }, count: 1, mode: choose }
  - id: zhu_guo_zei
    name: 诛国贼
    kind: trigger
    trigger: turn_start
    text: 己方回合开始时：若场上有「国贼」，消灭它，然后移除标记。
    effects:
    - action: destroy
      target: { side: enemy, filter: { type: character, has_status: guo_zei }, count: 1, mode: random }
    - action: remove_status
      status: guo_zei
      target: { side: enemy, filter: { type: character, has_status: guo_zei }, count: all }
    - action: remove_status
      status: guo_zei
      target: { side: ally, filter: { type: character, has_status: guo_zei }, count: all }
  - id: ci_ji_zuo_fei
    name: 此计作废
    kind: trigger
    trigger: on_death
    text: 亡语：此计作废，移除「国贼」标记。
    effects:
    - action: remove_status
      status: guo_zei
      target: { side: enemy, filter: { type: character, has_status: guo_zei }, count: all }
    - action: remove_status
      status: guo_zei
      target: { side: ally, filter: { type: character, has_status: guo_zei }, count: all }

```
- **引擎**：`turn_start`（7 张卡在用）、`on_death`（29 张）、`destroy`（马岱/周仓）、`remove_status`（华佗）、`apply_status`、`has_status`、`cost_min`、`jin_gong` 全是现成能力；**零代码**，只加一个状态数据 + 一张卡。
- **强度**：7 费 1/7 = 8（基准 15，**−7**）＋延迟消灭一个费用 ≥5 的目标（≈5~7，若王允活过敌方回合）≈ **13~15**；贴线。
  - 若偏强：目标费用 ≥6，或 8 费；
  - 若偏弱：6 费 1/6（更容易被解，但更早出场），或目标任意人物。
- **对冲**：
  - 敌方回合内**杀掉王允**（7 点伤害/硬解）→ 亡语移除标记，计败；
  - 给目标**披坚/免伤**（`destroy` 是 9999 点伤害，披坚吸收）→ 计败；
  - **净化/驱散**「国贼」，或**夺控/回手/变形**目标 → 标记失效/目标不在敌方；
  - 敌方不铺费用 ≥5 的人物 → 王允只是 7 费 1/7 白板。
- **史料**：
  - **B-12（B1，后汉书 卷66）**「允矯情屈意，每相承附，卓亦推心，不生乖疑」——隐忍、示弱；
  - **A-06（A，三国志 卷七）＋ B-13（B1，后汉书 卷66）** 王允与士孙瑞、吕布等**合谋**诛卓——他是策划者，不是动手的人；
  - **B-22（B1，后汉书 卷66）**「臨難苟免，吾不忍也」——城破不退，选择死；
  - **B1（后汉书 卷66）**「剛稜疾惡」「不循權宜」——“国贼”标签的严厉，以及他性格的两面。
- **C/D 边界**：**不采用**貂蝉/连环计/凤仪亭/跳楼/义父（C）；**不采用**“离间”（贾诩/周瑜的轴）。`费用 ≥5` 与「国贼」是游戏抽象，不是史料原文。

### 12.2 备选 A：5 费 1/6 · 不赦（封锁治疗）

- **卡面**：光环：敌方人物不能恢复生命（王允离场即失效）。
- **史料**：**A-32**「王允以為一歲不可再赦，不許之」——不给第二次机会；这是长安城破的直接导火索。
- **引擎**：**需补 1 个 cap `block_heal`**（`healTarget` 里检查；状态 `bu_she` 带 `caps: [block_heal]`）——不是零改动；按铁律先改 GDD 10/13 + ADR。
- **强度**：5 费 1/6 = 7（基准 11，−4）＋禁疗光环（≈2~4）≈ **9~11**；贴线。
- **对冲**：杀王允（光环失效）；不依赖治疗；`immune_debuff` 不吃标记。
- **为什么是备选**：它是“不赦”的直译，与华佗正面对冲；但需要改引擎，且没有你要的“失败=王允死”的戏剧性。

### 12.3 备选 B：6 费 1/6 · 死后遗策（亡语增益）

- **卡面**：亡语：己方全体人物 +1/+1。
- **史料**：**A-21**「臨難苟免，吾不忍也」＋**A-34**「允窮蹙乃下」——城破不退，死后留遗策。
- **引擎**：**零改动**（`on_death` + `modify` 全体友军）。
- **强度**：6 费 1/6 = 7（基准 13，−6）＋全体 +1/+1（≈4~6）≈ **11~13**；贴线。
- **对冲**：不杀王允 → 他只是一个 1/6 墙；杀他 → 触发亡语；对手要算“杀不杀”。
- **为什么是备选**：它把“死亡”做成**收益**而不是失败，与陈宫“替人挡伤”不撞；但没有“延迟/失败”的戏剧性，偏功能。

### 12.4 备选 C：6 费 1/5 · 合谋（协同）

- **卡面**：战吼：选择一名友方人物，本回合其攻击力 +2，且额外攻击一次。
- **史料**：**A-12/A-29/A-35** 合谋——王允不是独行侠，他的高光是“联合别人”。
- **引擎**：**零改动**（`modify` + `extra_attack`）。
- **强度**：6 费 1/5 = 6（基准 13，−7）＋一次额外攻击/+2（≈4~6）≈ **10~12**；略低，可 6 费 1/6（7，−6）→ 11~13。
- **对冲**：没有友军 / 友军被解 → 空放；额外攻击会被架盾/反击。
- **为什么是备选**：最“合谋”的直译，但它是辅助/combo，不是“设局杀国贼”的主轴。

## 13. 设计者最终定稿（2026-10-21）：4 费 1/4「密谋诛恶」

> 本节覆盖 §12 的 7 费「隐忍+诛国贼」方案；§12 保留为备选。最终卡已入库 `data/cards.yaml`。

**卡**：王允 · 群 · 谋臣 · **4 费 1/4** · `rarity: elite` · 无关键词。

**技能**：`密谋诛恶`（战吼）。

**卡面**：
> 战吼：依次指定两名敌方人物，令第 1 个目标立即对第 2 个目标发起一次普通攻击；交锋后，若这两名人物中仍有存活者，王允阵亡，且己方主公受到其中攻击力最高者等量的伤害。

**实现**：新增 `scheme_duel` 动作（ADR-180）；`target.count/pick: 2` 选两名；第 1 个（`ctx.chosen`）攻击第 2 个（`ctx.chosen2`）；`resolveAttack` 走真实普攻（含反击/亡语/攻击触发）；`survivor_condition: any`；`self_destruct` 用 `killUnit`（真实阵亡，披坚无效）；`lord_damage: max_attack`（存活者最高攻击）。

**⚠️ 口径**：`any` = **至少一名**存活。普通攻击的反击是**同时结算**（ADR-062），目标死了也会反击：**双方攻击力都 ≥ 对方生命 → 双方同时阵亡 → 没有存活者 → 不触发**（4 费大杀器的上限：0 代价 2 换 1）；只死一个或两名都存活 → 触发（王允阵亡 + 主公掉血）。若本意是“两名都存活（一个都没死）才惩罚”，改 `survivor_condition: both` 即可（动作支持，测试覆盖）。

**强度/定位**：4 费 1/4 = 5（基准 9，**−4**）——前期很脆，几乎不能站场；后期是一张**大杀器**：两个高攻低血敌人互殴，双方同归于尽时 **0 代价 2 换 1**；只死一个则王允阵亡 + 主公掉血，这是下限。若偏强：5 费 / 1/3 / 提高主公伤害；若偏弱：`both`（死一个就无代价）/ 去掉 `self_destruct`。
