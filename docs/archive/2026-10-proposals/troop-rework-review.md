## 一、为什么做这个改造

对战前中期压力不足、无脑拖后期容易赢。核心问题是**普通兵鸡肋 + 低费缺强力牌**，解法是给 4 个基础兵加"升变"机制、并按史实重做特种兵。

改造过程中发现三个系统级问题，一并修了（见第二节）。

## 二、机制层改动（3 项 + 1 个 bug 修复）

### 2.1 引擎：受伤侧首次能感知伤害属性 ⭐ 最重要

**问题**：`damage_type` 字段此前**只在发起伤害时被读取**（用于水攻加成），`dealDamage()` 的函数签名里根本没有属性参数。**受伤侧完全不知道伤害来源是火还是水。**

这导致"藤甲：物理 −1、火 +1"这类**减伤效果在架构上无法实现** —— 不是没写，是写不了。（GDD 17 早就把它标为 ⚠️ 待办）

**解法**：

| 改动 | 位置 |
|---|---|
| `dealDamage()` 新增 `damageType` 参数（缺省 `physical`） | `core/src/mutate.ts` |
| 新增 cap `reduce_physical` / `vulnerable_fire` / `thorns` | `core/src/constants.ts` |
| 效果伤害透传 `eff.damage_type` | `core/src/effects.ts` |

**关键设计**（减伤归零时的处理）：

```
减伤归零 → 只发 0 伤事件并 return
        → 不进后续击杀/免死/升级进度判定
```

避免"伤害被减到 0 却仍触发免死"这类幽灵判定。

### 2.2 引擎：`zhong_du` 改按火属性结算

该状态在卡池里**只被三张火属性卡用作"灼烧"**（荀攸/陆逊/董卓），**没有任何卡把它当毒用**。原先回合结算硬编码为 `dealDamage(…, '中毒')` 且不带属性，导致藤甲吃不到灼烧伤害。已改为 `fire`。

### 2.3 修一个从未被触发的引擎真 bug

`thorns`（反伤）的原实现有个提前 `return`，**跳过了免死与击杀判定**：

```
实测：20 点伤害打 6 血白毦兵 → hp 扣到 −14 却仍留在场上不死
```

这个路径在 ADR-110 删掉藤甲反伤层后一直休眠（无卡使用），所以 322 个测试无一暴露；白毦兵作为首个使用者才踩到。

**修法**：反伤块移到 `DAMAGE` 事件之后、免死/击杀判定之前，去掉提前返回；反伤传 `killerRef: null` 防止双向 `thorns` 递归。

### 2.4 「圣盾」统一改名「披坚」

状态显示名 `伤害免疫` → `披坚`（原「圣盾」在 ADR-103 已删关键词，只剩内部状态名）。4 张卡文案同步：关平 / 诸葛亮 / 曹仁 / 宿卫虎士。

## 三、特种兵改动清单（9 张）

### 3.1 藤甲兵（蜀·盾）—— 本轮机制锚点

| | 改前 | 改后 |
|---|---|---|
| 卡名 | 板楯蛮 | **藤甲兵** |
| 费用 | 2 | **3** |
| 身材 | 1/3 | **2/4** |
| 关键词 | 架盾 + **剧毒** | **架盾** |
| 技能 | 无 | **藤甲**（光环） |

**藤甲**：受到普通攻击/无属性伤害 −1（最低 0）；受到火属性伤害 **+1**

> **为什么改**：原「板楯蛮 + 剧毒」把史实特色（賨人**以木板为盾**、藤甲"刀枪不入、遇火即燃"）换成了游戏化的剧毒。ADR-110 又删掉了"火伤反弹"层 —— 因为它挂在火分支上会**惩罚用火克制藤甲的正确行为**，与设计意图相反。
> **卡名从「藤甲盾」改「藤甲兵」**：演义 IP 本名。

### 3.2 丹阳兵（蜀·步）—— 白板 → 有机制

| | 改前 | 改后 |
|---|---|---|
| 费用 | 2 | **3** |
| 身材 | 4/4 | **3/3** |
| 技能 | **无（全池唯一白板）** | **袍泽**（亡语） |

**袍泽**：阵亡时，己方其他【**步兵**系】单位永久 +1/+1

> **为什么这么设计**：① 原卡是 33 张里唯一没有机制的卡，既超模又是升变陷阱选项（8 个目标里选一张白板）；② 关键在**放宽触发条件**——写"其他丹阳兵"要求场上凑 2 张同名卡，实际很难触发；改成"其他**步兵系**"后，步兵是 1 费基础兵、副本上限 3，天然常驻 1-3 个，且升变目标里的 8 种步兵系特种兵全部适用；③ 史实：丹阳兵是**地域兵源**（陶谦拨四千助刘备、孙氏长期雇佣），"同乡阵亡、袍泽得 strength"贴合其雇佣兵集团的内核。
> **实现依赖**：`TargetFilter.troopKind` 过滤（`effects.ts:197`）——全池 38 张 `type: troop` 里只有 10 张是 `infantry`，**这条已加测试锁住"不得波及其他兵种"**。

### 3.3 无难兵（吴·盾）—— 修番号归属错误

| | 改前 | 改后 |
|---|---|---|
| 卡名 | **青巾兵** | **无难兵** |
| 费用 | 2 | **3** |
| 关键词 | 架盾 + **先攻** | **架盾** |
| 技能 | 无 | **赴难** |

**赴难**：己方主公生命值**低于**敌方主公时，攻击力 +1

> **为什么改**：「青巾」是**黄巾军**标志（张角"著黄巾"），安在东吴是常识性错误。改用《三国吴兵考》坐实的吴国中央宿卫番号「无难」（陈武传/孙权传注引《吴历》/孙和传/晋书周处传），含义是"其兵精锐，战无所难也"。
> **去掉先攻**：原"架盾 + 先攻"本身别扭（先攻进攻、架盾防守互相打架），且史料里无难兵**全部用于宿卫和平叛**，无一处抢攻记载。
> **与青州兵的刻意区分**：两者同模板（`on_attack` + `lord_hp_vs_enemy` + `attack_bonus`）但**条件取反** —— 青州 `>`（顺风、输出位 3/3 步兵）、无难 `<`（逆风、扛线位 2/4 架盾）。已加测试锁住二者不串味。

### 3.4 武卫营（魏·盾）—— 补上一个真实机制缺口

| | 改前 | 改后 |
|---|---|---|
| 费用 | 2 | **3** |
| 身材 | 2/4 | **2/5** |
| 技能 | **无** | **虎帐**（光环） |

**虎帐**：己方主公受到的伤害由自己承受，自身阵亡后保护消失

> **它填的是真缺口**：架盾规则写在 `legalTargets`（`rules.ts:123`），**只约束普通攻击的目标选择**。卡牌效果造成的**直击主公伤害不经过它** —— 全池有 **15 处**效果可直击主公（张辽/虎豹骑/敢死营/楼船军/陈武/诸葛瑾/周瑜…），此前**只有吴国车下虎士能挡**。武卫营让魏国玩家也有护卫手段。
> **与车下虎士的分层**：车下虎士 3/4 **无架盾**（专职护卫），武卫营 2/4 **有架盾**（护主 + 挡普攻），不是功能重复。
> **引擎零改动**：`hu_zhu`（`redirect_damage` + `guard_scope: lord`）+ `findLordGuard`（`mutate.ts:70`）+ 主公受伤先判护主再扣血（`mutate.ts:275-281`）——**"持续承伤直到阵亡"已原生支持**。实测：主公受 2 伤×2 → 守护者 4 血耗尽阵亡，第 3 次主公才开始掉血。

### 3.5 虎卫盾 / 宿卫虎士（魏）—— 正名

| 卡 | 改动 |
|---|---|
| **虎卫盾**（盾） | 2费 1/7 → **3费 1/6**；技能名「虎卫」→ **「卫主」** |
| **宿卫虎士**（步） | 技能名「虎卫」→ **「虎士」** |

> **降血理由**：7 血 + 架盾强制嘲讽 + 亡语回血是**三重叠加**，几乎无法被解。
> **正名依据**：《许褚传》"诸从褚侠客，**皆以为虎士**"、**"武卫之号，自此始也"**；《典韦传》"其将皆选卒，**每战常先登陷陈**"。史实上「虎士/宿卫虎士/武卫营」三者同源 —— 典韦率先登陷阵的帐前亲兵 → 许褚部皆称虎士 → 渭南战后改建武卫营。
> 原先两张卡技能名都叫"虎卫"，现按史实分工。

### 3.6 白毦兵（蜀·盾）—— 新增 thorns 的首个使用者

| | 改前 | 改后 |
|---|---|---|
| 费用 | 2 | **3** |
| 技能 | 无 | **忠勇**（光环） |

**忠勇**：受到**普通攻击**并实际受伤后，对攻击者额外造成 1 点伤害（与自动反击**分开结算**；技能伤害不触发）

> 史实据《三国志·杨戏传》陈到"俱以忠勇称"。沿用 ADR-110 释放的 `thorns` cap —— 也正是它踩出了 2.3 那个引擎 bug。

### 3.7-3.9 火属性伤害补全（三阵营各一名）

**先修数据漂移**：全池文案写着"火伤"的卡**大多没有 `damage_type: fire`** —— 火攻策略卡、火烧洛阳、陆逊「策火流云」三条全缺，导致**通用火攻卡无法作为藤甲的反制手段**（会被当成无属性伤害减掉）。已补齐。

火属性原本 **100% 集中在吴国**（潘璋/蒙冲斗舰/陆逊），藤甲作为蜀国目标时其他阵营无解，故每阵营补一名：

| 阵营 | 人物 | 技能 |
|---|---|---|
| 魏 | **荀攸** 4费1/4 | **乌巢袭粮**：战吼对敌方随机 2 名**受伤**单位各 2 点火伤 + 1 回合灼烧（建安十年荀攸力主许攸之谋夜袭乌巢） |
| 蜀 | **黄权** 3费1/3 | **断后**：受创时对敌方全体 1 点火伤（猇亭之战陆逊火烧连营，黄权率部断后） |
| 群 | **董卓** 5费3/6 | **暴虐**：己方有女性则生命上限 +2，对敌方全体**男性**施加 2 回合灼烧 |

**张角「五雷轰顶」按设计者要求保留不动。**

**董卓技能名的避合规过程**（值得注意）：
- 「酒池肉林」出自《史记·殷本纪》**商纣王**，与董卓无关 → 不可用
- 「淫乐纵恣」（《三国志》原词）→ **过不了审**
- 最终用《三国志》原词的「**暴虐**」，flavor 里的"性多欲/帷帐至于内寝"一并收敛

**黄权维持谋臣 1 攻**：`validate` 的「谋臣攻击力上限 1」拦住了 2 攻（报 error），设计者裁定**不改类型**。

## 四、费用下限规则（ADR-112）

设计者提出「特种兵费用 ≥ 对应基础兵 +1」，修正为「**下限 + 总价值**」而非僵硬等值，以兼容 ADR-007「费用绑定总价值」。

**数据核查**：基础兵 步兵1 / 盾兵2 / 弓兵2 / 骑兵3 费，而改造前 33 张特种兵**全部标 2 费**：

| 兵种 | 合规率 |
|---|---|
| 步兵 | 8/9 ✅（说明当初就是这个思路） |
| 盾兵 | 6/8 ❌ |
| 弓兵 | 0/9 ❌ |
| 骑兵 | 0/7 ❌ |

**不能僵硬套用的三个反例**：白马义从（中立 1/2 白板会被抬到 3 费）、无当飞军（0/2 → 3 费）、木牛流马（0/6 运输车 → 4 费）。

> **本轮只改 6 张**（藤甲兵/丹阳兵/无难兵/武卫营/虎卫盾/白毦兵）。**剩余 24 张由设计者另行逐个过。**

## 五、测试（311 → 329，+18）

| 模块 | 覆盖点 |
|---|---|
| 藤甲 | 减伤 / **减伤下限不得为负** / 火弱 / 水攻照常 / **状态驱动而非卡 id 驱动** |
| 无难兵 | 逆风加成 / 顺风**不加成** / 与青州兵**不串味** |
| 丹阳兵 | 亡语生效 / **不得波及其他兵种**（盾/骑/弓） |
| 武卫营 | 承伤 / **耗尽后失效** / **护的是"架盾挡不住的效果伤害"** / 只护己方主公 |
| 白毦兵 | 普攻合计回敬 3（反击 2 + 忠勇 1）/ **技能伤害不触发** / 被打死也照样回敬 |

### 踩到并已记录在注释里的坑

1. **`TargetRef` 是带 `kind` 判别字段的联合类型** —— 写成 `{side,row,col}` 会被 `ref.kind !== 'unit'` 判否、`dealDamage` 第一行返回 0。症状是「减伤完全不生效」，**极难定位**。
2. **`applyAction` 返回克隆的 state** —— 断言须读 `r.state` 而非 `state`。
3. **`scenario()` 只认卡池里已注册的 id** —— 测试卡必须先 `ctx.cards.set` 再 `setUnit`。
4. **光环不会随 `setUnit` 自动挂载** —— 必须显式调 `recomputeAuras`，否则状态根本没挂上（症状是全部减伤测试静默失败）。
