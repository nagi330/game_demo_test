### 1.1 陷阵营 —— 技能与史实完全相反
- [ ] **定稿触发时机**：`enemy_turn_end` → 建议改 `on_attack`
  - 现状：每个敌方回合结束**被动永久** +1/+1（无 `duration` = permanent）
  - 史实：《英雄记》"每所攻击**无不破者**"；高顺"陷阵之志，有进无退"、每战身先士卒
  - 问题：把"勇猛冲锋"做成了"站着不动越等越强"，是**"无脑拖后期"的机制化身**
  - 备选：改回"击杀后成长"（设计稿原案）/ 保留回合成长但设**硬上限**（最多 +3/+3）
  - 影响：第 6 回合成为 7/9 架盾，第 10 回合 13/15，一击打死场上任何单位
- [ ] 改完后重测数值曲线

## 五、🟡 体系级遗留（超出本轮，但影响判断）

- [x] **已定规则（ADR-120）：特种兵不得做「全体加属性」的光环**
  - 原因：光环按**同名份数独立叠加**（`effects.ts:404-419` 每个光环来源各结算一次），而 `type: troop` **同名可放 3 张**（ADR-065）
  - 实测：3 张 2 费 2/2 光环兵 → 各自 **5/2**、黄巾兵 1/1 → **4/1**，**6 费换 15 点攻击**（已写成回归测试）
  - 现有**全体**光环都在**独一无二的人物卡**上（马岱／沙摩柯／于禁／蒋钦）；troop 的光环一律**只作用于自己**（武卫营／白毦兵／藤甲兵／无当飞军）
  - 特种兵要给"配合"，走 `target: { source: true }`（**只作用于自己**，如「黄巾众」）或**不碰属性**的路子
- [x] **已补的引擎能力（ADR-121）：召唤也派发 `on_play`**
  - 原先只有 `playCard` 与 `upgradeUnit`（ADR-114）派发；`summon` 完全不派发 → 被召唤的单位拿不到自己的战吼
  - 改动前扫描全池被召唤的 10 种单位：**没有一张带 `on_play`** → 属"主动声明才生效"的低风险改动
  - 首个使用者：黄巾兵「黄巾众」（落地按当时统领数永久成长）
- [ ] **⚠️ 清理 `back` 行（ADR-051 遗留）** —— 战场现在是一行 8 格，`back` 行是死数据

  - ⚠️ `npm run ai:report` 的数据**完全不反映新兵种系统**，不能作为平衡依据
