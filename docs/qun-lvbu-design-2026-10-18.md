**定稿口径（实现里钉死的两条）**：
1. **先结算相邻 3 点伤害，再挂震慑；且只有主目标（被 5 点打的那个人）阵亡才挂**；相邻 3 点造成的击杀**不触发**（设计者 2026-10-18 确认）。

## 0. 先算账：8/8 意味着什么

| 项 | 数值 |
|---|---|
| 属性点 | 8 + 8 = **16** |
| 9 费基准 | 2×9+1 = **19** |
| 身体偏差 | **−3**（身板吃掉 16 点，剩 ≈3 点给技能） |
| 同费对照 | 曹真 9 费 4/6（−9，团队 +1/+1）；司马懿 9 费 1/10（−8，延迟清场） |
| 全池身材对照 | 关羽 8 费 7/7（14）、曹仁 10 费 5/8（13）、曹丕 8 费 4/8（12）；**8/8 = 16 会是全池最大身材** |

**结论**：8/8 是“高身材、低技能预算”的路线 B。严格贴线只该给 **≈3 点**技能；
定稿的「5+3+3＋条件震慑」约 **7~9 点**，合计 **23~25**（+4~6），属于 `elite` 终结卡的强度。
它不是无解：对手把阵型拉开（隔一格站）或把主目标换成 6+ 血，技能就只剩 5 点单体。
**设计者已定稿 8/8，不再改身材；强度杠杆放在数值/条件上（见定稿节）。**

## 1. 「一骑当千」还是「天下无双」？

| 名字 | 语义 | 适合的机制 | 风险 |
|---|---|---|---|
| **一骑当千** | 一个人冲进千军万马 | **对多**：连续攻击/清扫小兵/越打越多 | 对 token 卡组可能过强；对大哥卡组可能空放 |
| **天下无双** | 天下没有第二个对手 | **对单**：决斗/单挑/无人能挡 | 容易和许褚「虎痴」的决斗撞轴；单次决斗的“强”是数值强，不是玩法强 |

**我的建议**：
- **主推「天下无双」**——它更贴“武力最强”这五个字，而且“1 挑 2”的决斗能直接制造名场面；
- **「一骑当千」做成备选/第二形态**——它更贴“一人成军”，但需要控制目标数，否则会变成 token 清场器。
- 两者都不需要「先攻」：决斗是**一次挑战动作**，一骑当千是**多目标攻击**，都不是“永久先结算伤害”的关键词。

## 2. 四个方案

### 定稿前方案：天下无双（双决斗）

- **卡**：吕布 · 群 · 武将 · **9 费 9/8** · `rarity: elite` · 无关键词
- **技能**：`天下无双`（战吼）
- **卡面文案**：
  > 战吼：依次与至多两名敌方人物决斗（双方各进行一次真实普攻）。
- **DSL 形状**：
  ```yaml
  skills:
  - id: tian_xia_wu_shuang
    name: 天下无双
    kind: trigger
    trigger: on_play
    text: 战吼：依次与至多两名敌方人物决斗（双方各进行一次真实普攻）。
    effects:
    - action: duel
      target: { side: enemy, filter: { type: character }, count: 1, mode: choose, pick: 1 }
    - action: duel
      target: { side: enemy, filter: { type: character }, count: 1, mode: choose, pick: 2 }
  ```
- **史料**：
  - **A-02**（卷七）：「布便弓马，**膂力过人**，**号为飞将**」——武力与骑射的底子；
  - **B-03**（裴注引《英雄记》）：「郭汜在城北。布开城门，将兵就汜，言『且却兵，但身决胜负』。汜、布乃**独共对战**，布以矛刺中汜，汜后骑遂前救汜，汜、布遂**各两罢**。」
    ——**吕布相关史料中唯一一条单挑记载**；它证明“吕布敢单挑、且先刺中对手”，但结果是**没分出生死**，
    **不能写成“单挑无敌”**。本卡的“双决斗”是游戏化放大（1 挑 2），不是史实原样。
  - **A-11 / A-12**（卷七）：辕门射戟「布举弓射戟，**正中小支**。诸将皆惊，言『将军天威也』！」；
    「布性不喜合鬬，但喜解鬬耳」——一人到营门、一箭定和战，是“单人压场”的最强名场面。
  - **A-18**（卷七篇末陈寿评）：「吕布有**虓虎之勇**，而无英奇之略，轻狡反覆，唯利是视。」
    ——史书对吕布勇武**最接近的原话**；本卡只取“勇”，不取“略”。
  - **C**：三英战吕布（毛本第 5 回，正史无载）——“一人对多名顶级武将”的名场面；
  - **D**：「天下无双」是后世/游戏常用称号，**不是《三国志》对吕布的原话**，`note` 必须标 D。
  - ⚠️ **不能写**：单挑无敌 / 天下第一 / 万人之敌（万人之敌是关张，卷 36）/ 三英战吕布是正史 / 貂蝉是正史。
- **引擎**：**零改动**。`duel` 已实现（许褚「虎痴」在用）；`PLAY_CARD.target2` / `TargetSelector.pick: 2` 已支持；
  原型 `playTargetPlan` 已有 `pp.picks[2]`，AI 的 `PlanCombo` 也支持双目标。
  ⚠️ 需补测试 + UI 约束：两个目标必须是**不同**单位。若 UI 没传 `target2`，第二段 `pick: 2` 的 `pickOf`
  会回退到 `chosen`；若第一个目标已被第一段打死、不在合法池里，`mode: 'choose'` 会走**兜底**
  `narrowByMode → pool.slice(0, 1)`，即“自动打下一个合法目标”。所以：
  **(a)** 原型/AI 必须收集两个不同目标；**(b)** 测试要钉住“只传一个目标时第二段的行为”，
  避免日后被当成“指定了两个”的假象。
- **强度**：身体 17 + 两次决斗（通常 1~2 个击杀）≈ **21~23**，比基准 19 **高 2~4**。
  这是“精英终结卡”的强度；若实测过强，杠杆按顺序：
  ① 只决斗 **1 名**（回到 20~21，贴线）；② 第二段决斗的目标限制为**攻击力 ≤5**（`attack_max: 5`，不打最强的大哥，但这会削弱“最强”的气质，慎用）；
  ③ 决斗前吕布攻击力 **−2**（7 点，仍能杀 4~6 血，但打不过 7/7 关羽——不推荐，违背“武力最强”）。
- **对冲**：
  - **披坚**（免疫一次伤害）：第一次决斗被吸收，目标活下来并反击，吕布可能掉 5~7 血；
  - **高血量**：司马懿 1/10 能吃下 9 点，剩 1 血反击；曹仁 5/8 吃 9 点会死，但如果有护甲/减伤就能活；
  - **藤甲**：物理 −1，9→8，仍能杀大多数，但对 9 血单位会留 1 血；
  - **免伤/免疫**：直接让一次决斗空掉；
  - **只留一个人物**：第二段决斗没有合法目标，等于只打一次。
- **为什么最推荐**：
  - 它是四个方案里**最像“武力最强”**的：不是“先攻”这种永久数值，而是“我点名两个，你们一起上”；
  - 它给对手留了**明确的构筑/站位反制**（披坚、高血、藤甲、少留人），不是无解；
  - 它和“群 · 飞将无双”的单核思路一致：吕布落地先拆两个威胁，高顺/陈宫负责保大哥；
  - 它不需要新引擎能力，落地风险最低。
- **⚠️ 与许褚的区分**：许褚「虎痴」是 **6 费 5/6、每局一次、单目标**；吕布是 **9 费 9/8、每次战吼、双目标**。
  两者共用 `duel` 原语，但一个是“小规模单挑”，一个是“终结级一挑二”，`note` 要写清，避免被当成重复卡。

### 定稿前方案：一骑当千（冲阵，旧版）

- **卡**：同上（9/9/8）
- **技能**：`一骑当千`（战吼）
- **卡面文案**：
  > 战吼：依次攻击至多两名攻击力 ≤3 的敌方人物（每次都是真实普攻；吕布阵亡即停）。
- **DSL 形状**：
  ```yaml
  skills:
  - id: yi_qi_dang_qian
    name: 一骑当千
    kind: trigger
    trigger: on_play
    text: 战吼：依次攻击至多两名攻击力 ≤3 的敌方人物（每次都是真实普攻；吕布阵亡即停）。
    effects:
    - action: attack_each
      target: { side: enemy, filter: { type: character, attack_max: 3 }, count: 2 }
  ```
- **史料**：
  - **A-07**（卷七）：「常与其亲近成廉、魏越等**陷锋突陈**，遂破燕军。」——小股精锐反复冲阵，是“一骑当千”的**行为**依据；
  - **A-20**（《后汉书》卷七十五，A 后出）：「数十骑驰突燕阵，一日或至三四。」——骑兵反复冲击的细节；
  - **A-02**（卷七）：「布便弓马，膂力过人，**号为飞将**」——“飞将”冲阵的底子；
  - **C/D**：「一骑当千」是成语/后世形容，**不是《三国志》对吕布的原话**，`note` 标 C/D；
  - **C**：三英战吕布（演义）——“一人对多人”的名场面，但正史无载。
  - ⚠️ 不能把“陷锋突陈”写成“一人冲阵”；原文是「与成廉、魏越等」**带小队**冲阵，不是单人。
- **引擎**：**零改动**。`attack_each` 已实现（ADR-071，当前**池内 0 张真实卡在用**，只有合成卡测试）；
  `TargetSelector.filter.attack_max` 已实现；`count: 2` 走 `narrowByMode` 的 `slice(0, n)`。
  ⚠️ `attack_each` 直接调 `resolveAttack`，**不走 `legalTargets` 的架盾检查**——它会**无视架盾**。
  这是“冲阵”的合理演绎，但必须在卡面/`note` 写明；如果不想让它无视架盾，就别用这个动作（没有别的多段普攻动作）。
- **强度**：身体 17 + 至多 2 次小兵击杀 ≈ **21~23**；对大单位卡组，技能等于空放，只剩 9/8 白板。
  这是**meta 卡**：对黄巾/铺场强，对大哥/控制弱。杠杆：`count: 2 ↔ 3`、`attack_max: 3 ↔ 2`。
- **对冲**：
  - **攻击力 ≥4 的单位**不在目标池里，完全不吃这个战吼；
  - **披坚**：小兵活下来并反击，吕布可能掉血；
  - **藤甲**：物理 −1，9→8，仍能杀大多数小兵；
  - **少铺场**：只留 1 个小兵，战吼只打 1 次。
- **为什么是备选**：
  - 它是四个方案里**最“一人成军”**的，也最符合“一骑当千”四个字；
  - 但它对卡组类型的强弱太极端（token 杀手 / 大哥卡组白板），不如双决斗稳定；
  - 它把“吕布的强”落在**清杂兵**上，而不是“击败敌方最强”，和“武力最强”的气质有一点偏移。
- **如果设计者想要更史诗**：把 `count: 2` 改成 `count: 3`，或 `count: 'all'`；
  但 9 攻打 3 个 3 攻以下单位通常**一刀一个、不吃反击**，会变成“9 费 9/8 + 清 3 个”，
  建议先按 `count: 2` 实测，再决定要不要放开。

### 定稿前方案：辕门射戟（抉择：解斗 / 射戟）

- **卡**：同上（9/9/8）
- **技能**：`辕门射戟`（战吼，抉择）
- **卡面文案**：
  > 战吼（抉择）：① **解斗**：选择一名敌方人物，直到你的下个回合开始，它不能攻击；② **射戟**：对一名敌方人物造成 4 点伤害。
- **DSL 形状**：
  ```yaml
  skills:
  - id: yuan_men_she_ji
    name: 辕门射戟
    kind: trigger
    trigger: on_play
    text: 战吼（抉择）：① 解斗：一名敌方人物直到你的下个回合开始不能攻击；② 射戟：对一名敌方人物造成 4 点伤害。
    modes:
    - name: 解斗
      effects:
      - action: apply_status
        status: jin_gong
        duration: 1
        target: { side: enemy, filter: { type: character }, count: 1, mode: choose }
    - name: 射戟
      effects:
      - action: damage
        value: 4
        target: { side: enemy, filter: { type: character }, count: 1, mode: choose }
  ```
- **史料**：
  - **A-11**（卷七，原文已核）：「布令门候于营门中举一只戟，布言：『诸君观布射戟小支，一发中者诸君当解去，不中可留决斗。』布举弓射戟，**正中小支**。诸将皆惊，言『将军天威也』！」
  - **A-12**（卷七正文，已核）：「布谓灵等曰：『玄德，布弟也。弟为诸君所困，故来救之。**布性不喜合鬬，但喜解鬬耳**。』」
    ——不是“爱好和平”，是**仲裁/威慑**；前文「便严步兵千、骑二百，驰往赴备。灵等闻布至，皆敛兵不敢复攻」。
  - **C**：方天画戟、貂蝉连环计（演义；正史只作「戟/手戟/一只戟」，无“方天画戟”；貂蝉不见于正史）。
  - ⚠️ **不能写**：吕布射的是“方天画戟”（正史只作“戟”）；吕布爱好和平（A-12 的语境是辕门射戟的仲裁话术）。
- **引擎**：**零改动**。`modes` 抉择（曹彰「猛袭」先例）、`jin_gong`（block_attack）、`damage 4` 都是现成能力；
  UI 已支持 `modeIndex`，目标选择走 `mode: choose`。
- **强度**：身体 17 + 4 伤（2 点）或一回合不能攻击（2~3 点）≈ **19~20**，**贴线**。
  这是四个方案里**最稳、最不像“超模卡”**的一个。
- **对冲**：
  - 解斗只封**普攻**，目标仍可用主动技/战吼；华佗/净化可驱散 `jin_gong`；免疫可挡；
  - 射戟是 4 点物理伤害，披坚/藤甲/免伤都能减；
  - 目标可选“最不重要的那个人”来骗解斗——但这样吕布的 9/8 还在场上，对手还是要解。
- **为什么是备选**：
  - 它是四个方案里**最贴史料**的：辕门射戟是吕布最著名的“一箭定和战”，A 级；
  - 抉择让玩家根据局面选“控”还是“打”，符合“两难”方向；
  - 但它的“强”是控制/灵活，不是“数值上的武力最强”；如果设计者要的是“9/8 的大哥压场”，双决斗更直接。

### 定稿前方案：飞将（无视架盾）

- **卡**：同上（9/9/8）
- **技能**：`飞将`（被动/战吼上状态）
- **卡面文案**：
  > 飞将：吕布攻击时无视「架盾」，可以自由选择攻击目标。
- **DSL 形状**（需要新 cap）：
  ```yaml
  skills:
  - id: fei_jiang
    name: 飞将
    kind: trigger
    trigger: on_play
    text: 飞将：吕布攻击时无视「架盾」，可以自由选择攻击目标。
    effects:
    - action: apply_status
      status: fei_jiang_status
      target: { source: true }
  ```
- **史料**：
  - **A-02**（卷七）：「布便弓马，膂力过人，**号为飞将**」——“飞将”是史书原词，A 级；
  - **A-06**（卷七）：「布有良马曰赤兔。」；**A-20**（《后汉书》，A 后出）：「号曰赤菟，**能驰城飞堑**。」
    ——“飞将 + 赤兔”的机动意象有 A 级底子；
  - 机制是“飞过盾墙”的**设计演绎**，不是史书原句；`note` 要分开写。
  - ⚠️ **不能写**：赤兔是关羽的（赤兔是吕布的，A-06；关羽骑赤兔是演义 C-13）；吕布会“飞”（“飞将”是称号，不是飞行能力）。
- **引擎**：**需补 1 个 cap**（这是四个方案里唯一要改引擎的）：
  1. `StatusCap` 加 `ignore_taunt`（`core/src/constants.ts` + `types.ts` 导出）；
  2. 新状态 `fei_jiang_status`（`data/statuses.yaml` + `constants.ts` 的 `STATUSES`）；
  3. `rules.ts` 的 `legalTargets`：`const shields = hasCap(u, 'ignore_taunt') ? [] : shieldUnits(state, foe);`
     （`lordAttackTargets` 不用改——吕布不是主公）；
  4. GDD 10/13 补 cap 登记；测试钉死“无视架盾”和“不影响其他单位”。
- **强度**：身体 17 + 无视架盾（1~2 点）≈ **18~19**，**贴线甚至略保守**。
- **对冲**：
  - 架盾失效，但**披坚/高血/藤甲/免伤**仍然有效；
  - 对手可以把资源转到“杀吕布”而不是“挡吕布”；
  - 9 费卡落地前，对手有 8 个回合准备。
- **为什么是备选**：
  - 它是四个方案里**最“没有人能挡住我”**的，A 级“飞将”名字也最正；
  - 但它**改引擎**，而且会直接废掉对手的架盾投资——对“架盾”这个核心机制是一次池级冲击；
  - 如果设计者想要“零改动”，可以用一个**零引擎的子变体**：
    > 战吼：对一名敌方人物造成 3 点伤害；若其带有「架盾」，改为 6 点。
    （`bonus_vs_keyword: { keyword: jia_dun, value: 3 }`，现成字段；但这是“破盾狙杀”，不是“无视架盾”。）

## 3. 四个方案横向对比

| 方案 | 方向 | 引擎 | 强度（≈） | 对谁强 | 对谁弱 | 风险 |
|---|---|---|---|---|---|---|
| ⭐ **天下无双**（双决斗） | 单挑/对单 | 零改动 | 21~23（+2~4） | 中速、单核、少单位 | 披坚、高血、藤甲、免伤 | 略超模；与许褚同原语 |
| **一骑当千**（冲阵） | 对多/清场 | 零改动 | 21~23（+2~4） | 黄巾、铺场、token | 大哥、控制、高攻单位 | 对 token 过强，对大哥空放 |
| **辕门射戟**（抉择） | 控制/灵活 | 零改动 | 19~20（0~+1） | 单大哥、需要控场的局面 | 技能型、净化、免疫 | 不够“数值最强” |
| **飞将**（无视架盾） | 穿透/反制 | **需补 cap** | 18~19（0~−1） | 盾墙、架盾体系 | 高血、披坚、法术斩杀 | 池级冲击架盾机制 |

**推荐顺序**：天下无双 > 辕门射戟 > 一骑当千 > 飞将。
- 要“最像武力最强、最有名场面” → **天下无双**；
- 要“最稳、最贴史料、零风险” → **辕门射戟**；
- 要“一骑当千的清场快感” → **一骑当千**（先按 `count: 2` 实测）；
- 要“没有人能挡住吕布” → **飞将**（接受改引擎）。
