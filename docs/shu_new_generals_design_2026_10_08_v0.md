## 2. 可行性核对（**截至 2026-10-08：11 张所需的引擎能力已全部补齐，无卡待改设计**）

### 2.1 ✅ 可直接落地（零改动）

| 卡 | 实现方式 | 依据 |
|---|---|---|
| **罗宪** | 卡面基础关键词 `jia_dun`（架盾）＋ `aura` + `modify +2/+2`，条件 `count(己方人物) == 1` | 同诸葛亮「空城之计」的 `count` 条件；已实测：单独在场 4/8，有友军 2/6。⚠️ 架盾**只能**写成基础关键词（见下方说明） |
| **傅佥** | 亡语 `destroy target {event: 'killer'}` | 华雄亡语「遗计·威震四方」同款先例 |
| **严颜** | 卡面基础关键词 `jia_dun` ＋ 亡语 `damage 3 target {event: 'killer'}` | 同上（亡语能拿到击杀者）；架盾见下方"基础关键词"说明 |
| **董允「直谏」** | `apply_status can_mou stacks 1 target {lord: true}` | **引擎已有 `can_mou`（参谋，caps: `extra_lord_skill`＝主公技次数 +N），全卡池无人使用**；`rules.canUseLordSkill` 与 `engine.ts` 已实现加成次数的判定与消耗 |
| **费祎「息兵」** | `trigger turn_end` + `heal 1 target {ally, character, all}` | 已实测产出 HEAL 事件 |
| **王平** | **战吼** + 两条 `modify`（场上 / 手牌各一条，手牌那条写 `zone: hand`） | 手牌数值修正见 ADR-141；手牌侧按 `card_id: shu_wudangfeijun` 筛（无当飞军没有 tag） |
| **兀突骨** | **战吼** + 两条 `override_status`（场上按 `has_status: teng_jia` 筛，手牌按 `card_id: shu_tengjiabing` 筛），`caps: { reduce_physical: 2, vulnerable_fire: 0 }` | 规则覆盖见 **ADR-142**；端到端测试 `core/test/status-override.test.ts`（11 条）已跑通 |

### 2.2 ✅ 曾需微调 —— **已由 ADR-138 / ADR-139 补齐**（按"现状"列写卡即可）

| 卡 | 原问题 | 现状 |
|---|---|---|
| **朵思大王** | ① 毒攻不自动挂中毒；② 谋臣攻击 ≤ 1（2 攻会被 `validate` 报 error） | ① ✅ **毒攻现在自动挂中毒**（ADR-138，与火攻同一条全局规则）；② ✅ 已改为 **4 费 2/5 武将**（非谋臣），不再受谋臣攻击上限约束 |
| **蒋琬** | `gain_command` 只加**本回合** `cur`，回合末清零 → "回合结束 +1"当回合就失效 | ✅ 新增 `permanent: true`（ADR-139）：**永久抬统率上限**（封顶 10）。⚠️ 触发器要用 **`turn_start`**（"回合开始 +1"）—— 回合开始会把 `cur` 回满，所以只有抬 `max` 才有收益 |
| **杨仪** | `cycle_to_deck` 是"**先**回随机位置、**再**抽 1 张"，顺序与落点都不对 | ✅ 新动作 **`send_hand_to_deck`**（ADR-139）：`to: deck_bottom` + `mode: choose`、**不抽牌**；配一条 `draw 2` 就是"抽二选一、另一张回牌库底" |

### 2.3 ✅ 曾需改引擎 —— **已由 ADR-141 实现**

| 卡 | 曾经不可实现的部分 | 现状 |
|---|---|---|
| **孟获** | ~~① 手牌 +2/+2；② 亡语回手牌；③ 只能触发 6 次；④ 第 7 次给对手~~ | ✅ **四条全部已实现（ADR-141）**。卡面写法：`蛮王` = **战吼**（`trigger: on_play`）+ 两条 `modify`（场上 / 手牌，`exclude_source: true` 不含自己，不写 `duration` = 永久）；`七擒` = 亡语 `self_to_hand { count: 6, value: -1, health: -1, overflow: enemy }`。端到端测试 `core/test/menghuo-recall.test.ts`（9 条）已按此形状跑通 |

> **⚠️ 连带影响（ADR-141 之后）**：上表第 1、2 行的"手牌"半边**不再是引擎限制** —— `modify` 现在可以作用于手牌（写 `HandMod.kind: attack / health`），在**打出时**结算到单位身上。
> 也就是说 **王平「飞军统率」的手牌部分现在可做**，写法与「蛮王」完全一样（**战吼** + 两条 `modify`，手牌那条带 `zone: hand`）——
> 前提同样是**战吼而不是光环**：光环给手牌加成的 mod 带 `auraId`，牌一打出就没了。
> 兀突骨原来剩下的缺口（"**藤甲强化**"这个非数值修饰）**已由 ADR-142 的「规则覆盖」补齐** ——
> `override_status { status: teng_jia, caps: { reduce_physical: 2, vulnerable_fire: 0 } }`，手牌那半同样能带进场。
> 于是**三张统领（王平 / 兀突骨 / 孟获）现在都是"战吼 + 永久 + 场上与手牌都覆盖"的同一套写法**。

**另注（基础关键词：架盾）**：`jia_dun`（架盾）在引擎里**只能写在卡面的 `keywords:` 上**，全池 **20 张**卡都是这么写的（盾兵 / 藤甲兵 / 白毦兵 / 车下虎士 / 武卫营 / 伏楯士 / 徐盛 / 曹昂 / 朱然 / 周仓 / 向宠 / 董厥 / 假人 / 机械守卫 / 无难兵 / 无难右部 / 陷阵盾兵 / 虎卫盾 / 曹洪 / 曹真）；**没有任何动作能动态授予关键词**（DSL 里既没有 `grant_keyword` 也没有 `add_keyword`，`core/src/constants.ts` 的 `ACTIONS` 里查得到）。所以罗宪与严颜的架盾都必须是**基础关键词**，不能写成技能的副效果 —— 写成"「孤城」：架盾，……"在数据上是落不了地的（`npm run validate` 也不会报错，会静默变成一个没有架盾的卡）。

**另注（数值）**：
- **严颜 3 费 2/6 + 架盾**：属性 8 点，架盾按 `13-balance-data-model.md` §3 关键词表记 **−1** → **7 点 = 3 费白板基准（2×3+1）正好打平** —— 相当于用 1 点属性买掉"必须优先被打"的负担，再送一条亡语。亡语只在**被单位击杀**时才有目标（`event: killer` 取不到时空转），有天然折扣，可接受；若实机偏强，建议先降反噬 3 → 2，而不是再动费用。
- **罗宪 4 费 2/6 + 架盾**：8 − 1 = **7 点 vs 4 费基准 9**，**亏 2 点**，换「孤城」单独在场时 +2/+2（+4 属性，但要求场上没有其它己方人物）—— 定位是"守空城的独苗"，数值合理。
