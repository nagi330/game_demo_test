## 2. 可行性核对（结论：4 张直接落地 / 3 张微调 / 3 张需改设计）

### 2.1 ✅ 可直接落地（零改动）

| 卡 | 实现方式 | 依据 |
|---|---|---|
| **罗宪** | `aura` + `modify +2/+2`，条件 `count(己方人物) == 1` | 同诸葛亮「空城之计」的 `count` 条件；已实测：单独在场 4/8，有友军 2/6 |
| **傅佥** | 亡语 `destroy target {event: 'killer'}` | 华雄亡语「遗计·威震四方」同款先例 |
| **严颜** | 亡语 `damage 3 target {event: 'killer'}` | 同上（亡语能拿到击杀者） |
| **董允「直谏」** | `apply_status can_mou stacks 1 target {lord: true}` | **引擎已有 `can_mou`（参谋，caps: `extra_lord_skill`＝主公技次数 +N），全卡池无人使用**；`rules.canUseLordSkill` 与 `engine.ts` 已实现加成次数的判定与消耗 |
| **费祎「息兵」** | `trigger turn_end` + `heal 1 target {ally, character, all}` | 已实测产出 HEAL 事件 |

### 2.2 ⚠️ 需微调（改数据即可）

| 卡 | 问题 | 建议 |
|---|---|---|
| **朵思大王** | ① **毒攻不会自动挂「中毒」**——全局只有火攻自动挂灼烧（ADR-134）；② **校验器规定谋臣攻击 ≤ 1**，2 攻会被 `validate` 直接报 error | ① 效果里显式加 `apply_status status: zhong_du`；② 改 `type: general`（2 攻武将）或攻击降为 1 |
| **蒋琬** | `gain_command` 只加**本回合可用统率**，回合结束清零 —— "每己方回合结束时 +1 统率"当回合立刻失效，收益为 0 | 改为「**回合开始时**己方统率 +1」（每回合 ramp）。若要"统率**上限**永久 +1"，需新增状态 + 改代码 |
| **杨仪** | 现成 `cycle_to_deck` 是「**先**把手牌放回牌库**随机位置**，**再**抽 1 张」，与"先抽、再放回**底部**"顺序与落点都不同 | ① 改成"将一张手牌放回牌库随机位置，然后抽一张牌"（零改动）；② 或新增 DSL 动作 `to_deck_bottom`（改代码） |

### 2.3 ❌ 需改设计或改引擎

| 卡 | 不可实现的部分 | 原因（代码位置） | 替代方案 |
|---|---|---|---|
| **王平** | "**手牌里**的无当飞军 +1/+1" | `HandMod` 只支持 `cost` / `ban` 两种；`modify` 遇非场上目标直接 `continue`；`applyStatus` 明确 `if (ref.kind === 'hand') return` | 保留"场上"部分（✓）；"手牌"改为**从牌库发现/召唤一张无当飞军**，或只做场上全体 +1/+1 |
| **兀突骨** | "**手牌里**的藤甲兵" | 同上 | 场上部分可做：给 `teng_jia` 加 `stack_mode: max`（纯数据），光环对己方藤甲兵施加 2 层 → 净效果**正好由 −1 变 −2**（不会叠成 −3） |
| **孟获** | ① 手牌 +2/+2；② **亡语回手牌**；③ **只能触发 6 次**；④ 第 7 次给对手 | ① 手牌不可改；② `killUnit` **先把单位移出战场、再跑亡语**，亡语拿不到自己；③ 引擎只有一次性标记 `lethalUsed`，没有计数器；④ `return_to_hand` 固定回**拥有者**手牌 | **A（零新增，推荐）**：`on_lethal` + `chance: 0.5`＝50% 概率以 1 血存活（不是回手牌），无次数上限（期望再活 1 次）<br>**B**：改为"阵亡时召唤一个 4/7 的孟获衍生物"<br>**C**：加通用「阵亡计数器」（需改引擎，但以后所有"七擒"类设计都能用） |

**另注（数值）**：严颜 4 费 2/7 = **9 点属性正好等于白板基准**（2×4+1），再送一条"反噬 3 伤"的亡语偏强 → 建议压到 2/6，或反噬降为 2。

## 附：本文核对过的引擎事实（供复查）

| 事实 | 位置 |
|---|---|
| 手牌不能承载数值加成（只有 cost / ban） | `core/src/types.ts` `HandMod.kind`；`effects.ts` 的 `modify` 分支与 `applyStatus` 手牌早退 |
| 只有火攻自动挂灼烧，毒攻不自动挂中毒 | `core/src/effects.ts` 伤害分支仅判 `damage_type === 'fire'` |
| 谋臣攻击力上限 1 | `core/tools/validate.ts`（`STRATEGIST_ATTACK_MAX`） |
| 亡语触发时单位已离场 | `core/src/mutate.ts` `killUnit`：先 `setUnit(null)`，再跑 `onDeathResolver` |
| 免死只能用一次 / 无计数器 | `core/src/mutate.ts` `tryLethalSave`（只读 `chance`，`lethalUsed` 一次性标记；**不执行技能 effects**） |
| 主公技"额外次数"已实现 | `core/src/constants.ts` `can_mou`（caps `extra_lord_skill`）+ `rules.canUseLordSkill` + `engine.ts` |
| `stack_mode: max` 是"取较大者"不叠加 | `core/src/mutate.ts` `mergeStacks` |
| `cycle_to_deck` ＝ 先回牌库随机位置、再抽 1 | `core/src/effects.ts` `case 'cycle_to_deck'` |
