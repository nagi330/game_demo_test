## 0. 取源与可信度（先读这段，它决定后面每条引文能信到什么程度）

**环境**：本会话 `web_search` 返回 `HTTP 402 Insufficient Balance`（账号级），维基百科 / ctext.org / archive.org 出网被封。三路子研究员各自绕路取源，最终有两条路走通：

| 源 | 可达性 | 内容 | ⚠️ 限制 |
|---|---|---|---|
| 古诗文网《三国志》`gushiwen.cn/guwen/bookv_*.aspx` | ✅ curl 直连 | 陈寿正文 | **节译本**（蜀书五缺王平/出师表等），**无裴松之注** |
| 维基文库 `zh.wikisource.org/wiki/Special:Export/三國志/卷NN` | ✅（普通页面 URL 不通，`Special:Export` 接口可通） | 正文，繁体 | 部分卷未见裴注 |
| 本地引擎注册表 `core/src/*.ts` | ✅ | 卡牌 DSL 的真实能力边界 | — |

**因此本文件的引文规则**：
1. 标「**正史正文**」的，逐字出自陈寿本传，我或子研究员都实际 grep 过原文，附卷次传名；
2. 标「**通鉴**」的出自《资治通鉴》（司马光撰）；
3. 标「**演义**」的明确说明不是正史；
4. **裴松之注整块本轮基本取不到** —— 凡「只在裴注」的人物一律降档，**不凭记忆补写**。

### 0.1 本轮纠正的 8 处常见误记（值得单独记一笔）

| 流传说法 | 核查结论 |
|---|---|
| 秦宓「天辩」 | **全库 0 命中**，不在陈寿正文；主要出自演义与后世类书 |
| 王平「所断者三人之地」 | **不在《三国志》**；正史是「众尽星散，惟平所领千人鸣鼓自持」 |
| 费祎「大破张郃」 | **不在《三国志》**；射杀张郃的是**诸葛亮**（建兴九年）。费祎的正史战功只有兴势之战 |
| 司马徽「好好先生」 | 四个字**不在正史**；但「识人之鉴」在《蜀书·庞统传》正文里 |
| 谯周「力主南奔」 | **反了** —— 谯周恰恰是反对南奔、力主受降并请缨赴洛阳争封土的人 |
| 谯周精「谶纬」 | 兼通图纬的是他**父**〈山并〉；陈寿明说谯周本人「**颇晓天文，而不以留意**」 |
| 邓芝「魏人降蜀」 | **不实** —— 原文「义阳新野人，汉末入蜀，未见知待」；正史/演义的差异在**籍贯**（义阳新野 vs 涿郡） |
| 赵广「病卒绵竹」 | 演义；正史（裴注引《云别传》）是「随姜维**绵中**，临陈战死」 |
| ~~严颜「正史无传」~~ | **我上一轮判断错了。**「断头将军」是**陈寿正文**，在《蜀书六·张飞传》，且是完整四段式（见 §2.8） |
| ~~秦宓「天辩」不在正史~~ | **也要更正**：那句对决的**名称**不在正文，但**事迹在**——张温七问七答整段在《蜀书八·秦宓传》正文 |
| 秦宓「谏刘备称帝」 | 不在其传；他唯一一次谏主是谏东征吴，且「坐下獄幽閉，然後貸出」。正史里反对称帝的是**周群之子周诗** |
| 张嶷「剖胆斗胆」「一人镇七郡」 | 均查不到。可用的是裴注《益部耆旧传》遗言「**若有未捷，殺身以報**」与正文「在郡十五年，邦域安穆」 |
| 董允「为太子辩」 | 传里没有。实际是**拒纳后宫嫔妃**（而且赢了：「終執不聽。後主益嚴憚之」）＋压制黄皓 |
| 孙乾「从政清议」 | 查不到；正史定性是卷末评「皆雍容**風議**，見禮于世」 |

> 📌 **一个重要考据结果**：**徐庶在《三国志》中没有本传**。他的素材分别出自诸葛亮传（举荐、辞别）与董和传（诸葛亮的评价）。做卡文案时别写「陈寿载徐庶传曰」。

### 2.1 徐庶 · 3 费 1/2 · 谋臣 —— 荐才 / 佐公

**史料**（《蜀书·诸葛亮传第五》，正史正文）
- 「惟博陵崔州平、颉川徐庶元直与亮友善，谓为信然。」
- 「时先主屯新野。徐庶见先主……庶曰：'**此人可就见，不可屈致也。将军宜枉驾顾之。**'由是先主遂诣亮，**凡三往**，乃见。」
- 「亮与徐庶并从，为曹公所追破，**获庶母**。庶辞先主而**指其心**曰：'本欲与将军共图王霸之业者，**以此方寸之地也。今已失老母，方寸乱矣**，无益於事，请从此别。'遂诣曹公。」
- 《蜀书·董和传第九》（诸葛亮《与群下教》）：「惟**徐元直处兹不惑**……**后交元直，勤见启诲**……亦足以明其不疑於直言也。」

| 项 | 值 |
|---|---|
| 费 / 攻 / 血 | 3 / 1 / 2 |
| 关键词 | 无 |
| memo | 举荐卧龙的那张嘴；进了曹营，便再无一字 |
| flavor | 本欲与将军共图王霸之业者，以此方寸之地也。今已失老母，方寸乱矣。 |

**技能**
- **举荐**（上场）：战吼 —— 使一名友方武将永久 +1 攻 / +1 血。
- **佐公**（主公技结算后）：抽 1 张牌。

**定价** 3 + 3.0 + 2.1 = **7.6 vs 基准 7（+0.6）**
**理由**：「举荐」把"推荐卧龙"翻成"给友军永久 +1/+1"；「佐公」对应"勤见启诲"，并与刘备「仁德」（2 统率 / 每回合 1 次）接成**主公技引擎**。1/2 的身体让他前期真弱，符合"没羽翼不能久飞"。

### 2.2 谯周 · 3 费 1/3 · 谋臣 —— 天象 / 仇国

**史料**（《蜀书·杜周杜许孟来尹李谯郤传第十二》，正史正文）
- 「父〈山并〉，字荣始，治尚书，**兼通诸经及图、纬**。」（家学）
- 「身长八尺，体貌素朴，性推诚不饰，**无造次辩论之才，然潜识内敏**。」（不擅辩论，心里全明白）
- 「**周文养民，以少取多，勾践恤众，以弱毙强**，此其术也。」（《仇国论》）
- 「周语次，因书版示立曰：'**典午忽兮，月酉没兮。**'典午者谓司马也，月酉者谓八月也，**至八月而文王果崩**。」（预言应验）
- 「**自古已来，无寄他国为天子者也**……」＋「若陛下降魏，魏不裂土以封陛下者，**周请身诣京都，以古义争之**。」「於是遂从周策。刘氏无虞，一邦蒙赖，周之谋也。」
- ⚠️ 注意反差：陈寿明说谯周「**颇晓天文，而不以留意**」，会图纬的是他父亲。

**技能**
- **天象**（每回合开始）：查看牌库顶的一张牌并获得之。
- **仇国**（光环）：在场时，若己方场上人物**少于**敌方，己方全体人物 +1 攻。

**定价** 4 + 1.7 + 1.5 = **7.2 vs 基准 7（+0.2）**
**理由**：「仇国」= 把《仇国论》的主旨（**以弱胜强**）做成劣势补偿光环，引擎用 `condition.count_vs` 比较双方场上人物数（已核对 `effects.ts:284` 有实现）。「天象」用 `scry 1 → hand`，是全卡池**唯一的"稳定每回合 +1 牌"**。

> 🎁 **联动彩蛋**：谯周少时的好友是秦宓 ——「谯允南少时数往谘访，纪录其言於春秋然否论」。两人可以做成师承羁绊。

### 2.3 蒋琬 · 4 费 1/4 · 谋臣 —— 方整 / 托孤

**史料**（《蜀书·蒋琬费祎姜维传第十四》，正史正文）
- 「亮卒，以琬为尚书令……时新丧元帅，远近危悚。**琬出类拔萃，处群僚之右，既无戚容，又无喜色，神守举止，有如平日**，由是众望渐服。」
- 卷末评曰原词：「**蒋琬方整有威重，费祎宽济而博爱**，咸承诸葛之成规，因因循而不革，是以边境无虞，邦家和一。」（**「方整」是陈寿的原词**）
- 「**臣若不幸，后事宜以付琬。**」（诸葛亮密表后主）
- 「人心不同，各如其面；**面从后言，古人之所诫也**。」／「吾实不如前人，无可推也……**苟其不如，则事不当理**。」
- ⚠️ 蒋琬传里**没有「屯田」**（全书「分兵屯田」在诸葛亮传，指渭南屯田）。他的正史关键词是**舟师东下**「乃多作舟船，欲由汉、沔袭魏兴、上庸」与**驻涪**。

**技能**
- **方整**（光环）：在场时，己方全体武将 +1 攻。
- **托孤**（阵亡）：使一名友方武将永久 +1 攻 / +1 血。

**定价** 5 + 2.4 + 2.4 = **8.8 vs 基准 9（−0.2）**
**理由**：**全提案里唯一一张"死得其所比活着更值"的谋臣卡** —— 把诸葛亮临终那句话变成机制。

### 2.4 费祎 · 5 费 1/5 · 谋臣 —— 折辩 / 遇刺

**史料**（《蜀书·蒋琬费祎姜维传第十四》，正史正文）
- 「孙权性既滑稽，嘲啁无方，诸葛恪、羊衟等才博果辩，论难锋至，**祎辞顺义笃，据理以答，终不能屈**。权甚器之。」
- 「值军师魏延与长史杨仪相憎恶……**延或举刃拟仪，仪泣涕横集。祎常入其坐间，谏喻分别**……祎匡救之力也。」
- 兴势之战：「魏军次于兴势，假祎节……**羽檄交驰。人马擐甲，严驾已讫，祎与敏留意对戏，色无厌倦。**」→「**祎至，敌遂退，封成乡侯。**」
- 遇刺：「延熙十六年岁首大会，**魏降人郭脩在坐。祎欢饮沈醉，为脩手刃所害**。」
- ⚠️ 「大破张郃」是演义/民间说法，**正史无此说**（射杀张郃的是诸葛亮）。

**技能**
- **折辩**（上场）：使一名敌方武将技能禁用 1 回合。
- **遇刺**（阵亡）：对造成费祎死亡的敌方单位造成 3 点伤害。

**定价** 6 + 4.0 + 1.1 = **9.8 vs 基准 11（−1.2）**
**理由**：「折辩」＝辩到对方没话；「遇刺」亡语指定 `event: killer` —— **死在谁手上就砍回去**（已核对 `effects.ts:58-62` 的 on_death 上下文带 `killer`）。

### 2.5 王平 · 4 费 3/4 · 武将 · 架盾 —— 鸣鼓 / 收合

**史料**（《蜀书·黄李吕马王张传第十三》，正史正文）
- 「建兴六年，属参军马谡先锋。谡舍水上山，举措烦扰，**平连规谏谡，谡不能用，大败於街亭**。众尽星散，**惟平所领千人，鸣鼓自持，魏将张郃疑其伏兵，不往偪也。於是平徐徐收合诸营遗迸，率将士而还**。」
- 「九年，亮围祁山，平别守南围……**张郃攻平，平坚守不动，郃不能克。**」
- 「十二年，亮卒於武功，军退还，**魏延作乱，一战而败，平之功也**。」
- 兴势之策（曹爽率步骑十余万、汉中守兵不满三万）：「今宜先遣刘护军、杜参军据兴势，平为后拒……**涪诸军及大将军费祎自成都相继而至，魏军退还，如平本策**。」
- **最妙的一条**：「**平生长戎旅，手不能书，其所识不过十字，而口授作书，皆有意理。使人读史、汉诸纪传，听之，备知其大义**，往往论说不失其指。」

**技能**
- **鸣鼓**（上场）：自身获得「披坚」，并于本回合 +1 攻。
- **收合**（阵亡）：使己方全体武将 +1 攻 / +1 血。

**定价** 7 −1 + 1.2 + 2.1 = **8.6 vs 基准 9（−0.4）**
**理由**：全卡池最被低估的一块史料。"千人鸣鼓自持，张郃疑其伏兵"是**用声势换时间** —— 所以给的是披坚 + 本回合先手，不是伤害。架盾对应"张郃攻平，平坚守不动，郃不能克"。

> 📌 建议把「手不能书…口授作书」写进卡面 note：这是全蜀最妙的人设（不识字却能口授军令、听史书能知大义），将来若要做"被选中时指挥全场"的机制，这就是原文依据。

### 2.6 张嶷 · 4 费 3/3 · 武将 —— 和亲 / 身陨

**史料**（《蜀书·黄李吕马王张传第十三》，正史正文）
- 「弱冠为县功曹。先主定蜀之际，山寇攻县，县长捐家逃亡，**嶷冒白刃，携负夫人，夫人得免**。」
- 「**嶷度其鸟散，难以战禽，乃诈与和亲，剋期置酒。酒酣，嶷身率左右，因斩慕等五十馀级，渠帅悉殄。**」
- 「越巂郡……北徼捉马最骁劲，不承节度，嶷乃往讨，**生缚其帅魏狼，又解纵告喻，使招怀馀类**……种落三千馀户皆安土供职。」
- 预警后来应验：「嶷书戒之（费祎）曰：'昔岑彭率师，来歙杖节，咸见害於刺客，今明将军位尊权重，宜鉴前事，少以为警。'**后祎果为魏降人郭脩所害。**」
- 战死：「**嶷临陈陨身，然其所杀伤亦过倍。**」

**技能**
- **和亲**（上场）：随机一名敌方武将技能禁用 1 回合。
- **身陨**（阵亡）：对敌方全体人物造成 1 点伤害。

**定价** 6 + 3.2 + 1.05 = **9.4 vs 基准 9（+0.4）**
**理由**：「和亲」复刻的是**诈降斩首** —— 不是选目标是**随机**（你不知道他要杀谁），比费祎的"指定禁言"更阴。与张苞区分：张苞打全部低攻敌人，张嶷只打**一个随机的武将**且是**禁言**。

> 📌 张嶷这条链还能做一张联动卡：他给费祎写过那封**预言式的警告信**，而费祎后来真的死在刺客手里 —— 若你愿意，这两卡之间有一条现成的剧情线。

### 2.7 廖化 · 3 费 3/3 · 武将 · 先攻 —— 后继

**史料**（《蜀书·邓张宗杨传第十五》，正史正文）

- 「先主薨，为丞相参军……**以果烈称。官位与张翼齐**，而在宗预之右。」
- 借宗预之口：「时都护诸葛瞻初统朝事，**廖化过预，欲与预共诣瞻许**。预曰：'**吾等年逾七十，所窃已过，但少一死耳**，何求於年少辈而屑屑造门邪？'遂不往。」

### 2.8 严颜 · 3 费 2/4 · 武将 · 架盾 —— 断头 / 引为宾客

**史料**（《蜀书六·张飞传》，**正史正文**，我已在维基文库 `Special:Export/三國志/卷36` 独立复核）
- 「至江州，破璋將巴郡太守嚴顏，生獲顏。飛呵顏曰：'**大軍至，何以不降而敢拒戰？**'顏答曰：'卿等無狀，侵奪我州，**我州但有斷頭將軍，無有降將軍也**。'」
- 「飛怒，令左右牽去**斫頭**，顏**色不變**，曰：'**斫頭便斫頭，何為怒邪！**'飛**壯而釋之，引為賓客**。」
- 卷末评曰：「羽報效曹公，**飛義釋嚴顏，並有國士之風**。」
- 《华阳国志》（同卷附注）：「初，先主入蜀，至巴郡，顏拊心歎曰：'**此所謂獨坐窮山，放虎自衛也！**'」

**技能**
- 架盾（关键词）
- **断头**（受到伤害时）：随机一名敌方人物本回合不能普通攻击。
- **引为宾客**（阵亡）：使一名敌方武将获得「披坚」。

**定价** 6 −1 + 1.5 + 0.75 = **7.2 vs 基准 7（+0.2）**
**理由**：「断头」= 砍我也不怕，还反手让对面动不了；「引为宾客」是**实验性设计** —— 全卡池没有一张「死后给**敌方**增益」的牌，用它承载「飞壮而释之，引为宾客」这句全篇最有余味的结局。

> 📌 **这一节是我上一轮判断错的地方**：我原先把「断头将军」当作演义素材（项目里沙摩柯就是演义人物，先例是有的），子研究员在维基文库抓到正文后我已独立复核确认 —— **它是陈寿正文**，而且是完整四段式，比我原来那版设计好得多。这条记在 §0.1 里作为「先做判断、后被推翻」的样本。

### 2.9 董允 · 3 费 1/3 · 谋臣 —— 正色 / 抑阉

### 2.10 秦宓 · 3 费 1/3 · 谋臣 —— 称疾 / 答问如响

**史料**（《蜀书·许麌孙简伊秦传第八》，**正史正文**）
- 「秦宓字子敕，广汉绵竹人也。**少有才学，州郡辟命，辄称疾不往。**」
- **张温七问七答（正文全载）**：「温问曰：'君学乎？'宓曰：'**五尺童子皆学，何必小人！**'温复问曰：'天有头乎？'宓曰：'有之。'……'天有姓乎？'宓曰：'有。'温曰：'何姓？'宓曰：'**姓刘。**'温曰：'何以知之？'答曰：'**天子姓刘，故以此知之。**'……**答问如响，应声而出，於是温大敬服。**」
- 卷末评：「秦宓始慕肥遯之高，而无若愚之实。然**专对有馀，文藻壮美**，可谓一时之才士矣。」
- 唯一的谏主（谏东征吴，下场难看）：「先主既称尊号，将东征吴，**宓陈天时必无其利，坐下狱幽闭，然后贷出**。」

**技能**
- **称疾**（上场）：弃 1 张手牌，然后抽 2 张牌。
- **答问如响**（受到伤害时）：使攻击者获得「虚弱」1 回合。

**定价** 4 + 1.8 + 2.0 = **7.2 vs 基准 7（+0.2）**
**理由**：「称疾」把"连州郡征召都装病拒绝"翻成"先扔一张再拿两张"（净过牌为正，与马谡的"抽 2 弃 2"净 −0 区分）；「答问如响」是**被动反制**型（被打了才让对方变弱），与董允的「正色」（上场指定）分工不同。

> 📌 **这也是我上一轮判断错的地方**：另一路研究员报「天辩全库 0 命中」，我据此把它当成演义素材降级处理；实际上七问七答整段就在正文里，只是没用「天辩」这个词。**教训：检索命中的是关键词，不是事迹。**

### 2.11 李严 · 4 费 1/4 · 谋臣 —— 督粮 / 诬告

| 诸葛珪 | 是诸葛亮的**父辈不是兄弟**：「父珪，字君贡」—— 常见误记 |
| 杨戏、向朗、董和、何宗、刘永 | 正史有名有姓，但记述集中在"清贫/守正/举荐"这类不适合卡牌动词的性状上，强行做会变白板 |

> ⚠️ 两条正史事实与现有卡池相关：**① 吴国「马忠」在正史里其实是蜀臣**（《蜀书十三·马忠传》，斩刘胄平南土者），若卡面写「吴马忠」需注明是民间设定；**② 张飞帐下将杀飞的是「张达、范强」**，「范强」不在任何名单里，「张南」查无实据。

## 6. 顺带抓到的三个引擎事实

写提案时机检脚本撞出来的，都属于 ADR-116 那一类"字段合法但引擎不读"：

1. **`modify` 指向主公时只有 `duration: this_turn` 生效**（`effects.ts:1677`）。写 `target: {lord: true}` 而不给 `duration`，会走到 `t.kind !== 'unit'` 直接跳过 —— **永久给主公 +1 攻是静默无效的**。我最初给董允写的「己方主公 +1/+1」就是这样废掉的，改成了「抑阉」。全池目前只有车下虎士用 `this_turn` 修改主公。
2. **`draw` 只看 `target.side`**，无法"让某个被选中的单位抽牌"。我给蒋琬写的"托孤后令其抽 2 张"因此被删。
3. **`on_lord_skill_used` 不在 `constants.ts` 的 `TIMING` 表里**，但 `engine.ts:35` 真实派发它（张昭/张纮/东吴精骑/徐庶「佐公」都在用）—— **触发时机表与实现不同步**。建议补进 `TIMING`（一行改动，纯数据修复）。

> 这三条我只做了**记录**，没有改 `core/`。

## 8. 需要你拍板的六件事

1. **史料口径**：本轮全部走的是**陈寿正文**（部分卷为节译本），**裴松之注取不到**。是否接受这个口径？还是等拿到裴注/《华阳国志》再做（影响：夏侯氏、孟获、赵统赵广、诸葛果、蒲元）。
2. **严颜「引为宾客」这个实验性设计要不要**？全卡池没有"死后给敌方增益"的牌，它好玩但会反直觉。
3. **李严要不要做**？他历史评价负面，卡面会给蜀国池塞一个"内鬼感"角色。要不要只留「督粮」、去掉「诬告」？
4. **谯周的「天象」与"不以留意天文"**有张力，要不要改成更贴合「势小则胜」的纯劣势补偿？另外谯周与秦宓是正文可考的师友，要不要做**软联动**（而非硬绑定）？
5. **1 费段仍空缺**：17 张全在 3–6 费，蜀国没有 1 费人物卡。要不要专门补一张 1–2 费"小人物"（孙乾、霍峻这类）来拉低曲线？
6. **要不要动 `constants.ts` 补 `on_lord_skill_used`**（§6-3，一行改动）？
