## 0. 综述

1. **蜀汉女性在正史里近乎「失声」**。《三国志·蜀书》只为后妃开了**一卷**（卷34《二主妃子传》），全卷只记 **4 位女性**：先主甘皇后、先主穆皇后（吴氏）、后主敬哀皇后（张飞长女）、后主张皇后（张飞次女）。整卷的收尾评语只有一句：「《易》稱有夫婦然後有父子，夫人倫之始……是故紀錄，以究一國之體焉」——**收她们进来是为了「究一国之体」，不是为了记她们本人**。([卷34](https://zh.wikisource.org/wiki/三國志/卷34))
2. **绝大多数蜀汉女性连名字都没留下**。甘皇后之名「梅」出自明《夔州府志》引元碑；穆皇后**姓吴，名不详**；张飞妻只称「夏侯氏」；关羽之女只称「关氏」。**「吴苋」「关银屏」「张星彩」这些名字全部不是正史原文。**
3. **正史里她们的「事迹」多半是别人的事迹**。甘夫人留名靠的是「**棄后及後主，賴趙雲保護**」和诸葛亮的追谥奏；糜夫人留名靠的是兄长麋竺「**進妹於先主為夫人**」；夏侯氏留名靠的是《魏略》在**夏侯渊传**里的一句附注。**她们是男性传记的注脚。**
4. **演义把注脚放大成了名场面**。长坂坡「**糜夫人投井**」（41回）、「**关公秉烛立于户外**」护二嫂（25回）、关羽「**吾虎女安肯嫁犬子乎**」（73回）——这些妇孺皆知的情节，**正史里或只有一句、或完全没有**。
5. **民间与戏曲再放大一层，且开始「造人」**。明成化说唱词话《花关索传》造出**关索、鲍三娘、王桃、王悦、胡金定**；京剧《龙凤巾》造出**花鬘**；清代道教文献造出**诸葛果**；1986 年民间故事集《三国外传》造出**关银屏**。
6. **现代游戏又放大/改名一层**。**张星彩是光荣《真·三国无双4》的原创名**（原型=无名之张飞长女）；**马云禄出自 1930 年代周大荒的架空小说《反三国演义》**（不是游戏原创，但也不是演义）；**灵雎出自 2012 年电影《铜雀台》**。**这三类必须分开标注，否则会把游戏设定当历史。**
7. **对卡牌设计最有利的一类人，恰恰是「正史有载、演义没写」的那几个**——如**夏侯氏**（演义通篇未提张飞之妻，正史却记她请葬夏侯渊、刘禅认夏侯霸为舅）。她们既不是虚构，又没有任何被用滥的形象，**留白最大**。

# 第一部分 · 女性

## 1. 甘夫人（昭烈皇后）

| 项 | 内容 |
|---|---|
| **姓名 / 称号** | 甘氏，名不详（《夔州府志》引元《昭烈皇后墓碑》作「**甘梅**」）；追谥**皇思夫人 → 昭烈皇后** |
| **真实性** | **A 正史正文有载**（《三国志·蜀书·二主妃子传》，卷34） |
| **身份关系** | 刘备之妾 → 追谥皇后；**刘禅生母** |

**正史记载**
- 「先主甘皇后，沛人也。先主臨豫州，住小沛，**納以為妾**。先主數喪嫡室，**常攝內事**。隨先主於荊州，**產後主**。」——她是刘备反复丧妻后的「代理主母」([卷34](https://zh.wikisource.org/wiki/三國志/卷34))
- 「值曹公軍至，追及先主於當陽長阪，於時困偪，**棄后及後主，賴趙雲保護，得免於難**。後卒，葬於南郡。」——**刘备把她和儿子一起丢下了**，救人的是赵云。
- 章武二年追谥皇思夫人、迁葬于蜀；诸葛亮上言「**母以子貴**」，案谥法宜曰昭烈皇后，与先主合葬。亮评她「**履行脩仁，淑慎其身**」。

**演义 / 民间形象与名场面**
- **34 回**：生刘禅时有白鹤高鸣四十余声、异香满室，「甘夫人嘗夜夢仰吞北斗，故**乳名阿斗**」——把阿斗的小名挂到她身上([第034回](https://zh.wikisource.org/wiki/三國演義/第034回))
- **25 回**：下邳失守，与糜夫人同被曹操所掳；关羽「**秉燭立於戶外，自夜達旦**」护嫂，二夫人凡事问「叔叔自家裁处」——她成了关羽「义」的道具([第025回](https://zh.wikisource.org/wiki/三國演義/第025回))
- **41 回**：长坂坡「**披頭跣足**」杂在百姓中逃命，被赵云寻回([第041回](https://zh.wikisource.org/wiki/三國演義/第041回))
- **《拾遗记》**（志怪，非史）：刘备得河南玉人高三尺，置甘后身侧，「晝則講說軍謀，夕則擁后而玩玉人」；甘后谏以「子罕不以玉為寶」，被时人称为「**神智婦人**」。**该条时代错乱（她说「今吳、魏未滅」，而吴魏立国在她死后），维基亦判「存疑」**([维基·昭烈皇后](https://zh.wikipedia.org/wiki/昭烈皇后_(蜀漢)))

**能力 / 特色标签**：`贤内助` `悲情` `随军`
**3 个可游戏化钩子**
1. **「摄内事」→ 后方稳定**：己方主将（刘备）在场时，每回合开始为全体己方单位恢复 1 点生命——「数丧嫡室，常摄内事」的游戏化。
2. **「母以子贵」→ 延时觉醒**：本卡阵亡后不进弃牌堆，改为「葬于南郡」；当己方打出刘禅（或主将存活到第 N 回合）时回归并升级为「昭烈皇后」，获得增益。
3. **「弃后及后主」→ 舍身保核**：己方主将受到致命伤害时，可弃掉本卡代替承受——把正史那句冷冰冰的「棄后及後主」变成玩家主动做的选择。

**来源**：[《三国志》卷34](https://zh.wikisource.org/wiki/三國志/卷34)｜[《三国演义》第34回](https://zh.wikisource.org/wiki/三國演義/第034回)｜[《三国演义》第41回](https://zh.wikisource.org/wiki/三國演義/第041回)｜[维基·昭烈皇后（蜀汉）](https://zh.wikipedia.org/wiki/昭烈皇后_(蜀漢))

## 2. 糜夫人（麋夫人）

| 项 | 内容 |
|---|---|
| **姓名 / 称号** | 麋氏（正史作**麋**，演义作**糜**），名不详；弹词《三国志玉玺传》名「**绿筠**」 |
| **真实性** | **B 正史仅见旁证**——**《二主妃子传》里没有她**；她只出现在《麋竺传》一句和《先主传》的「虏先主妻子」里 |
| **身份关系** | 徐州别驾**麋竺之妹**、麋芳之姐；刘备夫人 |

**正史记载**
- 《麋竺传》：「建安元年，呂布乘先主之出拒袁術，襲下邳，**虜先主妻子**。先主轉軍廣陵海西，竺於是**進妹於先主為夫人**，奴客二千，金銀貨幣以助軍資；于時困匱，**賴此復振**。」——**这是一场军资换婚姻的交易**([卷38](https://zh.wikisource.org/wiki/三國志/卷38))
- 《先主传》：建安五年「曹公東征先主，先主敗績。曹公**盡收其眾，虜先主妻子**，並禽關羽以歸。」([卷32](https://zh.wikisource.org/wiki/三國志/卷32))
- **此后正史再无她的任何记载**——不记卒年、不记追谥。（演义却让她死后被追谥为皇后，**史无此事**）

**演义 / 民间形象与名场面**
- **25 回**：与甘夫人一同被掳许都，关羽离曹时一并带走([第025回](https://zh.wikisource.org/wiki/三國演義/第025回))
- **41 回「糜夫人投井」**（她的核心名场面）：左腿中枪、抱阿斗坐在**烧坏的土墙下、枯井旁**啼哭；三番五次不肯上马，说「妾已重傷，死何足惜」「**勿以妾為累也**」；最后「**乃棄阿斗於地，翻身投入枯井中而死**」。赵云「**便將土牆推倒，掩蓋枯井**」。演义赞诗：「拚將一死存劉嗣，勇決還虧**女丈夫**」([第041回](https://zh.wikisource.org/wiki/三國演義/第041回))
- **纪念实体**：湖北当阳长坂坡西侧有「**娘娘井**」与糜后祠，河北涿州三义宫后殿「娘娘殿」供奉甘、糜、吴三夫人([维基·麋夫人](https://zh.wikipedia.org/wiki/麋夫人))
- 蔡东藩评：「糜夫人甘心殉難，亦可謂**賢妻**……劉糜氏以**寧死全夫嗣**」

**能力 / 特色标签**：`刚烈` `悲情` `贤内助`
**3 个可游戏化钩子**
1. **「投井」→ 献祭型遗产**：本卡可主动自我牺牲，使自己场上一个友方单位获得「免疫本次伤害」并回复全部生命；牺牲时在原地留下「枯井」标记（一个 0 攻的障碍物，阻挡一次冲锋）。
2. **「进妹为夫人」→ 军资换婚姻**：入场时把一张手牌转化为 2 点资源/费用（「奴客二千，金银货币以助军资」），但**必须**以己方主公在场为条件——把「于时困匮，赖此复振」做成一张纯经济卡。
3. **「宁死全夫嗣」→ 护嗣**：本卡存活时，己方主公/关键单位受到的第一次致命伤害由她承受并转化为「阿斗」衍生物（一个可持续成长的 0/1 单位）。

**来源**：[《三国志》卷38·麋竺传](https://zh.wikisource.org/wiki/三國志/卷38)｜[《三国志》卷32·先主传](https://zh.wikisource.org/wiki/三國志/卷32)｜[《三国演义》第41回](https://zh.wikisource.org/wiki/三國演義/第041回)｜[维基·麋夫人](https://zh.wikipedia.org/wiki/麋夫人)

## 3. 吴氏（穆皇后）—— 通称「吴苋」

| 项 | 内容 |
|---|---|
| **姓名 / 称号** | **姓吴，名不详**；谥**穆皇后**，后主时尊为**皇太后**（长乐宫）。**「吴苋」这个名字不是正史原文，属后世/民间说法**——百度百科亦只写「**据说**其名为吴苋」 |
| **真实性** | **人物 A 正史正文有载**（卷34 有传）；**名字 D 后世附会** |
| **身份关系** | **吴懿（吴壹）之妹**；先嫁**刘焉之子刘瑁**（寡妇）→ 再嫁刘备为夫人 → 汉中王后 → 皇后 → 皇太后；刘备皇后中**唯一善终**者 |

**正史记载**
- 「先主穆皇后，陳留人也。**兄吳壹**，少孤，壹父素與劉焉有舊，是以舉家隨焉入蜀。焉有異志，而聞善相者**相后當大貴**。焉時將子瑁自隨，遂**為瑁納后**。瑁死，后寡居。」——她的第一次婚姻是刘焉的**政治投机**([卷34](https://zh.wikisource.org/wiki/三國志/卷34))
- 「先主既定益州，而孫夫人還吳，群下勸先主聘后，先主疑與瑁同族，**法正**進曰：『論其親疏，何與晉文之於子圉乎？』於是納后為夫人。」——刘备娶她**在法律上很勉强**，习凿齿直接批评先主「**過矣**」。
- 建安二十四年立汉中王后；章武元年五月立皇后，「**遣使持節丞相亮授璽綬**」；建兴元年尊皇太后；**延熙八年薨，合葬惠陵**——是刘备诸妻中**唯一与刘备合葬、且活得比刘备久 22 年**的一位。
- 附：建兴十二年正月，**刘琰妻胡氏**入宫朝贺被太后留下数月，刘琰疑其与后主有私、令士卒掌掴并以鞋打脸，胡氏告发，**刘琰下狱弃市**，朝廷自此禁止大臣妻母入朝贺庆。

**演义 / 民间形象与名场面**
- 演义称她是**法正推荐**给刘备的，并称**刘永、刘理皆吴氏所生**——**正史明确记载二子为刘备庶子且「與永異母」**，演义**与史不符**([维基·吴皇后](https://zh.wikipedia.org/wiki/吳皇后_(蜀漢)))
- 「**诸葛亮安居平五路**」（演义虚构段落）：刘禅率百官启奏太后，太后大惊以为诸葛亮辜负托孤、**想亲自去相府问罪**，被董允劝止——她在这里是**主少国疑的压舱石**
- 诸葛亮卒，「吴太后闻讯放声大哭」；魏延指杨仪谋反时，太后以「先帝曾说诸葛亮怀疑魏延」为由**判断可信杨仪**——一个**在关键时刻拍板的老太后**形象

**能力 / 特色标签**：`政治联姻` `贤内助` `刚烈`（以太后之尊定魏延杨仪之案）
**3 个可游戏化钩子**
1. **「相者当大贵」→ 命运标记**：入场时给己方主公附加「大贵」状态；该状态存在时主公免疫一次致命伤害，之后此卡获得 +2/+2（相士的预言照进牌局）。
2. **「寡妇再嫁」→ 转化敌方遗留资源**：可以指定对方场上一张「阵亡后留下的衍生物/装备」据为己有——把「瑁死后寡居，后归先主」做成一张**接收遗产**的卡。
3. **「安居平五路」→ 主帅封印解除**：己方主公处于「震慑/沉默」状态时，此卡可主动解除之并让主公立即行动一次——专治开局被压制的局面（对应太后定魏延之案）。

**来源**：[《三国志》卷34](https://zh.wikisource.org/wiki/三國志/卷34)｜[维基·吴皇后（蜀汉）](https://zh.wikipedia.org/wiki/吳皇后_(蜀漢))｜[维基·吴懿](https://zh.wikipedia.org/wiki/吳懿)（「三国志作吴壹，一说为避司马懿讳」）

## 4. 夏侯氏（张飞之妻、夏侯渊之侄女）

| 项 | 内容 |
|---|---|
| **姓名 / 称号** | 夏侯氏（**名不详**）；戏曲称「夏侯英」（1996 台视《关公》） |
| **真实性** | **B 正史仅见裴注**——不见于《张飞传》，出自**《魏书·诸夏侯曹传》裴注引《魏略》** |
| **身份关系** | **夏侯渊的从女**（侄女）、**夏侯霸的从妹**；**张飞之妻**；**刘禅两位皇后（敬哀皇后、张皇后）的生母** |

**正史记载**
- 《魏略》：「初，**建安五年**，時霸**從妹年十三四**，在本郡，**出行樵採，為張飛所得**。飛知其良家女，**遂以為妻**，**產息女，為劉禪皇后**。」——一个十三四岁的女孩上山打柴被掳走为妻([卷09](https://zh.wikisource.org/wiki/三國志/卷09))
- 「故淵之初亡，**飛妻請而葬之**。」——**定军山夏侯渊被杀后，是这位敌国大将的女儿出面请求收葬伯父/叔父**。这是整个三国最有人情味的一笔之一。
- 「及霸入蜀，禪與相見，釋之曰：『卿父自遇害於行間耳，非我先人之手刃也。』**指其兒子以示之曰：『此夏侯氏之甥也。』厚加爵寵。**」——249 年夏侯霸逃奔蜀汉，**刘禅用「我们是亲戚」化解了杀父之仇**。
- 逸闻：《夏侯渊传》载渊曾在荒年**舍弃自己的幼子、救活已故弟弟的女儿**——**未知是否即夏侯氏**（维基明确标为未定）。

**演义 / 民间 / 戏曲形象与名场面**
- **《三国演义》通篇未提张飞之妻**。维基直接写明：「罗贯中历史小说《三国演义》**只提到了张飞的子女，对张飞之妻没有提及**。」([维基·夏侯氏](https://zh.wikipedia.org/wiki/夏侯氏_(張飛妻)))
- 戏曲/影视补名：1985 电视剧《诸葛亮》作「夏侯夫人」；1996 台视《关公》作「**夏侯英**」

**能力 / 特色标签**：`政治联姻` `悲情` `随军`（她本身即「被掳—成婚—产女—葬叔」四段）
**3 个可游戏化钩子**
1. **「请而葬之」→ 敌我同源的收尸权**：敌方单位阵亡时可选择「收葬」，将其移入己方弃牌堆（不计入对方战功/不触发敌方亡语）——把夏侯氏葬夏侯渊这一笔做成规则。
2. **「此夏侯氏之甥也」→ 血缘免战**：当对方场上有「夏侯」姓氏单位时，本卡及其所在列**不能被其攻击**；若双方夏侯单位相邻，双方各 +1/+1（认亲）。
3. **「出行樵採，为张飞所得」→ 掠夺式招募**：从对手牌库随机「夺取」一张单位卡加入己方手牌（骰点/条件触发），**并且这张卡立刻获得「张」姓羁绊加成**——把正史那句冷峻的「为张飞所得」翻成机制。

**来源**：[《三国志》卷09 裴注引《魏略》](https://zh.wikisource.org/wiki/三國志/卷09)｜[维基·夏侯氏（张飞妻）](https://zh.wikipedia.org/wiki/夏侯氏_(張飛妻))｜[维基·夏侯渊](https://zh.wikipedia.org/wiki/夏侯淵)

> ⚠️ **联动钩子**：夏侯氏 + 夏侯霸 + 夏侯渊可做一条跨阵营（魏/蜀）的**亲缘羁绊线**，这是《酒话三国》目前卡池里极少见的「**敌我同族**」结构。

## 5. 关氏（关羽之女）—— 民间称「关银屏」「关三小姐」

| 项 | 内容 |
|---|---|
| **姓名 / 称号** | 关氏，**名不详**；民间称**关银屏 / 关三小姐 / 关氏三姐**；《三国群英传》叫「**关凤**」 |
| **真实性** | **人物 A 正史正文有载（无名）**；**「关银屏」这个名字是 1986 年民间故事集的命名 → D** |
| **身份关系** | **关羽之女**；孙权曾为其子求婚 |

**正史记载**
- 《关羽传》正文：「先是，**權遣使為子索羽女，羽罵辱其使，不許婚，權大怒。**」——**这是她唯一一次出现在正史里，而且只有一句话**([卷36](https://zh.wikisource.org/wiki/三國志/卷36))
- 正史**没有**说关羽骂的是什么话。「虎女焉嫁犬子」是演义的台词。
- 演义（73回）借诸葛瑾之口补出她的排行：「聞雲長自到荊州，**先生一子，次生一女**。其女尚幼，未許字人。」([第073回](https://zh.wikisource.org/wiki/三國演義/第073回))

**演义 / 民间 / 戏曲形象与名场面**

- **民间传说（1986 湖北省群众艺术馆《三国外传》）**——**这是「关银屏」这个名字的出处**：说她美丽聪慧，十八岁习得文采武艺；荆州失守后**逃到成都**，众人视为己出；诸葛亮南征时**亲自作媒**把她许配给**建宁太守李恢之子李遗**；南疆平定后随夫定居俞元（今澄江）**教化百姓**([维基·关氏](https://zh.wikipedia.org/wiki/關氏_(關羽女)))
- 民间传说里她还有一支「**女兵营**」，收纳了关索之妻**鲍三娘、王桃、王悦**以及妾**花中秀**——**但请注意：这套设定与《花关索传》互相冲突**

**能力 / 特色标签**：`刚烈` `武艺` `政治联姻`（被求婚的一方）
**3 个可游戏化钩子**
1. **「虎女」→ 拒绝型战吼**：对手打出「联姻/招募/策反」类效果时，可将其无效化并反弹伤害——「吾虎女安肯嫁犬子」的机制化。
2. **「关羽之女」→ 父荫与遗志**：己方关羽在场时获得「先攻」；关羽阵亡后本卡永久 +2 攻击并获得「复仇」——把「怀着为父报仇的宿愿逃到成都」做成成长曲线。
3. **「亲自作媒，许配李遗」→ 阵营内联姻**：与任一己方蜀国单位「结亲」，二者共享护甲/治疗；结亲后本卡获得「教化」——每回合为己方随机一张手牌减 1 费（南疆教化的隐喻）。

**来源**：[《三国志》卷36·关羽传](https://zh.wikisource.org/wiki/三國志/卷36)｜[《三国演义》第73回](https://zh.wikisource.org/wiki/三國演義/第073回)｜[维基·关氏（关羽女）](https://zh.wikipedia.org/wiki/關氏_(關羽女))｜[维基·三国虚构人物列表](https://zh.wikipedia.org/wiki/三國虛構人物列表)

## 6. 张氏（敬哀皇后）—— 游戏名「张星彩」

| 项 | 内容 |
|---|---|
| **姓名 / 称号** | 张氏，**名不详**；**敬哀皇后**；游戏名「**星彩 / 张星彩**」 |
| **真实性** | **人物 A 正史正文有载**（卷34 有传）；**「张星彩」是 D 级现代游戏原创名** |
| **身份关系** | **张飞长女**、夏侯氏之女；**刘禅第一任皇后**；其妹为刘禅第二任皇后（小张后） |

**正史记载**
- 「後主敬哀皇后，**車騎將軍張飛長女**也。章武元年，納為太子妃。建興元年，**立為皇后**。十五年薨，葬南陵。」([卷34](https://zh.wikisource.org/wiki/三國志/卷34))
- 「後主張皇后，**前后敬哀之妹**也。建興十五年，入為貴人。延熙元年春正月……立为皇后。」——**姐妹二人先后为后**
- 附：后主太子**刘璿**「母王貴人，本**敬哀張皇后侍人**也」——**张皇后的侍女后来生了太子**，这一层关系可以做成宫廷卡组

**演义 / 民间 / 戏曲形象与名场面**
- **演义对她几乎无描写**，只作为「张飞之女、后主皇后」的名分存在。
- **「星彩」这个名字完全出自日本光荣《真·三国无双》系列**，初登场于《真·三国无双4》，是**KOEI 的原创人物**——「因为敬哀皇后没有留下真实姓名，所以光荣公司为了不引起历史争议，用了『星彩』这个原创名」([360搜索聚合结果](https://www.so.com/s?q=%E4%B8%89%E5%9B%BD%E6%9D%80+%E5%BC%A0%E6%98%9F%E5%BD%A9+%E5%90%8D%E5%AD%97+%E6%9D%A5%E6%BA%90+%E5%8E%9F%E5%88%9B+%E8%99%9A%E6%9E%84))
- ⚠️ **维基明确指出一个矛盾**：「但是**活跃年份对不上，更多是偏向妹妹张皇后**」——敬哀皇后 237 年就死了，而游戏里星彩活跃到蜀汉后期([维基·敬哀皇后](https://zh.wikipedia.org/wiki/敬哀皇后_(蜀漢)))

**能力 / 特色标签**：`贤内助` `政治联姻` `武艺`（游戏设定）
**3 个可游戏化钩子**
1. **「姐妹先后为后」→ 传承**：本卡阵亡后，从牌库/手牌检索「张皇后」入场，继承其全部增益——**这是正史实有、且游戏里几乎没人用过的结构**。
2. **「本敬哀张皇后侍人也」→ 侍女升格**：己方低费「侍女/随从」类单位死亡时，可将其转化为一张「王贵人」衍生物（0/1，可成长为太子）。
3. **「车骑将军张飞长女」→ 父女连携**：张飞在场时本卡获得「架盾」；本卡在场时张飞获得 +1 攻击（而不是反过来）——**强调她是「给予方」**，避开已被用滥的「父荫」套路。

**来源**：[《三国志》卷34](https://zh.wikisource.org/wiki/三國志/卷34)｜[维基·敬哀皇后（蜀汉）](https://zh.wikipedia.org/wiki/敬哀皇后_(蜀漢))

> ⚠️ **命名建议**：卡面建议用「**敬哀皇后**」或「**张皇后**」；若为了玩家认知保留「**张星彩**」，`note` 必须标 **D 级（《真·三国无双4》原创名）**。

3. **「敦煌公主 / 扬威将军」→ 双形态**：己方马超阵亡后，本卡从「女将」形态变为「敦煌公主」形态（攻击转辅助，为全体西凉/骑兵单位提供 +1/+1）。

**来源**：[维基·反三国演义](https://zh.wikipedia.org/wiki/反三國演義)｜[维基·三国虚构人物列表](https://zh.wikipedia.org/wiki/三國虛構人物列表)｜[ja.wikipedia·馬雲騄](https://ja.wikipedia.org/wiki/馬雲騄)

## 9. 花鬘

> ⚠️ **覆盖提示**：`docs/research/shu-nanzhong-nanman.md` 已把花鬘列入南中/南蛮专题（C1）。此处只补**不重复**的要点。

| 项 | 内容 |
|---|---|
| **姓名 / 称号** | 花鬘（huā mán）。**民间关银屏传说里又叫「花中秀」** |
| **真实性** | **C 戏曲虚构**——**不在《三国志》，也《不在三国演义》**，仅见于**京剧《龙凤巾》**（溥绪由昆腔翻为皮黄，又名《化外奇缘》） |
| **身份关系** | **孟获与祝融夫人之女**；**关索之妻** |

**正史记载**
- **无。**《三国志》与《三国演义》**均未提及花鬘**([维基·花鬘 (三国)](https://zh.wikipedia.org/wiki/花鬘_(三國)))
- ⚠️ **易错点**：词条「花鬘」本义是**佛教法器**（梵语 रुचक，花穿成串套在颈上），与三国人物**同名不同人**，检索时要加「(三国)」([维基·花鬘](https://zh.wikipedia.org/wiki/花鬘))

**戏曲形象与名场面**
- 诸葛亮征南蛮时**与关索交锋，败而坠马**；关索不忍杀，纵其归营；后**关索被俘**，两造互生爱意，碍于敌对身份**只得私订婚约**
- 花鬘**反遭蜀营所擒**，两营借此**走马换将**；直到降服孟获，**诸葛亮知晓此情深受感动，主持婚姻使之共结连理**
- **版本冲突（重要）**：《花关索传》里关索娶的是**鲍三娘、王桃、王悦**，**全篇没有花鬘**；民间关银屏传说里花鬘是**关索之妾**且被纳入关银屏的**女兵营**。**三套说法互不一致 → 存疑**

**能力 / 特色标签**：`武艺` `政治联姻`（敌我通婚）`巫术/道术`（南蛮血统可挂南中系）
**3 个可游戏化钩子**
1. **「阵前坠马、被纵归营」→ 双向不杀**：本卡与关索互相攻击时，双方伤害减半且**都不能被对方击杀**；若二者都存活到第 3 回合，**一起获得 +2/+2**（私订终身）。
2. **「走马换将」→ 人质交换**：本卡可将己方一个被「震慑/俘获」的单位与对方场上一张同费单位互换控制权——戏曲里最戏剧性的一场机制化。
3. **「诸葛亮主持婚姻」→ 第三方批准**：本卡与关索同时在场的回合结束时，若己方有「诸葛亮」，二者进化（获得「先攻＋架盾」）；若无诸葛亮，则**不能进化**——把「需要主婚人」做成硬条件。

| 项 | 内容 |

| **真实性** | **C 演义虚构**（正史、《三国志》正文与裴注**均无**）；中文维基《三国虚构人物列表》明确归类为**虚构**([维基·三国虚构人物列表](https://zh.wikipedia.org/wiki/三國虛構人物列表)) |

- **坐骑考**：她骑的「**卷毛赤兔**」与关羽的赤兔**同名不同马**——参见本文件 §19 关于「赤兔是良马标准而非单一马名」的考据

**能力 / 特色标签**：`武艺` `巫术/道术`（祝融=火神）`名马`
**3 个可游戏化钩子**（补 `shu-nanzhong-nanman.md` 未提的角度）
1. **「卷毛赤兔」→ 与关羽同名坐骑的混淆梗**：本卡坐骑可命名为「赤兔」（与关羽的赤兔在同一装备池），二者同名但数值不同——**利用「赤兔是良马标准而非专名」的考据做一张同名装备**。
2. **「我虽是一妇人，愿与你出战」→ 性别触发**：场上男性单位越多，本卡攻击越高——与貂蝉「只对男性生效」形成**同一机制的正反两面**（貂蝉是削弱男性，她是被男性激励）。
3. **「五口飞刀」→ 五次远程点伤**：每回合可对任意目标造成 1 点伤害，共 5 次/局；用尽后本卡攻击 −3（背上的刀插完了）。

**能力 / 特色标签**：`武艺` `悲情`（被排挤出正史谱系的「第三子」）
**3 个可游戏化钩子**
1. **「认父」→ 条件入场**：本卡不能直接打出，只能通过「关羽在场」或「己方单位阵亡后从牌库检索」入场——把「赴荆州认父」做成硬条件。
2. **「鲍家庄养病」→ 迟到者**：本卡入场时处于「伤病」状态（攻−2），第 3 回合后痊愈并获得「先攻」——**「迟到但最终到场」是他最强的叙事特征**。
3. **「南征先锋 + 关索戏」→ 傩戏/驱邪**：本卡可无视「震慑/恐惧」类状态，并移除己方全体的负面状态一次（民俗里关索是**驱邪戏神**）——这是全卡池里独一份的机制位。

**能力 / 特色标签**：`武艺`（自吹型）`刚烈`（嘴硬）
**3 个可游戏化钩子**

## 19. 的卢马 与「的卢跃檀溪」

| 项 | 内容 |
|---|---|
| **名称** | 的卢（dí lú），又名「的颅」 |
| **真实性** | **B 正史仅见裴注，且被裴松之同期学者反驳**——**不是陈寿正文** |
| **归属** | 张武 → 赵云夺之献刘备 → 刘备转赠刘表 → 刘表退还 → 刘备 |

**正史记载**
- **正史正文完全没有「的卢跃檀溪」**。它出自**《三国志·蜀书·先主传》裴松之注引《世语》**：
  > 「備屯樊城，劉表禮焉，憚其為人，不甚信用。曾請備宴會，蒯越、蔡瑁欲因會取備，備覺之，偽如廁，潛遁出。**所乘馬名的盧**，騎的盧走，**墮襄陽城西檀溪水中，溺不得出**。備急曰：『**的盧：今日厄矣，可努力！**』**的盧乃一踴三丈，遂得過**，乘桴渡河，中流而追者至。」([卷32](https://zh.wikisource.org/wiki/三國志/卷32))
- ⚠️ **紧跟着就是同时代人的否定**：**孙盛**直接判定「**此不然之言**。備時羈旅，客主勢殊，若有此變，豈敢晏然終表之世而無釁故乎？**此皆世俗妄說，非事實也。**」——**裴松之把它收进来了，但立刻附上了反驳。这是在《三国志》里能找到的、对「的卢跃檀溪」最权威的质疑。**
- **「妨主」之说在正史中查不到**——那是演义（34 回）里**蒯越**相马时的判断

**演义形象与名场面**（34 回，原文已核）
- 蒯越相马：「此馬**眼下有淚槽，額邊生白點**，名為的盧，**騎則妨主**。張武為此馬而亡。主公不可乘之。」——**刘备把马送给刘表，刘表听蒯越的话又退还**；**伊籍**在路上拦住刘备再劝一次，刘备答：「**凡人死生有命，豈馬所能妨哉！**」([第034回](https://zh.wikisource.org/wiki/三國演義/第034回))
- **檀溪一跃**（本章回目即「劉皇叔躍馬過檀溪」）：「玄德乃加鞭大呼曰：『**的盧，的盧！今日妨吾！**』言畢，那馬忽從水中**湧身而起，一躍三丈，飛上西岸**。」后附苏轼古风一首：「**馬蹄踏碎青玻璃**，天風響處金鞭揮……**西川獨霸真英主，坐下龍駒兩相遇**。」
- ⚠️ **注意台词差异**：**正史是「今日厄矣，可努力」（求助），演义是「今日妨吾」（质问）**——一个是被困求救，一个是明知凶兆仍不认命。**做卡时这两句正好可以做成两个技能名。**

**能力 / 特色标签**：`名马` `悲情`（凶兆宿命）
**3 个可游戏化钩子**
1. **「妨主 / 一跃三丈」→ 双面坐骑**：装备后每回合开始时 30% 概率「妨主」（持有者 −1 生命），但**持有者受到致命伤害时必定触发一次「一跃三丈」——免疫该次伤害并位移到任意列**。高风险高回报的**唯一一张负面+保命复合坐骑**。
2. **「今日厄矣」vs「今日妨吾」→ 二选一台词**：卡面可做**两个技能分支**——选「厄矣」获得治疗/求助效果（拉一个友方单位到自己身边）；选「妨吾」获得攻击性（撞击相邻敌人 2 点伤害）。**同一匹马，两种命运观。**
3. **「孙盛说这是假的」→ 史料质疑彩蛋**：卡面 `note` 直接写「裴松之注引《世语》，孙盛判为『世俗妄说』」；游戏内可做一张**「存疑」标记**——对手可以花费用「质疑」这张装备，成功则该装备本回合失效（**把史学争议做成互动机制，这在卡牌游戏里几乎是没人做过的设计位**）。

## 20. 赤兔马

| 项 | 内容 |
|---|---|
| **名称** | 赤兔（赤菟？） |
| **真实性** | **A 正史正文有载**（《吕布传》），但**「关羽的赤兔」是演义**；**「赤兔」很可能是一类良马的标准，而非某一匹马的名字** |
| **归属** | 董卓（演义）→ 吕布 → 曹操（演义）→ 关羽（演义）→ **马忠（演义，绝食而死）** |

**正史记载**
- 《吕布传》裴注引《曹瞒传》：时人语曰「**人中有呂布，馬中有赤兔**」；**吕布「有良馬曰赤兔」**([维基·赤兔马](https://zh.wikipedia.org/wiki/赤兔馬))
- 《后汉书》称其能「**馳城飛塹**」，「或为一种**红黑色的良马**」
- ⚠️ **正史中吕布被擒后，「赤兔」再无任何记载**——**曹操把它送给关羽、关羽骑它斩颜良、千里走单骑、最后绝食而死，全部是演义**([维基·赤兔马](https://zh.wikipedia.org/wiki/赤兔馬))
- **最关键的考据**（对做卡最有用）：依长沙**马王堆三号汉墓出土帛书《相马经》**「得兔與狐，鳥與魚，得此四物，毋相其餘」「欲得**兔之頭與其肩**……」，可知**兔头、兔肩是汉代相名马的标准之一**——「赤兔马」**是达到该标准的马匹类型，不是单一马的名字**，与「鸟目的白鹤/白鹄」「狐耳的黄耳」同理。另有说「赤兔」乃「**赤菟**」之误，「菟」即虎（楚人称虎为「於菟」）([维基·赤兔马](https://zh.wikipedia.org/wiki/赤兔馬))

**演义 / 民间形象与名场面**
- 董卓→吕布（189 年诱吕布杀丁原）→ 曹操→关羽；关羽死后「赤兔马被赐予**马忠**，遂**绝食而死**」
- **虚构人物祝融夫人也骑「卷毛赤兔」**（90 回原文：「坐下卷毛赤兔馬」）——**同名不同马，正好印证「赤兔是良马标准」的考据**
- 《水浒传》里关羽后裔**关胜**骑赤兔，反派**钱振鹏**骑**卷毛赤兔马**

**能力 / 特色标签**：`名马` `武艺`
**3 个可游戏化钩子**
1. **「相马经标准」→ 可复制的坐骑类型**：卡池里设置**多张「赤兔」系坐骑**（赤兔、卷毛赤兔、赤兔·西凉），共用同一「兔头兔肩」标签，可叠加触发「同类相斥」或「同类共鸣」——**把「赤兔不是一匹马」的考据直接变成卡池结构**。
2. **「换主三次」→ 装备转移**：本装备**可以被任意单位的阵亡触发转移到击杀者身上**（董卓→吕布→曹操→关羽→马忠的链条）——**唯一一张会自己「跳槽」的装备**。
3. **「绝食而死」→ 忠义绑定**：装备者阵亡时，本装备**不能被转移**，直接销毁并给己方全体 +1 攻击一回合（绝食殉主）——与钩子 2 构成**互斥的两种形态**，由玩家选择。

**来源**：[维基·赤兔马](https://zh.wikipedia.org/wiki/赤兔馬)｜[《三国演义》第90回](https://zh.wikisource.org/wiki/三國演義/第090回)（卷毛赤兔原文）

## 21. 张飞之妻夏侯氏 与 夏侯渊 / 夏侯霸 的关系（专条）

**关系链（全部有正史依据）**

```
夏侯渊 ──从父女──▶ 夏侯氏（张飞妻）──▶ 敬哀皇后 + 张皇后（刘禅两任皇后）
   ▲                      ▲
   │从父子                │夫妻
夏侯霸 ◀── 249年奔蜀 ──▶ 张飞
            刘禅：「此夏侯氏之甥也」
```

**正史三条（逐字）**
1. **她是谁**：《魏略》「時霸**從妹**年十三四」——**夏侯霸的从妹 ⇒ 夏侯渊的从女**([卷09](https://zh.wikisource.org/wiki/三國志/卷09))
2. **她做了什么**：「故淵之初亡，**飛妻請而葬之**」——**定军山之战夏侯渊被黄忠斩杀，是敌国大将张飞的妻子出面请求收葬**
3. **她带来了什么**：刘禅对夏侯霸「**此夏侯氏之甥也**，厚加爵寵」——**249 年高平陵之变后，一个魏国降将因为在蜀汉有这门亲戚而得到厚待**

**为什么这条对卡牌设计特别有价值**
- **她是「正史有载、演义完全没写」的类型**——**没有任何被用滥的形象**，做卡时全是原创空间；
- **她是唯一能把蜀、魏两个卡池用「血缘」而非「敌对」连起来的枢纽**；
- 演义不写她的原因维基也说了：**罗贯中只提张飞的子女，不提张飞之妻**——所以她的知名度低，但**史料密度反而高**（三条全是一手）。

**来源**：[《三国志》卷09 裴注引《魏略》](https://zh.wikisource.org/wiki/三國志/卷09)｜[维基·夏侯氏（张飞妻）](https://zh.wikipedia.org/wiki/夏侯氏_(張飛妻))｜[维基·夏侯渊](https://zh.wikipedia.org/wiki/夏侯淵)

## 22. 关羽之子：关平 / 关兴 / 关索 的真实性辨析

| 人物 | 真实性 | 正史依据（逐字） | 演义改动 |
|---|---|---|---|
| **关平** | **A 真实，且是亲生长子** | 「權遣將逆擊羽，**斬羽及子平**於臨沮」；《蜀记》「獲羽及子平」。**正史未言其为义子**([卷36](https://zh.wikisource.org/wiki/三國志/卷36)) | **演义改成「义子」（与史实不符）**：亲父名**关定**、有亲兄**关宁**，刘备主张让关羽与关平结为义父子（28 回）。演义里关平**武勇不逊乃父**，与庞德大战三十回合不分胜负，多次劝阻关羽冲动([维基·关平](https://zh.wikipedia.org/wiki/關平)) |
| **关兴** | **A 真实** | 「**子興嗣**。興字安國，**少有令問**，丞相諸葛亮**深器異之**。弱冠為**侍中、中監軍**，**數歲卒**。子統嗣，**尚公主**，官至虎賁中郎將」([卷36](https://zh.wikisource.org/wiki/三國志/卷36)) | 演义把他写成**北伐主力猛将**，与张苞并称「小关张」，亲手斩杀多名魏将（谭雄、周平、董禧、杨陵等），**死亡时间也大幅推后** |
| **关索** | **C 完全虚构** | **正史无任何记载**；《关羽传》只记平、兴二子 | 见 §13。**古本演义详写、毛本极简**——**做卡时须指定采用哪一版** |

**关键提醒**
- **「关平是义子」是演义的改编，正史视他为亲子。** 中文维基《三国虚构人物列表》专门给「关定」这条加了注：「**正史关平为关羽亲生儿子（长子）**」([维基·三国虚构人物列表](https://zh.wikipedia.org/wiki/三國虛構人物列表))
- **关羽最少还有一个女儿**（孙权求婚被拒，见 §5）——**关羽并非只有儿子**，这与「关索是第三子」的传说无冲突但**与「只有平兴二子」的正史表述并列时必须说清**：正史只列了**两个儿子**，另有一个**未记名的女儿**。
- **关平在民间信仰里是神**：关羽庙中**左为提刀的周仓、右为捧印的关平**，称「**关平帝君**」「关平太子」，形象「面如傅粉，唇若涂脂」；宋代封武夷侯，明代封**竭忠王**。清《关侯祖墓碑记》与道教《关圣太子宝诰》称他生于**光和元年五月十三日**，**母即关羽妻胡氏**——**但这是清代碑记与道教文献，不是正史**([维基·关平](https://zh.wikipedia.org/wiki/關平))
- **关平之妻**：清代地方志《江陵县志》记**赵氏（赵云之女）**为关平之妻，生**关樾**——**同样是清代方志，存疑，但作为卡牌钩子极好用**([维基·关平](https://zh.wikipedia.org/wiki/關平))
