## 0. 结论先行

1. **「凤雏」这个外号是庞德公起的，不是司马徽起的。**
   裴注引《襄阳记》：「诸葛孔明为**卧龙**，庞士元为**凤雏**，司马德操为**水镜**，**皆庞德公语也**。」
   ——司马徽（德操）只是**被命名者之一**（水镜），不是命名者。（**B**）⚠️ 见 §2、§9-1。
2. **司马徽确实说过「伏龙、凤雏」，但那是另一句话、另一个场合**，且**不在《诸葛亮传》正文里**：
   《三国志·蜀书五·诸葛亮传》（**卷三十五**）**裴注引《襄阳记》**：「刘备受世事于司马德操。德操曰：『儒生俗士，岂识时务？识时务者在乎俊杰。**此间自有伏龙、凤雏。**』备问为谁，曰：『诸葛孔明、庞士元也。』」（**B**）完整上下文见 §2.2。
3. **「卧龙凤雏，得一可安天下」不是正史，是演义。**
   维基文库全站 `insource:"得一可安天下"` **在《三国志》（含裴注）0 命中**，只命中**毛本第 35、36、57 回**与嘉靖本。
   毛本**第 35 回**原文作「**伏龙、凤雏，两人得一，可安天下**」（说话人＝**水镜先生司马徽**，对象＝刘备）。（**C**）
4. ⚠️ **「论帝王之秘策，揽倚伏之要最」不是别人对庞统的评语，是庞统自己说的话。**
   出自**裴注引张勃《吴录》**：顾劭问「吾与卿孰愈」，庞统答「陶冶世俗，甄综人物，吾不及卿；**论帝王之秘策，揽倚伏之要最，吾似有一日之长**」。
   ——这是庞统的**自我评价**，说者＝庞统，听者＝顾劭（顾雍之子），**不是司马徽**。（**B**）详见 §3.2。
5. **「庞士元非百里才也」是鲁肃写信给刘备说的，而且诸葛亮也同时推荐了他。**
   《三国志·蜀书七·庞统法正传》（**卷三十七**）**正文**：「吴将**鲁肃**遗先主书曰：『**庞士元非百里才也，使处治中、别驾之任，始当展其骥足耳。**』**诸葛亮亦言之于先主**，先主见与善谭，大器之，以为治中从事。」（**A**）
   ⚠️ 原文是「非百里**才**也」（无「之」字）；成语形式「**非百里之才**」出自**演义第 57 回**与后世类书。详见 §3.1。
6. **上中下三策的全文是正文 A 级，且刘备选的是中策。**
   卷三十七正文：「**先主然其中计，即斩怀、沛，还向成都，所过辄克。**」三策全文见 §4.1。（**A**）
   ⚠️ 上策是「**阴选精兵，昼夜兼道，径袭成都**」，下策是「**退还白帝，连引荆州，徐还图之**」。
7. ⭐ **涪城之会那场君臣冲突是正史正文，A 级，可以放心用。**
   卷三十七正文原句：「**伐人之国而以为欢，非仁者之兵也。**」→ 刘备：「**武王伐纣，前歌后舞，非仁者邪？卿言不当，宜速起出！**」→ 事后：「**向者之论，阿谁为失？**」→ 庞统：「**君臣俱失。**」→「先主大笑，宴乐如初。」
   而且**裴注还挂着两段评论**（习凿齿为庞统辩护、裴松之反驳习凿齿），是三份态度的完整现场。全文见 §4.2。（**A**／裴注 **B**）
8. **他的死是干净的 A 级，而且死得极简。**
   卷三十七正文：「**进围雒县，统率众攻城，为流矢所中，卒，时年三十六。先主痛惜，言则流涕。**」
   紧接着是待遇：刘备给他父亲官（「**拜统父议郎，迁谏议大夫**」），而且「**诸葛亮亲为之拜**」。（**A**）详见 §5。
9. ⚠️ **「靖侯」的追谥时间，本传与旁证互相矛盾 —— 本传是压缩写法，不是当时就谥的。**
   卷三十七正文作「追赐统爵关内侯，**谥曰靖侯**」；但《后主传》（**卷三十三**）明记「**景耀三年秋九月，追谥故将军关羽、张飞、马超、庞统、黄忠**」，
   《华阳国志·卷七》同记景耀三年「**军师庞统曰靖侯**」；且《关张马黄赵传》（**卷三十六**）自己说「**先主时，惟法正见谥**」。
   → **靖侯是景耀三年（260 年）追谥的，距庞统之死（建安十九年＝214 年）约 46 年。**「关内侯」是爵，「靖侯」是谥，**两件事、两个时间**。（**A／⚠️**）详见 §5.3。
10. **落凤坡是演义，正史绝无。** 维基文库全站 `insource:"落鳳坡"` 在**《三国志》全书 0 命中**，
    最早只见**嘉靖本三国志通俗演义**与**毛本第 63 回**（其余为《反三国演义》《蜀碧》《西游记》《清稗类钞》等后世书）。
    正史的死地只有「**雒县**」两个字。（**C**）详见 §6.2。
11. **换马是演义。** 毛本第 63 回：刘备「**吾所骑白马，性极驯熟。军师可骑，万无失一。劣马吾自乘之**」，遂与庞统换马；
    张任军「**骑白马者必是刘备**」→「**箭如飞蝗，只望骑白马者射来**」。**正史无换马，也无「认错人」这回事。**（**C**）
12. **连环计是演义，正史里庞统在赤壁完全没出场。**
    正史的做法是「**曹操自己把船连起来、被黄盖看破**」：《三国志·吴书九·周瑜传》（**卷五十四**）**正文**：
    「瑜部将**黄盖**曰：『今寇众我寡，难与持久。**然观操军船舰，首尾相接，可烧而走也。**』」（**A**）
    《武帝纪》（**卷一**）也只写「公至赤壁，与备战，不利」＋裴注引《山阳公载记》「公船舰为备所烧」——**两处都不见庞统**。
    演义把它改写为**毛本第 47 回《阚泽密献诈降书　庞统巧授连环计》**，由蒋干引荐、庞统向曹操献策。（**C**）详见 §6.1。
13. **耒阳断案是演义，「不到半日将百余日之事尽断毕了」这十四个字正史没有。**
    正史只有六个字：「**统以从事守耒阳令，在县不治，免官。**」（卷三十七正文，**A**）
    演义扩写成毛本**第 57 回**《柴桑口卧龙吊丧　**耒阳县凤雏理事**》一整套张飞巡县、庞统半日断案的戏。（**C**）详见 §6.4。
14. ⚠️ **庞统与蒋琬没有任何亲属关系 —— 「从弟／表弟」的说法未找到原文。**
    维基文库 `insource:"龐統" prefix:三國志 insource:"蔣琬"` **0 命中**；《蒋琬传》（**卷四十四**）**通篇没有一个「庞」字**（唯一同字是蒋琬让茂才名单里的「**庞延**」，另一人）。
    两人真正的关联是**叙事同构**，而且相当惊人：
    诸葛亮为**蒋琬**说过「**蒋琬，社稷之器，非百里之才也**」（卷四十四**正文 A**），蒋琬也有「**众事不理，时又沉醉**，先主大怒，将加罪戮」的同款故事。
    → **「大材小用、居小任而废事、诸葛亮出面保」是一个被用了两次的母题**，不是亲属关系。（**A**）详见 §7.14、§9-6。
15. **正史里他没有「副军师中郎将」这个官。** 卷三十七正文：「亲待亚于诸葛亮，**遂与亮并为军师中郎将**」——
    **两人是同一个官号**。「**副**军师中郎将」是演义毛本第 57 回加的。（**A**／**C**）详见 §6.5。
16. **陈寿把他比作荀彧。** 卷三十七「评曰」：「**庞统雅好人流，经学思谋，于时荆、楚谓之高俊。**法正着见成败，有奇画策算，然不以德素称也。
    拟之魏臣，**统其荀彧之仲叔**，正其程、郭之俦俪邪？」（**A**）——这是陈寿给庞统的最高定位，也是全篇最"重"的一句。

## 2. 出身与「凤雏」之名

### 2.1 出身（A，正文）

> 「**庞统字士元，襄阳人也。少时朴钝，未有识者。颍川司马徽清雅有知人鉴，统弱冠往见徽，徽采桑于树上，坐统在树下，共语自昼至夜。徽甚异之，称统当南州士之冠冕，由是渐显。**」
> ——《三国志·蜀书七·庞统法正传》（**卷三十七**）

**要点**：

| 项 | 内容 | 等级 |
|---|---|---|
| 字 | **士元** | **A** |
| 籍贯 | **襄阳**（今湖北襄阳） | **A** |
| 早年 | 「**少时朴钝，未有识者**」——**不是神童，是"看起来笨"** | **A** |
| 转折点 | 弱冠去见司马徽，**司马徽在树上采桑、庞统坐在树下**，从白天谈到夜里 | **A** |
| 司马徽给的评语 | 「**称统当南州士之冠冕**」 | **A** |
| 效果 | 「**由是渐显**」 | **A** |

> ⚠️ **「采桑于树上，坐统在树下」这个画面是正文 A 级**，而且是庞统整个人生故事的**起点**——
> 一个被当成钝才的年轻人，跟一个在树上采桑的老先生聊了**一整天**，从此出名。

### 2.2 「凤雏」是谁起的 —— **庞德公，不是司马徽**（B）

**原始出处（裴注引《襄阳记》，挂在「由是渐显」之后）**：

> 「《襄阳记》曰：**诸葛孔明为卧龙，庞士元为凤雏，司马德操为水镜，皆庞德公语也。**德公，襄阳人。孔明每至其家，独拜床下，德公初不令止。德操尝造德公，值其渡沔，上祀先人墓，德操径入其室，呼德公妻子，使速作黍，『徐元直向云有客当来就我与庞公谭。』其妻子皆罗列拜于堂下，奔走供设。须臾，德公还，直入相就，不知何者是客也。德操年小德公十岁，兄事之，呼作庞公，故世人遂谓庞公是德公名，非也。德公子山民，亦有令名，**娶诸葛孔明小姊**，为魏黄门吏部郎，早卒。子涣，字世文，晋太康中为牂牁太守。**统，德公从子也**，少未有识者，**惟德公重之，年十八，使往见德操**。德操与语，既而叹曰：『**德公诚知人，此实盛德也。**』」
> ——《三国志·蜀书七·庞统法正传》**裴注引《襄阳记》**（**卷三十七**）

**这段是本文献密度最高的一段，逐条拆开**：

| 项 | 原文 | 等级 |
|---|---|---|
| **三个外号一句话给出** | 「诸葛孔明为**卧龙**，庞士元为**凤雏**，司马德操为**水镜**」 | **B** |
| **命名者** | 「**皆庞德公语也**」——**庞德公** | **B** |
| **庞统与庞德公的关系** | 「**统，德公从子也**」——**族侄**（从子＝兄弟之子／同族侄辈） | **B** |
| **庞统与诸葛亮的关系** | 庞德公之子**庞山民娶了诸葛亮的"小姊"（姊）** → 诸葛亮是庞统族兄的姐夫 | **B** |
| **庞统见司马徽的引荐人** | 「**年十八，使往见德操**」——**是庞德公让他去的** | **B** |
| **司马徽对庞德公的服气** | 「德操年小德公十岁，**兄事之**」＋「**德公诚知人，此实盛德也**」 | **B** |
| **庞德公的家风** | 司马徽径直进他家、呼他妻子做饭，「**不知何者是客也**」——宾主不分的一家人 | **B** |

> ⚠️ **「卧龙、凤雏、水镜」这三个人一起出现，是襄阳一个圈子里的"评语"**，
> 命名者庞德公是**诸葛亮与庞统共同的长辈／亲戚**。
> 这就是「卧龙凤雏」这个对举**在正史里的真实来源** —— 不是天下人这么说，是**一个襄阳老人给他们起的绰号**。

### 2.3 司马徽的原话：「此间自有伏龙、凤雏」（B）

⚠️ **这句话不在《庞统传》里，在《诸葛亮传》裴注里；也不在正文，在裴注。**

> 「时先主屯新野。徐庶见先主，先主器之，谓先主曰：『诸葛孔明者，卧龙也，将军岂愿见之乎？』
> **《襄阳记》曰：刘备受世事于司马德操。德操曰：『儒生俗士，岂识时务？识时务者在乎俊杰。此间自有伏龙、凤雏。』备问为谁，曰：『诸葛孔明、庞士元也。』**
> 先主曰：『君与俱来。』庶曰：『此人可就见，不可屈致也。将军宜枉驾顾之。』由是先主遂诣亮，凡三往，乃见。」
> ——《三国志·蜀书五·诸葛亮传》**裴注引《襄阳记》**（**卷三十五**）

**四问四答**：

| 问 | 答 |
|---|---|
| **谁说的？** | **司马徽（司马德操，号水镜）** |
| **对谁说的？** | **刘备**（「刘备受世事于司马德操」） |
| **完整上下文？** | 刘备向司马徽请教天下事 → 司马徽先贬低儒生俗士（「**儒生俗士，岂识时务？识时务者在乎俊杰**」）→ 再抛出「**此间自有伏龙、凤雏**」→ 刘备追问是谁 → 「**诸葛孔明、庞士元也**」 |
| **A 还是 B？** | **B** —— 出自**裴注引《襄阳记》**，《诸葛亮传》**正文没有这一段** |

## 3. 评价考：非百里之才 / 论帝王之秘策 / 卧龙凤雏得一可安天下

### 3.1 「庞士元非百里才也」—— 鲁肃写信，诸葛亮同时开口（**A**）

**原文全段**（卷三十七**正文**）：

> 「**先主领荆州，统以从事守耒阳令，在县不治，免官。吴将鲁肃遗先主书曰：『庞士元非百里才也，使处治中、别驾之任，始当展其骥足耳。』诸葛亮亦言之于先主，先主见与善谭，大器之，以为治中从事。**」
> ——《三国志·蜀书七·庞统法正传》（**卷三十七**）

**逐项核实**：

| 问 | 答 |
|---|---|
| **说话人是谁？** | **鲁肃**（且是**写信**：「遗先主书曰」，是**书面**不是当面） |
| **对谁说的？** | **刘备（先主）** |
| **只有鲁肃吗？** | **不是。**紧接着一句「**诸葛亮亦言之于先主**」——**诸葛亮也向刘备说了同样的话**。**两个人、两条渠道** |
| **原文字面** | 「庞士元**非百里才**也」（**无「之」字**） |
| **「非百里之才」这个成语从这来吗？** | ⚠️ **半是**。意思是这里来的；但**四字成语形式「非百里之**才**」不见于《三国志》正文**——维基文库 `insource:"非百里之才"` 命中的是**《三国演义》第 57 回**、**《太平御览》卷 263**、《册府元龟》《资治通鉴》（胡三省音注本）《续后汉书》等**后世类书与史抄**。**引用时写「非百里才」才与卷三十七一致。** |
| **结果** | 「先主**见与善谭，大器之**，以为**治中从事**」——见一面、聊一次，立刻改观 |
| **等级** | **A**（正文） |

**演义版（C，用于对照）**——毛本**第 57 回**把信写全了：

> 「庞士元**非百里之才**，使处治中别驾之任，始当展其骥足。**如以貌取之，恐负所学，终为他人所用，实可惜也。**」
> ——毛本《三国演义》第 57 回

⚠️ **演义加了两句正文没有的话**：「如以貌取之，恐负所学，终为他人所用，实可惜也。」
（这句其实与《三国志·吴书·鲁肃传》裴注引《吴书》里鲁肃荐诸葛瑾的语境相近，但**不是庞统传的原文**，属演义增饰。）

**诸葛亮的版本（C，演义第 57 回）**：

> 「孔明笑曰：『**士元非百里之才，胸中之学，胜亮十倍。**亮曾有荐书在士元处，曾达主公否？』」
> ——毛本《三国演义》第 57 回

### 3.2 ⭐「论帝王之秘策，揽倚伏之要最」—— **是庞统自己的话**（B）

> ⚠️ **设计者记忆需要更正**：这**不是司马徽对庞统的评价**，也**不是《襄阳记》**，而是
> **裴注引张勃《吴录》**里，**庞统对顾劭说的话**，内容是**自我评价**。

**原文全段**（裴注引张勃《吴录》，挂在「陆子可谓驽马有逸足之力，顾子可谓驽牛能负重致远也」之后）：

> 「张勃**吴录**曰：或问统曰：『如所目，陆子为胜乎？』统曰：『驽马虽精，所致一人耳。驽牛一日行三百里，所致岂一人之重哉！』
> **劭就统宿，语，因问：『卿名知人，吾与卿孰愈？』统曰：『陶冶世俗，甄综人物，吾不及卿；论帝王之秘策，揽倚伏之要最，吾似有一日之长。』劭安其言而亲之。**」
> ——《三国志·蜀书七·庞统法正传》**裴注引张勃《吴录》**（**卷三十七**）

**四问四答**：

| 问 | 答 |
|---|---|
| **谁说的？** | **庞统自己**（不是司马徽、不是任何人对他评价） |
| **对谁说的？** | **顾劭**（顾雍之子；「劭就统宿，语」——**顾劭到庞统那儿住下、夜谈**） |
| **什么场合？** | 顾劭问「**吾与卿孰愈**」（你跟我谁更强），庞统先让一步，再给自己定位 |
| **等级** | **B** —— 裴注引张勃《吴录》，**《三国志》正文无** |

**这句话的结构值得注意**：庞统把它拆成**两半互为对照**——

| 半句 | 内容 | 归属 |
|---|---|---|
| 前半 | 「**陶冶世俗，甄综人物**」 | 「**吾不及卿**」→ 让给顾劭 |
| 后半 | 「**论帝王之秘策，揽倚伏之要最**」 | 「**吾似有一日之长**」→ 留给自己 |

> ⭐ **「吾似有一日之长」这六个字极有戏**：**不是狂妄，是"我大概就这一项比你强一点"**。
> 而且顾劭的反应是「**安其言而亲之**」——**听了很舒服，跟他更亲近了**。
> 对照他同段里评陆绩、顾劭「**驽马有逸足之力**／**驽牛能负重致远**」的刻薄比喻，这是个**很会说话的人**。

**演义原文（毛本第 35 回，说话人＝水镜先生司马徽）**：

> 「玄德曰：『备亦尝侧身以求山谷之遗贤，奈未遇其人何！』水镜曰：『岂不闻孔子云：「十室之邑，必有忠信。」何谓无人？』……

> 玄德曰：『伏龙、凤雏何人也？』水镜**抚掌大笑**曰：『好！好！』玄德再问时，水镜曰：『天色已晚，将军可于此暂宿一宵，明日当言之。』」
> ——毛本《三国演义》**第 35 回**《玄德南漳逢隐沦　单福新野遇英主》

**⚠️ 三处必须核对的字**：

1. 原文是「**伏龙**、凤雏」，**不是「卧龙、凤雏」**（与 §2.3 的裴注用字一致）。
2. 原文有「**两人**」二字：「伏龙、凤雏，**两人**得一，可安天下」。
3. 说话人是**水镜先生司马徽**，说完「**抚掌大笑**」，还**故意卖关子**（「天色已晚……明日当言之」）。

**毛本第 36 回徐庶重述、第 57 回刘备重述，两处都是同一句**：

> 「玄德曰：『昔水镜先生曾为备言：「**伏龙、凤雏，两人得一，可安天下。**」今所云莫非即伏龙、凤雏乎？』庶曰：『**凤雏乃襄阳庞统也。**伏龙正是诸葛孔明。』」（**第 36 回**）
> 「玄德喜曰：『昔司马德操言：「**伏龙、凤雏，两人得一，可安天下。**」今吾二人皆得，**汉室可兴矣**。』遂拜庞统为**副军师中郎将**，与孔明共赞方略。」（**第 57 回**）

> ⚠️ **这句话本身是 C 级，但它非常有用**：它是**「庞统与诸葛亮并列」这个对举在通俗文化里的唯一一句口号**，
> 也是**现代所有三国游戏里庞统设计的底层依据**（见 §12）。**用它就必须标 C。**

### 3.4 陈寿的定评：比作荀彧（A）

> 「评曰：**庞统雅好人流，经学思谋，于时荆、楚谓之高俊。**法正着见成败，有奇画策算，然不以德素称也。**拟之魏臣，统其荀彧之仲叔**，正其程、郭之俦俪邪？」
> ——《三国志·蜀书七·庞统法正传》「**评曰**」（**卷三十七**）

| 项 | 内容 | 等级 |
|---|---|---|
| 陈寿给的八字 | 「**雅好人流，经学思谋**」 | **A** |
| 时人的定位 | 「于时**荆、楚谓之高俊**」 | **A** |
| 陈寿的类比 | 「**统其荀彧之仲叔**」——**把他比作荀彧**（「仲叔」＝次一等／同列第二） | **A** |
| 同传法正的类比 | 「正其**程、郭**之俦俪」——程昱、郭嘉之流 | **A** |

> ⭐ **注意这个分档**：陈寿把**庞统往荀彧那一档放**，把**法正往程昱、郭嘉那一档放**。
> 这是陈寿对两人**不同量级**的判断，也是**同传并列但不等价**的证据。

### 3.5 杨戏《季汉辅臣赞》（A，卷四十五）

> 「**军师美至，雅气晔晔，致命明主，忠情发臆，惟此义宗，亡身报德。** ──赞**庞士元**」
> ——《三国志·蜀书十五·邓张宗杨传》杨戏《季汉辅臣赞》（**卷四十五**，**正文**）

**要点**：
- 杨戏称他「**军师**」（官号），给的六个字是「**美至**」「**雅气晔晔**」。
- 「**致命明主，忠情发臆**」＝把命交给明主，忠心从胸臆里发出来。
- 「**惟此义宗，亡身报德**」＝**为了"义"而死，以死报德**——这是蜀汉内部对他的官方定性。
- ⚠️ 这与陈寿的「经学思谋」角度**不同**：杨戏讲的是**忠义**，陈寿讲的是**才学**。

## 4. 入蜀：上中下三策（全文）与涪城之会

### 4.1 ⭐ 上中下三策（**A，正文，全文**）

**背景（前一段，同一处正文）**：

> 「**益州牧刘璋与先主会涪，统进策曰：『今因此会，便可执之，则将军无用兵之劳而坐定一州也。』先主曰：『初入他国，恩信未著，此不可也。』**」
> ——《三国志·蜀书七·庞统法正传》（**卷三十七**）

👉 **这是庞统的第一次献计（涪城会上一举擒刘璋），刘备当场否掉了。三策是第二次。**

**⭐ 三策全文（逐字）**：

> 「璋既还成都，先主当为璋北征汉中，**统复说曰：**
> 『**阴选精兵，昼夜兼道，径袭成都；璋既不武，又素无预备，大军卒至，一举便定，此上计也。**
> **杨怀、高沛，璋之名将，各仗强兵，据守关头，闻数有笺谏璋，使发遣将军还荆州。将军未至，遣与相闻，说荆州有急，欲还救之，并使装束，外作归形；此二子既服将军英名，又喜将军之去，计必乘轻骑来见，将军因此执之，进取其兵，乃向成都，此中计也。**
> **退还白帝，连引荆州，徐还图之，此下计也。**
> **若沈吟不去，将致大困，不可久矣。**』
> **先主然其中计，即斩怀、沛，还向成都，所过辄克。**」
> ——《三国志·蜀书七·庞统法正传》（**卷三十七**）

**三策拆解表**：

| 策 | 原文 | 内容要点 | 风险 |
|---|---|---|---|
| **上计** | 「**阴选精兵，昼夜兼道，径袭成都**」 | 挑精兵、昼夜赶路、**直扑成都**；理由：「璋既不武，又素无预备，大军卒至，一举便定」 | **最快也最险**（孤军深入、后方未定） |
| **中计** | 「杨怀、高沛……**将军因此执之，进取其兵，乃向成都**」 | **骗杀杨怀、高沛两名关将、吞并其兵**，再打成都。手法：「遣与相闻，说荆州有急，欲还救之，**并使装束，外作归形**」（假装修假、做出回家的样子） | **中速**。原文自陈成功率理由：「此二子既服将军英名，又喜将军之去，计必乘轻骑来见」 |
| **下计** | 「**退还白帝，连引荆州，徐还图之**」 | **退回白帝城、把荆州的力量拉过来，慢慢再图** | **最稳也最慢** |
| **附加警告** | 「**若沈吟不去，将致大困，不可久矣**」 | **第四条路：犹豫不决 = 大困** | ⚠️ 这句是全段最狠的一句，**它不是"第四策"，是对"什么都不做"的判词** |

**⚠️ 刘备选了哪一策？→ 中策。原文：**

> 「**先主然其中计**，即斩怀、沛，还向成都，所过辄克。」

| 问 | 答 |
|---|---|
| **选了哪一策？** | **中策**（「先主然其中计」） |
| **执行了吗？** | 执行了。「**即斩怀、沛**」（＝杨怀、高沛），然后「还向成都，所过辄克」 |
| **等级** | **A**（正文） |
| **旁证** | 《华阳国志·卷五》同记「**刘主然其中计。即斩怀等**」；《资治通鉴》卷六十七同 |
| **旁证二** | 《先主传》（**卷三十二**）只记前半段的「便可于会所袭璋」，**不记三策**——⚠️ 三策**只见《庞统传》** |

**演义版的三策（C，毛本第 62 回）—— 措辞不同，务必分清**：

> 「统曰：『**只今便选精兵，昼夜兼道径袭成都，此为上计。杨怀、高沛乃蜀中名将，各仗强兵拒守关隘；今主公佯以回荆州为名，二将闻知，必来相送；就送行处，擒而杀之，夺了关隘，先取涪城，然后却向成都，此中计也。退还白帝，连夜回荆州，徐图进取，此为下计。若沈吟不去，将至大困，不可救矣。**』
> 玄德曰：『**军师上计太促，下计太缓：中计不迟不疾，可以行之。**』」
> ——毛本《三国演义》第 62 回

⚠️ **演义给刘备加了一句正史没有的评语**：「**上计太促，下计太缓：中计不迟不疾，可以行之。**」
——正史只有**「先主然其中计」四个字**，**没有解释为什么**。演义这句更好用、更有"戏"，但**它是 C 级，不能写成正史**。

### 4.2 ⭐ 涪城之会：「君臣俱失」—— **A，正文，全段可抄**

> ⚠️ **设计者记忆基本正确，这段确实是正文原文**，但**有三个字要核对**（见下表）。

**原文全段**（卷三十七正文，紧接三策之后）：

> 「**于涪大会，置酒作乐，谓统曰：『今日之会，可谓乐矣。』统曰：『伐人之国而以为欢，非仁者之兵也。』先主醉，怒曰：『武王伐纣，前歌后舞，非仁者邪？卿言不当，宜速起出！』于是统逡巡引退。先主寻悔，请还。统复故位，初不顾谢，饮食自若。先主谓曰：『向者之论，阿谁为失？』统对曰：『君臣俱失。』先主大笑，宴乐如初。**」
> ——《三国志·蜀书七·庞统法正传》（**卷三十七**）

**逐句拆开（这一段是本文"戏"最足的一段）**：

| 环节 | 原文 | 要点 |
|---|---|---|
| ① 刘备发话 | 「**今日之会，可谓乐矣。**」 | 刚打下涪城、置酒作乐，刘备**主动**把话头递给庞统 |
| ② 庞统顶回去 | 「**伐人之国而以为欢，非仁者之兵也。**」 | ⚠️ 是「**欢**」，不是「乐」；是「**非仁者之兵**」，不是「非仁者」 |
| ③ 刘备翻脸 | 「**武王伐纣，前歌后舞，非仁者邪？卿言不当，宜速起出！**」 | ⚠️ 是「**前歌后舞**」（不是演义里的「作乐象功」）；**「宜速起出」＝你给我出去** |
| ④ 庞统的动作 | 「于是统**逡巡引退**」 | ⚠️ **「逡巡」＝迟疑徘徊地**退下 —— **不是摔门而去** |
| ⑤ 刘备后悔 | 「先主**寻悔，请还**」 | **「寻」＝不久**；是他**请**庞统回来的 |
| ⑥ ⭐ 庞统的态度 | 「统复故位，**初不顾谢，饮食自若**」 | **回到原位、一句道歉都没有、照吃照喝** —— 这九个字全段最硬 |
| ⑦ 刘备追问 | 「**向者之论，阿谁为失？**」 | ⚠️ 是「**向者**」（刚才），不是「昨日」；「**阿谁**」＝谁 |
| ⑧ 庞统的回答 | 「统对曰：『**君臣俱失。**』」 | **四个字，各打五十大板** —— 不认全错，也不全推给君主 |
| ⑨ 收场 | 「**先主大笑，宴乐如初。**」 | **一笑而过，接着喝** |

**⚠️ 与演义的差异（C，毛本第 62 回）—— 这几处最容易混**：

| 项 | 正史（卷三十七，**A**） | 演义（毛本第 62 回，**C**） |
|---|---|---|
| 庞统的话 | 「伐人之国而以为**欢**，非仁者**之兵**也」 | 「伐人之国而以为**乐**，非仁者**之兵**也」 |
| 刘备的反问 | 「武王伐纣，**前歌后舞**，非仁者**邪**？」 | 「吾闻昔日武王伐纣，**作乐象功**，此亦非仁者之兵**欤**？」 |
| 庞统的退场 | 「**逡巡引退**」 | 「庞统**大笑而起**」 |
| 刘备的道歉 | 无（只有「先主寻悔，请还」） | 「**次早穿衣升堂，请庞统谢罪曰：『昨日酒醉，言语触忤。幸勿挂怀。』**」 |
| 刘备的话 | 「**向者**之论，阿谁为失？」 | 「**昨日之言，惟吾有失。**」 |
| 庞统的回答 | 「**君臣俱失。**」 | 「**君臣俱失，何独主公？**」 |

> ⚠️ **判断口径**：**「君臣俱失」四个字是正史原文（A）**；
> 而**「惟吾有失」「何独主公」「次早请罪」「大笑而起」都是演义加的（C）**。
> **卡面 flavor 若用「君臣俱失」，可以标 A；若用「惟吾有失」，必须标 C。**

### 4.3 裴注里挂着的两段评论（B）—— 关于「君臣俱失」的两种立场

**① 习凿齿：为庞统辩护**（裴注引习凿齿，紧挂在这段之后）：

> 「**习凿齿曰：**夫霸王者，必体仁义以为本，仗信顺以为宗，一物不具，则其道乖矣。今刘备袭夺璋土，权以济业，负信违情，德义俱愆，虽功由是隆，宜大伤其败，譬断手全躯，何乐之有？
> **庞统惧斯言之泄宣，知其君之必悟，故众中匡其失，而不修常谦之道，矫然太当，尽其蹇谔之风。**夫上失而能正，是有臣也，纳胜而无执，是从理也；有臣则陛隆堂高，从理则群策毕举；
> **一言而三善兼明，暂谏而义彰百代，可谓达乎大体矣。**若惜其小失而废其大益，矜此过言，自绝远谠，能成业济务者，未之有也。」
> ——《三国志·蜀书七·庞统法正传》**裴注引习凿齿**（**卷三十七**）

**② 裴松之：反驳习凿齿，认为刘备有错、庞统无失**：

> 「**臣松之以为**谋袭刘璋，计虽出于统，然违义成功，本由诡道，心既内疚，则欢情自戢，故闻备称乐之言，不觉率尔而对也。
> 备宴酣失时，事同乐祸，自比武王，曾无愧色，**此备有非而统无失**，其云『君臣俱失』，**盖分谤之言耳**。
> 习氏所论，虽大旨无乖，然推演之辞，近为流宕也。」
> ——同上，**裴松之案**（**卷三十七**）

| 说者 | 立场 | 关键句 |
|---|---|---|
| **习凿齿**（东晋） | **庞统做得对**，而且「**一言而三善兼明**」 | 「众中匡其失，而不修常谦之道，**矫然太当，尽其蹇谔之风**」 |
| **裴松之**（刘宋） | **刘备有错、庞统无失**；「君臣俱失」是**替君主分担舆论** | 「此备有非而统无失，其云『君臣俱失』，**盖分谤之言耳**」 |

> ⭐ **「分谤」这两个字是裴松之给的，是这段冲突最精彩的一层解读**：
> 庞统说「君臣俱失」，**不是真的认为自己错了，是把君主的错往自己身上分一半**。
> ——**这是 B 级（裴注），引用时必须写「裴松之案」，不能写成陈寿的话。**

### 4.4 前情：庞统怎么劝刘备取益州（**B**，裴注引《九州春秋》）

> 「《九州春秋》曰：**统说备曰：『荆州荒残，人物殚尽，东有吴孙，北有曹氏，鼎足之计，难以得志。今益州国富民强，户口百万，四部兵马，所出必具，宝货无求于外，今可权借以定大事。』**
> **备曰：『今指与吾为水火者，曹操也，操以急，吾以宽；操以暴，吾以仁；操以谲，吾以忠；每与操反，事乃可成耳。今以小故而失信义于天下者，吾所不取也。』**
> **统曰：『权变之时，固非一道所能定也。兼弱攻昧，五伯之事。逆取顺守，报之以义，事定之后，封以大国，何负于信？今日不取，终为人利耳。』备遂行。**」
> ——《三国志·蜀书七·庞统法正传》**裴注引《九州春秋》**（**卷三十七**）

| 项 | 内容 | 等级 |
|---|---|---|
| 庞统的立论 | 荆州「荒残，人物殚尽」，益州「**国富民强，户口百万**」 | **B** |
| ⭐ 刘备的名言 | 「**操以急，吾以宽；操以暴，吾以仁；操以谲，吾以忠；每与操反，事乃可成耳**」 | **B**（裴注，**《先主传》正文无此语**） |
| 庞统的反驳 | 「**权变之时，固非一道所能定也。兼弱攻昧，五伯之事。逆取顺守，报之以义，事定之后，封以大国，何负于信？**」 | **B** |
| 结果 | 「**备遂行**」 | **B** |
| 旁证 | 《资治通鉴》**卷六十六**把它采入**正文**（但《通鉴》是北宋书，不改等级） | — |

> ⚠️ **「操以急，吾以宽」这组对句在《三国志·先主传》正文里找不到**，出处是**裴注引《九州春秋》**（B）。
> 演义毛本第 60 回把它改写进刘备口中，是 C。

## 5. 死与身后

### 5.1 正史的死（**A，正文，全段**）

> 「**进围雒县，统率众攻城，为流矢所中，卒，时年三十六。先主痛惜，言则流涕。拜统父议郎，迁谏议大夫，诸葛亮亲为之拜。追赐统爵关内侯，谥曰靖侯。统子宏，字巨师，刚简有臧否，轻傲尚书令陈袛，为袛所抑，卒于涪陵太守。统弟林，以荆州治中从事参镇北将军黄权征吴，值军败，随权入魏，魏封列侯，至巨鹿太守。**」
> ——《三国志·蜀书七·庞统法正传》（**卷三十七**）

**逐项核实（设计者的三个问题）**：

| 问 | 答 | 等级 |
|---|---|---|
| **原文全段？** | 见上，**全段就这一整段**，没有更多 | **A** |
| **死法？** | 「**进围雒县，统率众攻城，为流矢所中，卒**」——**围雒县、亲自率众攻城、被流矢（乱飞的箭）射中而死** | **A** |
| **年纪？** | 「**时年三十六**」 | **A** |
| **刘备的反应？** | ⭐ 原文是「**先主痛惜，言则流涕**」（**不是「言则流涕」单独一句**，前面还有「先主痛惜」四字） | **A** |
| **对家属？** | 「**拜统父议郎，迁谏议大夫，诸葛亮亲为之拜**」——**给庞统的父亲官做，而且是诸葛亮亲自去拜** | **A** |
| **追赐关内侯？** | ✅ 原文「**追赐统爵关内侯**」 | **A** |
| **谥「靖侯」？** | 原文「**谥曰靖侯**」——**字是对的**，但**时间有问题**，见 §5.3 | **A／⚠️** |

> ——**这是一条 A 级、可直接用的「庞统 × 诸葛亮」关系证据，比任何游戏里的"羁绊"都硬。**

### 5.3 ⚠️ 换马：**演义**（C）

| 项 | 内容 | 等级 |
|---|---|---|
| **换马** | 毛本第 63 回：庞统坐下马「**眼生前失**」把他掀下来，刘备说「**吾所骑白马，性极驯熟。军师可骑，万无失一。劣马吾自乘之**」，遂换 | **C** |
| **换马的后果** | 张任军士「**遥指军中大将：『骑白马者必是刘备。』**」→「**箭如飞蝗，只望骑白马者射来**」 | **C** |
| **庞统的道谢** | 「庞统谢曰：『**深感主公厚恩。虽万死亦不能报也。**』」 | **C** |
| **正史有没有？** | ❌ **完全没有**。卷三十七正文对死前的情形只有「**进围雒县，统率众攻城**」九个字，**没有马、没有白马、没有认错人** | **A**（正史之无） |

### 5.4 ⚠️ 死后的待遇：**两个时间、两件事**（A／⚠️）

**《庞统传》原文的写法**（卷三十七）：一句话里塞了两件事 ——
「**追赐统爵关内侯，谥曰靖侯。**」

**但旁证指向两个不同的时间**：

| 事情 | 出处 | 时间 | 等级 |
|---|---|---|---|
| **追赐爵关内侯** | 卷三十七「追赐统爵关内侯」 | 推测在死后不久（**先主时**） | **A**（时间无直接记载） |
| **谥曰靖侯** | 卷三十七「谥曰靖侯」 | ⚠️ 与下两条冲突 | **A**（文字）／**⚠️**（时间） |
| **追谥的旁证一** | 《后主传》（**卷三十三**）：「**三年秋九月，追谥故将军关羽、张飞、马超、庞统、黄忠。**」 | **景耀三年＝260 年** | **A** |
| **追谥的旁证二** | 《华阳国志·卷七·刘后主志》：在记「三年」的那一条里写「秋九月，追谥故前将军关羽曰壮缪侯，车骑将军张飞曰桓侯，骠骑将军马超曰威侯，**军师庞统曰靖侯**，后将军黄忠曰刚侯」，其下紧接「**四年，春三月，追谥故镇军赵云曰顺平侯**」 | ⚠️ 该条「三年」**下与卷三十三的景耀四年追谥赵云完全吻合**，故定为**景耀三年＝260 年**；但该条原文夹注作「魏景初元年也」（＝237 年，**与蜀汉景耀三年不合，疑为传写之误**），且「靖」字**元丰本作「静」** | **B／⚠️** |
| **反证** | 《关张马黄赵传》（**卷三十六**）：「初，**先主时，惟法正见谥**；后主时……于是关羽、张飞、马超、庞统、黄忠及云**乃追谥**，时论以为荣。」 | ⚠️ **明说先主时只有法正得谥** | **A** |

**结论**：

> ⚠️ **「靖侯」是景耀三年（260 年）追谥的，距庞统之死（建安十九年＝214 年）约 46 年。**
> 卷三十七把「追赐爵关内侯」与「谥曰靖侯」写在紧接死亡之后，是**陈寿的压缩笔法**，
> **不是"死的时候就把两件事都办了"**。《后主传》＋《华阳国志》＋《关张马黄赵传》三处旁证一致指向 260 年。
> **设计者若要在卡面写"谥靖侯"，写"景耀三年追谥"才准确；写"死后即谥"会与卷三十六自相矛盾。**

**「靖」字的谥法含义**：⚠️ **未找到原文**（《逸周书·谥法解》有「柔德安众曰靖」「恭己鲜言曰靖」等条，但**本轮未核到蜀汉这次追谥所用的谥法条文**，
《云别传》里赵云谥议是明写谥法条文的，庞统这次**没有留下谥议文本**）。见 §10。

**裴注补充（B）—— 庞林妻子的故事**：

## 6. 演义加成逐条

> 底本：维基文库毛本《三国演义》120 回。以下四条是庞统在通俗文化里的**四大名场面**，
> 逐条给出**回目 + 原文 + 与正史的关系 + 等级**。

### 6.1 赤壁连环计 —— **演义（C）；正史是曹操自己连的船**（A）

**演义原文（毛本第 47 回《阚泽密献诈降书　庞统巧授连环计》）**：

> 「原来襄阳庞统，字士元，因避乱寓居江东。**鲁肃曾荐之于周瑜**，统未及往见。瑜先使肃问计于统曰：『破曹当用何策？』
> **统密谓肃曰：『欲破曹兵，须用火攻；但大江面上，一船着火，余船四散。除非献"连环计"，教他钉作一处，然后功可成也。』**
> 肃以告瑜，瑜深服其论，因谓肃曰：『为吾行此计者，非庞士元不可。』」（同上）
>
> 「（蒋干）问姓名，答曰：『姓庞，名统，字士元。』干曰：『**莫非凤雏先生否？**』统曰：『**然也。**』」（同上）
>
> 「统曰：『……**若以大船小船各皆配搭，或三十为一排，或五十为一排，首尾用铁环连锁，上铺阔板，休言人可渡，马亦可走矣。乘此而行，任他风浪潮水上下，复何惧哉？**』
> 曹操下席而谢曰：『**非先生良谋，安能破东吴耶？**』……操即时传令，唤军中铁匠，**连夜打造连环大钉，锁住船只**。」（同上）
>
> 「后人有诗曰：赤壁鏖兵用火攻，运筹决策尽皆同。**若非庞统连环计，公瑾安能立大功？**」（同上）
>
> 「（徐庶）一把扯住统曰：『你好大胆！**黄盖用苦肉计，阚泽下诈降书，你又来献连环计，只恐烧不尽绝！**你们拿出这等毒手来，只好瞒曹操，也须瞒我不得！』吓得庞统魂飞散。」（同上）

**⚠️ 正史有没有？→ 没有。正史是曹操自己连的船。**

| 项 | 内容 | 等级 |
|---|---|---|
| **正史原文** | 《三国志·吴书九·周瑜传》（**卷五十四**）**正文**：「瑜部将**黄盖**曰：『今寇众我寡，难与持久。**然观操军船舰，首尾相接，可烧而走也。**』」 | **A** |
| **谁连接的？** | **曹操自己的船「首尾相接」**——是曹军的**既有状态**，**不是谁去献计让他连的** | **A** |
| **谁看破的？** | **黄盖**（不是庞统、不是周瑜） | **A** |
| **庞统在赤壁出场了吗？** | ❌ **《周瑜传》正文无庞统**；《武帝纪》（**卷一**）只有「公至赤壁，与备战，不利」＋裴注引《山阳公载记》「**公船舰为备所烧**」——**两处都不见庞统** | **A**（正史之无） |
| **庞统与赤壁的唯一史实交集** | 战后他**做过周瑜的功曹**（裴注引《江表传》：「卿为**周公瑾功曹**」），**周瑜死后送丧至吴**（卷三十七正文） | **B／A** |

> ⭐ **「先后顺序」是关键**：正史里庞统与周瑜的关系是**周瑜死后**才发生的（他送丧到吴、被吴人认识），
> **赤壁（208 年）时他在不在周瑜幕中，正史无明文**；《江表传》只说他「为周公瑾功曹」，**没有系年**。
> **结论：连环计是演义原创（C），正史依据是"曹操的船本来就连着"（A）。**

### 6.4 耒阳断案 —— **演义（C）；正史只有六个字**（A）

**正史（卷三十七正文，全文就这些）**：

> 「**先主领荆州，统以从事守耒阳令，在县不治，免官。**」

| 项 | 正史 | 等级 |
|---|---|---|
| 官职 | 「**以从事守耒阳令**」（以从事的身份**代理**耒阳县令） | **A** |
| 政绩 | 「**在县不治**」——**四个字，就这些** | **A** |
| 结果 | 「**免官**」 | **A** |
| **断案** | ❌ **正史无一字** | **A**（正史之无） |

**演义原文（毛本第 57 回），关键三段**：

> 「统到耒阳县，**不理政事，终日饮酒为乐**；一应钱粮词讼，并不理会。有人报知玄德，言庞统将耒阳县事尽废。玄德怒曰：『**竖儒焉敢乱吾法度！**』遂唤张飞分付：『引从人去荆南诸县巡视。』」（同上）
>
> 「同僚覆曰：『庞县令自到任及今，**将百余日，县中之事，并不理问，每日饮酒，自旦及夜，只在醉乡。今日宿酒未醒，犹卧不起。**』」（同上）
>
> 「统**手中批判，口中发落，耳内听词**，曲直分明，并无分毫差错，民皆叩首拜伏。**不到半日，将百余日之事，尽断毕了，投笔于地**，而对张飞曰：『**所废之事何在？曹操、孙权，吾视之若掌上观文，量此小县，何足介意！**』」（同上）

**⚠️ 但有一件"半真"的事**：「**不理政事＋沉醉＋被免官＋诸葛亮出面保**」这个**母题在正史里确实存在 —— 只是主角是蒋琬**，见 §7.14。

### 6.5 「凤雏先生」这个称呼的出处（C）

| 出处 | 原文 | 等级 |
|---|---|---|
| **毛本第 47 回** | 蒋干问：「**莫非凤雏先生否？**」统曰：「**然也。**」 | **C** |
| **毛本第 57 回** | 鲁肃：「此人乃襄阳人，姓庞，名统，字士元，**道号凤雏先生**。」；「孔明急视其人，乃**凤雏先生庞统**也」 | **C** |
| **毛本第 57 回**（孙权的反应） | 「权见其人**浓眉掀鼻，黑面短髯，形容古怪**，心中不喜」；「权曰：『**狂士也，用之何益？**』」 | **C** |
| **正史** | 「**凤雏**」二字只在**裴注引《襄阳记》**里出现一次（「庞士元为凤雏」，**B**）；「**凤雏先生**」这个四字称呼**正史 0 命中** | **B／A（正史之无）** |

> ⚠️ **「凤雏」是 B（裴注）；「凤雏先生」是 C（演义）。两者不要混用。**
> ⚠️ 另：演义里庞统「**浓眉掀鼻，黑面短髯**」的丑陋外貌**是 C**；**正史对庞统的外貌一字未提**（对比赵云有《云别传》的「身长八尺，姿颜雄伟」）。

### 8.3 ⚠️ 演义"自我否认"的一处有趣细节

毛本第 57 回孙权说：「**此时乃曹操自欲钉船，未必此人之功也。吾誓不用之。**」

> ⭐ **演义自己在第 57 回借孙权之口，否认了第 47 回庞统献连环计的实际功劳** ——
> 而且这句话**与正史（曹操自己连船）恰好吻合**。
> **这是一条可以用来给"连环计不可信"背书的 C 级内证**，但**它仍然是演义，不能当史料。**

### 8.4 《华阳国志》卷五的异文（B，用于校对）

《华阳国志·卷五》与《庞统传》平行记载，**逐句有异**（常璩「每存其意而异其文」）：

| 上计理由 | 「**又素无预备，大军卒至，一举便定**」 | 「**又无素豫，一举而定**」 |
| 下计 | 「**退还白帝**，连引荆州」 | 「**退之白帝**，连引荆州」（各本有异文，校记谓「还」字或为衍文） |

| 3 | **「陆勣」还是「陆绩」** | 卷三十七正文同段先作「**陆勣**、顾劭、全琮皆往」，后作「**绩**、劭谓统曰」——**同段两个写法** | ⚠️ 疑为传写之异（**陆绩**字公纪，吴之名士）。**卡池对应卡是 `shu_luce`（陆绩）**。引用时以「**陆绩**」为正、注明维基文库本作「陆勣」 |
| 4 | **「杨怀、高沛」的具体职守** | 卷三十七作「据守**关头**」；《华阳国志》作「据守**关头**」；演义作「**涪水关**」 | 正史只作「**关头**」，**演义把它具体化为「涪水关」** |
| 5 | **上计是否"太促"** | 正史**只有「先主然其中计」六字**，**没有解释理由**；「上计太促，下计太缓」是演义加的 | 采信正史：**理由无载** |
| 6 | **庞统父之名** | 卷三十七只作「统父」，**无名** | **未找到原文** |
| 7 | **赤壁之战时庞统的所在** | 正史无；裴注只说他做过周瑜功曹（无系年） | **存疑**，不要写成"庞统参加了赤壁之战" |
| 8 | **《襄阳记》辑本的可信度** | 今传《襄阳记》为**后人辑本**，文字有讹（「入生俗士」「此间由卧龙」等明显误字） | ⚠️ **引用一律以裴注所引文字为准**，辑本只作参考 |
| 9 | **《九州春秋》「操以急，吾以宽」是否被《先主传》正文采信** | 《先主传》正文**无此语**；《资治通鉴》把它采入正文 | **存疑**，须标 **B**（裴注引《九州春秋》），**不得写成《先主传》载** |
| 10 | **庞统任「治中从事」与「军师中郎将」的先后** | 卷三十七：「以为**治中从事**」→「亲待亚于诸葛亮，遂与亮**并为军师中郎将**」——**同段两任，中间无时间标记** | **先后关系可读通，但无确切系年** |

## 11. 可翻译成卡牌机制的特征清单 ⭐ 本报告重点

> **每条格式**：`特征 → 原文（逐字） → 等级 → 一个机制方向`。
> ⚠️ **本节只提供"特征 → 机制方向"的素材**，**不产出卡牌成品、不写数值、不动 `data/`**。
> ⚠️ 所有机制方向都只是**方向**，落地前必须核 `core` 的动作／触发器／条件／过滤器是否存在（见 `docs/gdd/18-character-skill-design.md`）。

### 11.1 ⭐ 上中下三策（**三选一 / 分支机制**）—— 本卡最独特的素材

| 项 | 内容 |
|---|---|
| **原文** | 「**阴选精兵，昼夜兼道，径袭成都……此上计也。**」「**杨怀、高沛……将军因此执之，进取其兵，乃向成都，此中计也。**」「**退还白帝，连引荆州，徐还图之，此下计也。**」「**若沈吟不去，将致大困，不可久矣。**」「**先主然其中计**」 |
| **出处** | 《三国志·蜀书七·庞统法正传》**卷三十七正文** |
| **等级** | **A** |
| **特征要点** | ① **同一回合给出三个明确不同的选项**（激进／中庸／保守）；② **第四个选项是"不选"**，而原文判它「**将致大困**」；③ **实际选择结果有记载：中策** |
| **机制方向 1** | **一次性三选一**：打出时（或某触发时）**展示三个明确的、互斥的选项**，玩家选一个立即结算；**三个选项分别对应不同的收益／风险档位**（速攻 / 换资源 / 退缩） |
| **机制方向 2** | **「沈吟不去」的第四选项**：如果**不选**（或超时／放弃），触发一个**明确的负收益**——这正好把原文那句「将致大困」变成机制 |
| **机制方向 3** | **三选一 + 事后确认**：原文里刘备选了中策且**执行成功**（「所过辄克」），可给"选完之后有一段额外收益"的两段式 |
| **⚠️ 落地注意** | ① 三选一属于 `mode:'choose'` 的范畴，**必须核 `docs/gdd/18-character-skill-design.md` 里"choose 的兜底陷阱"**：AI 与超时必须有确定性的兜底分支，否则会卡住对局；② 三选一若含随机成分，须过 `docs/gdd/12-randomness.md` 三条铁律（**不能"单次随机决定胜负"**）——**"玩家选"不是随机**，这是合规的关键区别 |

### 11.2 ⭐ 涪城之争「君臣俱失」（**双向 / 对等代价**）

| 项 | 内容 |
|---|---|
| **原文** | 「**伐人之国而以为欢，非仁者之兵也。**」→「**武王伐纣，前歌后舞，非仁者邪？卿言不当，宜速起出！**」→「**先主寻悔，请还。统复故位，初不顾谢，饮食自若。**」→「**向者之论，阿谁为失？**」→「**君臣俱失。**」→「**先主大笑，宴乐如初。**」 |
| **出处** | 卷三十七**正文**（**A**）；裴注另有习凿齿、裴松之两段评论（**B**） |
| **等级** | **A**（正文）＋**B**（裴注「分谤」说） |
| **特征要点** | ① **当面顶撞君主**（而且是**在宴会上、当着众人**：「众中匡其失」）；② **事后不道歉**（「**初不顾谢，饮食自若**」）；③ **各打五十大板**（「**君臣俱失**」，**不是全揽也不是全推**）；④ **裴松之的解读：这是"分谤"** —— **替君主分担舆论** |
| **机制方向 1** | **双向代价 / 对等交换**：「君臣俱失」的字面就是**双方各失**——机制上可做成**己方与对手同时付出代价，而收益归己方**（或反之），核心是**"两边都掉东西"**而不是单向 |
| **机制方向 2** | **顶撞（高风险高收益）**：设计成"**对己方主公／友军造成一点代价，换取一个更强的效果**"——对应「众中匡其失」的**当众顶撞** |
| **机制方向 3** | **「不道歉」的被动**：对应「**初不顾谢，饮食自若**」——**发动后不产生任何"道歉／回退"式的副作用**（比如：效果结算后**不返还、不受反制、状态不变**） |
| **机制方向 4** | **「分谤」的责任转移**：对应裴注的 B 级解读——**把对手或己方受到的负面效果"各分一半"**（伤害分摊／代价平摊） |
| **⚠️ 落地注意** | 「君臣俱失」这四个字**是 A 级**，可以直接做 flavor；「**惟吾有失**」「**何独主公**」是演义（**C**），**不要写进 note 的 A 级栏** |

### 11.3 ⭐ 「非百里之才」（**大材小用 → 潜力 / 翻盘**）

| 项 | 内容 |
|---|---|
| **原文** | 「先主领荆州，统以从事守耒阳令，**在县不治，免官**。吴将鲁肃遗先主书曰：『**庞士元非百里才也，使处治中、别驾之任，始当展其骥足耳。**』**诸葛亮亦言之于先主**，先主见与善谭，**大器之**，以为治中从事。」 |
| **出处** | 卷三十七**正文** |
| **等级** | **A** |
| **特征要点** | ① **在小位置上表现很差**（「在县不治」）；② **换个位置就完全不同**（「**始当展其骥足**」——"骥足"＝千里马的蹄子）；③ **推荐人有两位**（鲁肃写信＋诸葛亮开口）；④ **一句话就被"大器之"**（见一面就改观） |
| **机制方向 1** | ⭐ **位置决定价值**：同一张牌在**不同位置／不同费用段／不同角色类型下强度不同** —— 例如「在有主公／有指定友军在场时强度提升」「放在某类卡旁边才生效」。**这是「非百里之才」最字面的翻译** |
| **机制方向 2** | **被低估 → 成长**：登场时**很弱**（对应「在县不治」），满足条件后**大幅成长**（对应「大器之」「展其骥足」） |
| **机制方向 3** | **被推荐（需要队友"开口"）**：需要**另一个友方角色存在或行动过**才能激活完整效果 —— 对应「**诸葛亮亦言之于先主**」（**两个推荐人**，可做成"需要两张牌／两个友军"） |
| **机制方向 4** | **潜力计数**：把「骥足」（千里马）做成一个**初始为 0、随回合累积的潜力条**，达到阈值后质变 |
| **⚠️ 落地注意** | ⚠️ **「潜力类」效果最怕变成"白板等到天荒地老"**。1/4 的 6 费身体（偏差 −8）意味着**他必须在前两回合就产生可见价值**，纯慢速积累撑不住 |

### 11.4 连环计（**把敌人的东西连在一起，反过来害他**）—— ⚠️ **C 级**

| 项 | 内容 |
|---|---|
| **原文** | 演义第 47 回：「**若以大船小船各皆配搭，或三十为一排，或五十为一排，首尾用铁环连锁，上铺阔板……乘此而行，任他风浪潮水上下，复何惧哉？**」＋「**除非献"连环计"，教他钉作一处，然后功可成也。**」＋后人诗「**若非庞统连环计，公瑾安能立大功？**」 |
| **出处** | 毛本《三国演义》**第 47 回**（嘉靖本亦见） |
| **等级** | **C**（⚠️ **纯演义**）。**正史真相（A）**是「曹操自己的船「首尾相接」，黄盖看破」——见 §6.1 |
| **特征要点** | ① 表面上**帮对手**（让他的船更稳、解决晕船）；② 实际上**把对手的东西绑成一个整体**；③ **一个点着火，全体遭殃**（火攻收益被放大） |
| **机制方向 1** | ⭐ **"帮忙"式陷阱**：给对手一个**看起来是增益、实际是负担**的东西（例如给对手的随从加上某种"绑定"标记），之后**一处受伤、全体连带** |
| **机制方向 2** | **链接／扩散伤害**：把**同类型的敌方单位"连"起来**，**对其一造成的伤害按比例扩散给其余**。⚠️ 但本仓库**没有庞统专属的"铁索连环"关键词**，需核 `data/keywords.yaml` 现有注册项 |
| **机制方向 3** | **反噬放大器**：让对手**已有的一类资源／状态变成弱点**（例如"对手的某类牌越多，受到的效果越强"）——对应"把敌人连成一片，反而害他" |
| **⚠️ 落地注意** | ⚠️ **这是 C 级，卡面 `note` 必须标 C，不能写「史实」**。它的**唯一 A 级垫底**是「操军船舰首尾相接」这一句（但那是**曹操自己的部署**、且**与庞统无关**）。设计者若要保留"连环"母题，**建议把它写成"演义向"并标注**，或者改用 §11.1（三策）／§11.2（涪城）这种 A 级素材做主技能 |

### 11.5 凤雏（**与诸葛亮齐名 / 成对出现**）

| 项 | 内容 |
|---|---|
| **原文（分级要命）** | **B**（裴注引《襄阳记》）：「诸葛孔明为**卧龙**，庞士元为**凤雏**，司马德操为**水镜**，**皆庞德公语也**。」<br>**B**（裴注引《襄阳记》，卷三十五）：「此间自有**伏龙、凤雏**。」<br>**A**（卷三十七正文）：「**亲待亚于诸葛亮，遂与亮并为军师中郎将。**」<br>**A**（卷三十七正文）：「**诸葛亮亲为之拜。**」<br>**C**（演义第 35 回）：「**伏龙、凤雏，两人得一，可安天下。**」 |
| **等级** | **B**（外号本身）／**A**（同官号、诸葛亮亲拜）／**C**（得一可安天下） |
| **特征要点** | ① **成对命名**（卧龙／凤雏是同一个人在同一天给的）；② **同官号**（「**并为军师中郎将**」）；③ **辈分错位**（诸葛亮是庞统族兄的姐夫，**诸葛亮的姐姐嫁给了庞统的族兄**）；④ ⭐ **最硬的一条：诸葛亮亲自去拜庞统的父亲**（「**诸葛亮亲为之拜**」） |
| **机制方向 1** | ⭐ **同场共鸣（需要诸葛亮在场才成立）**：场上同时存在诸葛亮时获得额外效果 —— **这是全池里唯一有 A 级依据的"双人共鸣"之一**（依据：「**遂与亮并为军师中郎将**」＋「**诸葛亮亲为之拜**」，**都是正文 A**） |
| **机制方向 2** | **成对 / 双生机制**：与一个指定友军**共享某个资源或状态**（对应"两人得一"的成对结构） |
| **机制方向 3** | **互斥／此消彼长**：对应演义那句「**一凤并一龙**……**凤死落坡东**」的宿命结构（⚠️ **C 级**，第 63 回童谣） |
| **⚠️ 落地注意** | ⚠️ **「得一可安天下」是 C，绝不能写进 note 的 A 级栏**。而「与诸葛亮同官号」「诸葛亮亲为之拜」是 **A**，可以放心用。**若要用"齐名"，A 级依据是"同为军师中郎将"，不是"齐名"二字**（正史无「齐名」） |

### 11.6 雒城中流矢（**攻城时的意外之死 / 死于过程而非决斗**）

| 项 | 内容 |
|---|---|
| **原文** | 「**进围雒县，统率众攻城，为流矢所中，卒，时年三十六。先主痛惜，言则流涕。**」 |
| **出处** | 卷三十七**正文** |
| **等级** | **A** |
| **特征要点** | ① **死于"流矢"**——不是被名将单挑杀死，是**乱飞的箭**；② **死在攻城过程中**（"率众攻城"——**他本人在前线，不是在后帐**）；③ **死得很突然，没有遗言、没有铺垫**；④ **死后的反应极重**（「先主痛惜，言则流涕」＋给他父亲官＋「诸葛亮亲为之拜」） |
| **机制方向 1** | ⭐ **"意外"而非"必然"的死法**：阵亡效果设计成**不是被指定目标杀死才触发，而是"受到任意伤害而死"就触发**——对应「流矢」＝**没人瞄准他**。⚠️ 但 `docs/gdd/12-randomness.md` **禁止"单次随机决定胜负"**，所以**不能做成"随机死亡"**；应做成**"因任意伤害死亡都适用"的宽触发条件**（这是确定性的，不是随机） |
| **机制方向 2** | **攻城者姿态**：**攻击时**才暴露弱点（例如"攻击时受到的伤害 +1"或"攻击时阵亡触发额外效果"）——对应「**率众攻城**」时中箭 |
| **机制方向 3** | ⭐ **阵亡 = 全队悲愤（哀兵）**：对应「**先主痛惜，言则流涕**」＋「**诸葛亮亲为之拜**」——**他一死，全队的反应比他自己活着时更强**。这是**现卡「阵亡抽 2 张」的原型**（抽 2 张确实是"哀兵"的一种翻译），但**可以做得更有指向性**（例如给指定友军加 buff、或让诸葛亮获得收益） |
| **机制方向 4** | **36 岁的短命（见 11.7）** |
| **⚠️ 落地注意** | ⚠️ **不要写「落凤坡」**（C）；**不要写「被张任射死」**（正史无，A 级之无）；**不要写「换马」**（C）。**A 级可用的是：流矢、攻城、三十六岁、先主痛惜、诸葛亮亲为之拜** |

### 11.7 三十六岁早逝（**短命 / 未完成的潜力**）

| 项 | 内容 |
|---|---|
| **原文** | 「卒，**时年三十六**」（卷三十七**正文 A**）；《华阳国志》卷七称他「**军师庞统**」（**B**） |
| **等级** | **A** |
| **特征要点** | ① **三十六岁**在三国人物里属于**明显早逝**（对比：刘备 63、诸葛亮 54、赵云约 76、法正 45）；② **死时正值上升期**（刚拿下涪城、正要打雒城）；③ **对比诸葛亮**：诸葛亮比他多活了 18 年，而且**庞统死时诸葛亮还在荆州**（「亮留镇荆州」，是庞统死后才入蜀） |
| **机制方向 1** | **「早逝」＝高强度短窗口**：设计成**前几回合非常强、之后衰减或自毁**——把"三十六岁"翻译成"**他只有很短的巅峰期**" |
| **机制方向 2** | **未完成（残局价值）**：他死后留下了**未完成的入蜀事业**（刘备「**言则流涕**」、后来诸葛亮亲自入蜀接手）——机制上做成"**他离场时把未完成的东西交给队友**" |
| **机制方向 3** | **倒计时 / 自毁**：明确的回合数限制 —— ⚠️ **但必须让收益与期限匹配**，否则就是"花钱买一个必然的亏损" |
| **⚠️ 落地注意** | ⚠️ 「三十六」这个数字本身**不适合写进机制**（本仓库没有"年龄"概念，且 36 回合在卡牌局里不成立）；**要用的是"短窗口"这个结构，不是数字本身** |

### 11.8 其余可用特征（简明清单）
