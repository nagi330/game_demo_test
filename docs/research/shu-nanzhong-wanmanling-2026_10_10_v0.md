# 南蛮·洞主群史实考证（木鹿大王 / 带来洞主 / 金环三结 / 董荼那）

> **摘要**
> 1. 五人（木鹿、带来洞主、金环三结、董荼那、祝融夫人）在**《三国志》与《华阳国志·南中志》中全无记载**（insource 检索 0 命中），**是《三国演义》独占虚构**。
> 2. **带来洞主没有阵亡**——他是第 90 回活到最后的角色，孟获的妻弟（国舅）、八番部长，两次亲手把孟获绑去献给诸葛亮。同回阵亡的是**朵思大王**（三江城）与**兀突骨**（盘蛇谷）。
> 3. **木鹿大王不是死在盘蛇谷**，也不死于火攻：他死在银坑洞前，真兽被诸葛亮的木刻彩画巨兽吓回、**反冲自己的蛮兵**，原文仅一句「木鹿大王死於亂軍之中」。盘蛇谷烧死的是乌戈国主兀突骨与三万藤甲军。
> 4. **金环三结与董荼那无「争地图内讧」、也无义兄弟关系**：二人是并列的第一/第二洞元帅；「洞中所获地图」不存在——那是孔明早先从功曹吕凯处得的**《吕凯图本》**。金环三结第 87 回被**赵云一合一枪枭首**，且**演义未交代「三结」名号的来历**（查不到）。
> 5. **「象兵」全书 0 命中**；演义只有个人骑象（木鹿白象、兀突骨骑象）。正史南中之战更无战象——《三国志》卷 35 全文「象」字仅 1 次，指弩机零件。**另需注意：「七擒七纵」不在陈寿正文**，出自裴松之注引《汉晋春秋》；马谡「攻心」段亦为裴注引《襄阳记》。

## 1. 南蛮通用兵种叫法（各指谁）

| 叫法 | 出处原文 | 指谁 / 含义 |
|---|---|---|
| **洞兵** | 第 90 回：「重賞**洞兵**」「木鹿大王引**本洞兵**帶猛獸而出」「即與孟獲引**洞兵**而出」 | 南蛮**通用正规军名**，量级从「生力洞兵五萬」到「各引五萬蠻兵」不等。洞主级人物的自卫军即称「本洞兵」 |
| **洞丁** | 第 89 回：「手下萬餘**洞丁**，各舞刀牌，往來衝突」；「急引宗族**洞丁**殺開條路」 | 与「洞兵」同义的另一写法，偏指**近身刀牌兵**；「宗族洞丁」= 宗族私兵 |
| **獠丁** | 第 89 回：「孟獲引前部一萬刀牌**獠丁**，直扣前寨搦戰」 | 刀牌近战突击部队（与上条同类，命名用「獠」） |

| 藤甲兵（简体写法） | — | 通行简体本写法，wikisource 繁本作「籐甲」 |

## 2. 木鹿大王

**身份与字号**：八纳洞洞主，位于银坑洞西南。原文只作「**此去西南八納洞，洞主木鹿大王**」（第 90 回），**全书未给字号（查不到）**。

**兵种（关键订正）**：他统率的兵**叫「洞兵」，不是「象兵」**——原文是「木鹿大王引**本洞兵**帶猛獸而出」。演义**全书 0 次**出现「象兵」「象骑」（Wikisource `insource:` 检索验证）。白象是他**个人的坐骑**，不是兵种编制。

**外形与法术**：孟获出洞迎接时「見其人**騎著白象**，身穿金珠纓絡，腰懸兩口大刀」；上阵时「腰挂兩把寶刀，手執**蒂鐘**，身騎白象」。「深通法術：出則騎象，能**呼風喚雨**，常有虎豹豺狼、毒蛇惡蠍跟隨。手下更有**三萬神兵**」（带来洞主荐语）。起手式是摇蒂钟咒语 + 狂风飞砂走石，画角一响猛兽乘风冲出。蛮兵装束另有一套：「人多不穿衣甲，盡裸身赤體，面目醜陋；身帶四把尖刀；軍中不鳴鼓角，但**篩金為號**」。

**死法（关键订正：不在盘蛇谷、不死于火攻）**：诸葛亮先令魏延、赵云诈败退至银坑洞口一带，然后开出**十辆红油柜车**，内藏「**木刻彩畫巨獸**，俱用五色絨線為毛衣，鋼鐵為牙爪，一個可騎坐十人」，军士「口內裝煙火之物」。再战时木鹿照旧摇钟召兽，诸葛亮羽扇一摇把风回吹，蜀阵假兽「口吐火燄，鼻出黑煙」，蛮洞真兽「不敢前進，皆奔回蠻洞，**反將蠻兵衝倒無數**」，随后追杀的结局只有一句：**「木鹿大王死於亂軍之中」**——**没有火攻他，没有正面交手，无人被记为凶手**。战场是**银坑洞前**，不是盘蛇谷。盘蛇谷是乌戈国主兀突骨被火攻连同三万藤甲军烧死之处（第 90 回）。赵云对他的评价是全回对他的最高定位：「**我等上陣一生，未嘗見如此人物**」。

**智谋**：**全回零描写**。他只有「勇」与「术」两个标签，两次都被诸葛亮用机关（车阵 + 假兽 + 回扇风）以巧破力，死因是自己召来的兽踩自己。

**正史**：**无**。《三国志》insource 检索「木鹿」0 命中，《华阳国志·南中志》0 命中。**正史完全没有战象**。

**可用于卡牌的记忆点**
- **「反噬」**：木鹿的兽群在假兽（火烟）面前掉头——**冲回己方阵型并造成友军伤害**。对应技能：本回合他造成的伤害有 X 点会反弹回随机友军/嘲讽他本人的单位；受「火/烟」属性的单位对其伤害 +1（呼应木兽口吐火燄）。
- **「篩金為號 / 蒂鐘一响」**：**召唤物是他自己召的，且被己方单位恐惧会立刻溃散反向冲阵**——「木鹿在场时，所有敌方野兽/召唤单位获得『畏象』：死亡时改为冲撞木鹿的友军」。

## 3. 带来洞主

**写法确认**：正字就是「**帶來洞主**」，**没有「了」字**。第 90 回全部 4 次出现、嘉靖本《三国志通俗演义》第 179/180 回同，无异写。

**身份（关键订正：他不是独立洞主，更没有阵亡）**：原文明确定位为**孟获的妻弟**（即国舅），「乃孟獲妻弟，現為**八番部長**，名曰帶來洞主」——**「部长」是职衔，名字里带「洞主」但不是洞主**。第 90 回开篇他才首次登场，是**主降派**。结局：第 90 回末「孟獲與祝融夫人並孟優、**帶來洞主**、一切宗黨在別帳飲酒」时，他是促成孟获肉袒谢罪的人之一。**全书无他的死**（同回战死的另有守三江城的**朵思大王**「死於亂軍之中」，以及盘蛇谷的**兀突骨**）。

**战绩（全部是计谋，不是武勇）**：① **举荐外援**——力荐八纳洞木鹿大王：「大王可修書具禮，某親往求之」；② **第六擒的绑缚者**——率刀斧手把孟获、祝融夫人及宗党数百人「盡皆擒來，獻與丞相」，随后自己出「**詐降**」计谋，想在洞中杀孔明：「汝只道吾深信，故來詐降，欲就洞中殺吾」，结果被搜出身畔利刀、全盘落空；③ **引荐第二拨外援**——献策乌戈国藤甲军。他**全书没有一次与人交手**，无一处武艺描写。

**正史**：**无**。「帶來」在《三国志》《华阳国志·南中志》insource 检索均 0 命中。

**可用于卡牌的记忆点**
- **「献主」**：两次把己方主帅送出门换赏——**可将己方一名非核心武将/首领交给对手，换取大量手牌或本回合额外行动**；若无合法目标则技能不可用（对应「无目标时不可发动」的约束）。
- **「诈降」**：伪装为「投降」骗取对手资源，**但只要对手手牌数 ≥ 你的手牌数则诈降失败**，你受 2 点伤害且本回合不可再行动——把「被识破」做成可读条件，而不是随机判定。

## 4. 金环三结

**身份**：**孟获麾下三洞元帅之一，排在第一**，不是南蛮王、也不是独立洞主。第 87 回原文：「卻說**蠻王孟獲，聽知孔明智破雍闓等，遂聚三洞元帥商議。第一洞乃金環三結元帥**，第二洞乃董荼那元帥，第三洞乃阿會喃元帥」，三洞元帅「各引五萬蠻兵」分三路（金环三结取中路、董荼那左路、阿会喃右路），孟获许诺「如得勝者，便為**洞主**」——可见「洞主」是他们**尚未获得的升迁目标**，说明三人当时只是元帅。其大寨在山口，「寨邊東西兩路，卻通五溪洞並董荼那、阿會喃各寨之後」。

**死法（关键订正）**：第 87 回，诸葛亮故意不用赵云魏延、二将请战私自带五千精兵趁夜摸营，「剛到金環三結大寨之時，約有四更，蠻兵方起造飯，準備天明廝殺。忽然趙雲、魏延兩路殺入，蠻兵大亂。趙雲直殺入中軍，正逢金環三結元帥；**交馬只一合，被雲一槍刺落馬下，就梟其首級**」。诸葛亮事后自陈计策：「先破金環三結，隨即分兵左右寨後抄出，以王平、馬忠應之」——**用吕凯图本定寨位，以言辞激赵云、魏延的锐气**，是全回第一场硬仗的胜因。孟获第一擒即在紧随其后（魏延解孟获到大寨）。

**「分裂 / 争地图 / 被离间」——查不到**：演义**没有**任何一处写金环三结与董荼那争夺地图或互相内讧。三点澄清：① 二人是**并列元帅，不是义兄弟**；② 第 87 回孔明的「反间计」针对的是益州三郡的**高定、雍闓、朱褒**（离间高定与雍闓 → 高定杀朱褒献首级），与金环三结无关；③ 那张「图」是孔明**早已从永昌太守王伉麾下功曹吕凯处获得的《吕凯图本》**，用途是「**吾觀呂凱圖本，已知他各人下的寨子**」，**由孔明独占使用**，从未成为洞主们争夺的实物。

**武力描写**：只有「一合」这一笔——**全书对他的武艺描写仅此一句，且是败笔**。无字号（查不到）、无相貌描写、无智谋（他甚至没来得及用计）。

**正史**：**无**。《三国志》insource「金環」0 命中，《华阳国志》0 命中。

**可用于卡牌的记忆点**
- **「一合」**：他是全书唯一被描述为「交馬只一合」就阵亡的洞主——**技能：若该单位在场，任何敌方单位对它发动的攻击自动结算两段（首段结束后若其存活，再结算第二段）**；或者反过来做「先手即死」的脆皮刺客型：**受到第一个攻击伤害时不受护甲/闪避，直接进入重伤**。
- **「三结」无出处 → 名字可自由解读**：演义**没有解释「三结」二字的来历**（查不到；民间「三姓结义」之说不在书中）。设计若要绑定「结」，建议自定为「**三洞结盟/三个义兄弟**」而非声称有史据，并在卡面来源标注写「演义未载」。

## 5. 董荼那

**身份与关系**：孟获麾下**第二洞元帅**（第 87 回），与金环三结、阿会喃并列。**演义未写他是金环三结的义兄弟（查不到）**——全书未给董荼那任何兄弟或亲属设定，他的「兄弟」关系线**查不到**，故不为其安排。（第 89 回出现过一句「兄弟二人，抱頭相哭」，经核原文指的是**孟获与其弟孟优**重逢，与董荼那无关，勿混引。）

**战绩与结局（被夹击擒 → 释放 → 内讧 → 被主公杀掉）**：
1. **第 87 回被擒**：赵云、魏延破金环三结后分兵抄其后寨，正遇提前赶到的王平，**前后夹攻**，「董荼那奪路走脫，魏延追趕不上」；实为张嶷**用伏兵守山路**擒获。孔明令去缚、以酒食衣服赐之，「令各自歸洞，勿得助惡」，放回。
2. **第 88 回出戰失利**：「吾願往」→ 与马岱「不戰而退」，被孟获当众喝问「正是賣陣之計」，喝教推出斩了，众酋长哀告才免死，**打了一百大棍放归本寨**。
3. **第 88 回带头内讧**：他纠集众酋长「手執鋼刀，引百餘人，直奔大寨而來」，趁孟获大醉，**亲手将孟获执缚，押到泸水边驾船渡北岸献给孔明**——孟获第二次被擒。孔明放人后，孟获随即设局报复。
4. **第 88 回死法**：孟获「先伏刀斧手於帳下，差心腹人到董荼那、阿會喃寨中，只推**孔明有使命至**，將二人賺到大寨帳下，**盡皆殺之，棄屍於澗**」——**死在内讧清算中，凶手是孟获本人，用的是诱骗之计，不是战场死法。**

**武力描写**：**极弱**。全书唯一一次正面交锋是与马岱——「岱縱馬向前大罵曰：『無義背恩之徒！吾丞相饒汝性命，今又背反，豈不自羞！』**董荼那滿面慚愧，無言可答，不戰而退**」；另有其部将忙牙长与马岱接战，「忙牙長出馬，與馬岱交鋒，只**一合，被岱一刀，斬於馬下**」（非董荼那本人）。

**正史**：**无**。《三国志》insource「董荼那」0 命中，《华阳国志》0 命中。

**可用于卡牌的记忆点**
- **「百棍」**：他活着从阵前退回挨了一百大棍——**技能：每受到一次「未还击」的伤害，叠加 1 层『负创』（上限 N 层）；满层时该单位免疫下一次控制**。把「受罚」做成可累积的资源。
- **「刀指主公 / 内讧」**：手执钢刀直入大帐捆走主帅——**战吼：指定敌方一名非主公武将，将其移交给其对手（或使其本回合无法响应指令）**；对应他被自己旧主「诈赚杀之」的反讽，可给该卡加一条**限定：不能对已向你造成过伤害的单位生效**。

## 6. 设计问题一：「象兵」出现在哪一回？正史有没有？

**结论：演义里没有「象兵」这个兵种，正史连战象都没有。**

| 问题 | 答案 | 依据 |

## 7. 设计问题二：三人是「同一批」洞主吗？

**结论：不是。三人分属三个不同的阵营位置，不应做成同一「阵营/标签」体系。**

| | 木鹿大王 | 金环三结 | 带来洞主 |
|---|---|---|---|
| **回目** | 第 90 回 | **第 87 回** | 第 90 回 |
| **编制** | **八纳洞洞主**（洞外盟军主将） | 孟获本部**第一洞元帅** | 孟获**妻弟**（国舅）+**八番部长** |
| **隶属** | 八纳洞主，**受带来洞主之请来援** | 孟获直辖三洞元帅之一 | **孟获的姻亲**，非洞主编制 |
| **登场→退场** | 第 90 回登场 → 同回即死于银坑洞乱军 | 第 87 回登场 → **同回被赵云一枪枭首**（全战役最早死的洞主） | 第 90 回登场 → **活到七擒结束**，促成最终归降 |
| **怎么来的** | 客军（孟获遣使修书具礼请来的外援） | 本部（未开打就被夜袭打死） | 内应/主降派（自己人绑自己人） |
| **结局** | 死于己方猛兽反冲踩踏 | 被斩首 | **无死** |

**建议的标签体系（三档）**：
- **本部元帅**（金环三结、阿会喃、朵思大王等）：孟获直辖，最早被消耗，用于「前排送死/被先手秒杀」。
- **客军洞主**（木鹿大王、兀突骨、杨锋等）：外部盟友，各带一套独门军械/坐骑（木兽、藤甲、三万藤甲军），**死后其技/械可被其他卡继承**。
- **姻亲内应**（带来洞主）：不属洞主序列，功能是**资源转换与背叛**（献主、诈降），无武艺。

三者**唯一可共享的标签是地域系「南中·洞主」或「南蛮」**，这可作为羁绊/筛选条件；**阵营归属必须区分**，否则「带来洞主（内应）·木鹿（客军）·金环三结（本部）」同标签会立刻造成设计冲突——尤其「带来洞主是引来木鹿的人」这一层，正好可以用**羁绊**而非同一阵营来表达。
